# 课时 key=fire min=7：消防常识
深夜，休息区的一个插座突然冒出黑烟，旁边还有客人在睡觉。你离得最近，手边就有灭火器。这时候第一句喊什么、第一个动作做什么，决定了火能不能在刚起来时就灭掉。

## 本课目标
- 学完能正确拨打 119，说清关键信息
- 学完能按「提、拔、握、压」用好灭火器
- 学完能说出疏散的要点，知道消防通道不能堵

## 发现火情先做什么
:::steps 喊、报、扑、撤
喊｜大声喊「着火了」，叫附近的同事帮忙，请一个人去报告值班经理
报｜拨打 119，同时按门店规定启动报警
扑｜火小、自己能控制时，用灭火器扑救刚起的火
撤｜火大了、烟大了，马上停止扑救，组织客人疏散
:::

## 打 119 说什么
:::cards 报警要说清四件事
在哪里｜门店的详细地址，附近明显的标志
什么着火｜比如电器、厨房油锅、布草
火有多大｜火势怎样，有没有人被困、有没有人受伤
你是谁｜你的姓名和能联系上你的电话
:::

说完别急着挂电话，等对方问清楚。按门店安排，派人到门口接消防车。

## 灭火器怎么用
门店里常见的是干粉灭火器。用之前看一眼压力表，指针在绿色区域才正常。

:::steps 提、拔、握、压
提｜提起灭火器，跑到离火几米远、站在上风的位置
拔｜拔掉保险销
握｜一只手握住喷管，对准火焰的根部
压｜另一只手用力压下压把，左右扫射，直到火灭
:::

:::warn 这几种火要注意
- 电器着火：先断电，再灭火，不要用水泼
- 油锅着火：盖上锅盖、关火，不要用水浇
- 人身上着火：不要乱跑，就地打滚，或者用浸湿的厚浴巾盖住
:::

## 疏散
- 跟着疏散指示标志走安全出口，不坐电梯
- 用湿毛巾捂住口鼻，弯腰、低姿前进
- 浴区的客人穿得少，提醒他们披上浴巾、浴衣马上走，不要回去拿东西
- 到门店规定的集合点集合，清点人数，报告还有谁没出来
- 已经出来了，就不要再回去

:::ban 消防红线
- 不堵消防通道，不在通道和安全出口堆东西
- 不锁死安全出口，不挡住灭火器和消火栓
- 不私拉电线，不在禁止的地方抽烟、用明火
:::

《消防法》要求单位保障疏散通道、安全出口畅通。消防通道一旦被堵，着火时就是一条死路。

:::check
用干粉灭火器灭火时，应该对准哪里喷？
- [ ] 火焰的顶部
- [x] 火焰的根部
- [ ] 烟最大的地方
解析：要对准火焰的根部左右扫射，才能把火压住。对着火苗顶上或者烟喷，灭不了火。
:::

:::check
着火疏散时为什么不能坐电梯？
- [x] 着火时电梯可能断电停住，人会被困在里面，烟也会灌进来
- [ ] 电梯太慢
- [ ] 电梯只给客人用
解析：火灾时电梯随时可能停电，被困在里面很危险。要走安全出口和楼梯。
:::

## 本课小结
- 发现火情：喊、报、扑、撤；报警说清在哪里、什么着火、火多大、你是谁
- 灭火器：提、拔、握、压，对准火焰根部
- 疏散走安全出口不坐电梯，消防通道永远不能堵

# 课时 key=utility min=6：用电、用水与设备
浴区一个插座旁边一直在滴水，有同事伸手去拔插头，觉得手麻了一下。浴区、厨房到处是水，水和电碰到一起，是最危险的组合。

## 本课目标
- 学完能说出潮湿的地方用电的几条规矩
- 学完能在发现漏水漏电时，先断电、再报修
- 学完能在有人触电时用对方法

## 潮湿的地方怎么用电
:::ban 用电红线
- 湿手不碰开关、插座、插头
- 不私拉电线，不乱接插线板
- 浴区、厨房里不用自己带来的电器
- 不用湿布擦带电的设备
:::

- 插座的防水盖要盖好，电线不能泡在水里
- 设备外壳破了、电线露出来了，马上停用并报告
- 下班前按门店规定关掉不用的电器

## 发现漏水、漏电
:::steps 停、断、隔、报
停｜停下手上的事，自己不靠近，也别让客人靠近
断｜能安全断电的，用干手关掉这一路的开关；不会断、够不着的，马上叫工程同事
隔｜放提示牌、拉警戒线，把这一片隔开
报｜报告工程部和值班经理，说清位置和情况
:::

## 有人触电
- 先断电：关掉开关或总闸
- 一时断不了电：用干燥的木棍、塑料棍这类不导电的东西，把电线挑开
- 不能用手直接去拉触电的人
- 人脱离电源以后，马上拨打 120，请有急救证的同事处理

## 设备与燃气
:::table 设备怎么对待
设备｜你要做的｜不要做的
锅炉、热水、蒸汽设备｜有异响、漏水、冒汽，马上报告工程｜不是工程人员不操作、不拆修
配电箱｜前面不堆杂物，门关好｜不随便打开，不在旁边堆东西
燃气｜闻到燃气味：关阀门、开窗，人撤到外面再打电话｜不开关电器，不打火，不在现场打电话
:::

:::tip 看到检修牌不要动
设备检修时，工程同事会在开关上挂「正在检修，禁止合闸」一类的牌子。看到这种牌子，谁也不要去动开关。
:::

:::check
发现浴区插座旁边漏水，有人说手麻了，第一步做什么？
- [ ] 拿湿拖把把水拖干
- [x] 让人远离，能安全断电的先断电，再报告工程
- [ ] 用手把插头拔下来
解析：漏水加漏电非常危险。先让人远离、断电，再隔开、报告。不能用湿拖把、湿手去碰。
:::

## 本课小结
- 湿手不碰电，不私拉电线
- 漏水漏电：停、断、隔、报
- 有人触电先断电，不能用手直接拉

# 课时 key=patrol min=6：巡场
凌晨两点，你巡到一处消防通道，门口堆着几箱刚到的饮料。手机扫码打卡成功了，可你要是只扫码不看，这个隐患就留下了。巡场打卡记的是你来过，真正要紧的是你看到了什么、处理了什么。

## 本课目标
- 学完能用柚子饭堂扫场所码打卡
- 学完能处理断网、「这一轮已打过卡」这些情况
- 学完能说出巡场要看的地方，发现问题马上报告

## 怎么打卡
门店在场内各处贴了场所二维码，一个码对应一个场所。门店设定的巡场部门的同事，在柚子饭堂的「工作台」里能看到「巡场」。

:::steps 扫码打卡
打开｜在柚子饭堂点「工作台」，再点「巡场」
扫码｜点「扫码打卡」，扫贴着的场所码；也可以直接用手机相机或微信扫一扫
看结果｜屏幕上大字显示场所名称、打卡时间和第几轮
看清单｜下面列着这一轮各个场所，还没巡的排在前面
:::

## 一轮一次
- 巡场按时间分轮，默认 3 小时一轮；间隔和从几点开始，由门店在后台设
- 同一个场所，每一轮只记一次打卡，不管是谁打的
- 这一轮已经有人打过，再扫会提示「这一轮已打过卡」，并写明是谁几点打的
- 结束的一轮里没打的场所会标「漏巡」，店总和门店指定的人在后台、手机上都看得到

## 断网了怎么办
:::tip 断网也能扫
- 断网时照常扫码，记录先存在手机上
- 联网后会自动补交，不用重扫；页面上显示「还有 N 笔等联网补交」
- 只收 24 小时内扫到的，联网后尽快打开柚子饭堂让它补交
:::

:::ban 不能这样做
- 不用码的照片代打卡，不替别人打卡
- 不只扫码不看
- 码坏了、丢了、怀疑被人拍走了，告诉主管在后台「换码」重贴
:::

## 巡场看什么
:::table 巡场重点
地方｜看什么
消防通道、安全出口｜有没有堆东西，门有没有锁死，指示灯亮不亮
灭火器、消火栓｜在不在原位，有没有被挡住，压力表指针在不在绿区
电器、配电箱｜有没有冒烟、焦味、异响，电线有没有露在外面
水管、地面｜有没有漏水、积水
门窗和可疑情况｜该锁的锁了没有，有没有可疑的人和东西
客人｜有没有醉酒、晕倒、吵架，有没有在禁烟的地方抽烟
:::

:::warn 打卡不能代替报告
巡场打卡只记谁几点到过哪里，不能在上面报问题。发现问题，当场能处理的处理掉；处理不了的，马上报告值班经理或工程部。
:::

:::check
你扫码时提示「这一轮已打过卡」，说明什么？
- [ ] 系统坏了，要一直扫到成功为止
- [x] 这一轮这个场所已经有人打过卡，不会重复记
- [ ] 你的账号被停用了
解析：同一个场所每一轮只记一次，提示里会写是谁几点打的。照常检查这个场所，然后去下一处。
:::

## 本课小结
- 柚子饭堂「工作台」里的「巡场」扫码，一个场所一轮只记一次
- 断网照常扫，联网自动补交，24 小时内有效
- 打卡只是记录，发现问题要当场处理或马上报告

# 课时 key=emergency min=8：突发事件处置
周末客人多，一位客人在池边滑倒，头磕在地上。旁边的人围过来，有人想把他扶起来。你是第一个赶到的员工。这时候慌和乱都没用，记住几条原则，就能稳住场面。

## 本课目标
- 学完能说出突发事件处置的五条原则
- 学完能处理客人晕倒、溺水、滑倒受伤
- 学完能在打架、停电时保护好客人和自己

## 五条原则
:::cards 记住五个词
先安全｜先确认现场对你和客人是安全的，再上前
呼救｜大声叫同事帮忙，需要时马上拨打 120 或报警 110
报告｜第一时间报告值班经理
不乱动｜受伤的人，特别是头、脖子、腰受伤的，不要随意搬动
配合｜配合急救人员和警察，事后如实说明经过
:::

## 几种常见情况
:::table 先做什么、不要做什么
情况｜先做什么｜不要做
客人晕倒｜叫人、报告；在高温的地方晕倒的，几个人小心把他移到通风凉快处；叫不醒、呼吸不正常的马上拨打 120｜不要灌水，不要围得透不过气
溺水｜大声呼救，用救生杆、救生圈这类能递过去的东西施救；救上来后由有急救证的同事急救，同时拨打 120｜不会救生的不要盲目跳下水
滑倒受伤｜让客人先别急着起来，问哪里疼；出血的用干净毛巾按住；撞到头、脖子或怀疑骨折的不搬动，拨打 120｜不要硬把人拉起来
打架｜不参与、不激化，让周围的客人离开；报告值班经理和保安，需要时报警 110｜不要动手，不要一个人硬去拉
停电｜保持镇静，安抚客人原地别动；引导池里、桑拿房里的客人慢慢出来；用应急照明｜不要乱跑，不要点明火照明
:::

## 急救交给有证的人
- 心肺复苏、止血包扎这些急救，由有急救证的同事做
- 门店配有自动体外除颤器（AED）的，由培训过的同事按门店规定使用
- 你能做的：喊人、拨打 120、拿急救箱、劝散围观的人、到门口接救护车

拨打 120 时说清：门店地址和附近的标志；病人是男是女、大概多大年纪、发生了什么、现在清不清醒、有没有呼吸；你的电话。

:::scenario 客人在池边滑倒
一位客人在池边滑倒，头磕到地上，说脖子有点疼。旁边有人想把他扶起来。你怎么做？
- [x] 请大家先别扶，让客人别乱动，叫同事报告值班经理、请有急救证的同事过来，拨打 120｜对。头和脖子受伤不能随意搬动。先稳住客人，再呼救、报告，交给专业的人。
- [ ] 赶紧和旁边的人一起把他扶到休息区｜不对。脖子疼可能伤到了颈椎，随意搬动会加重伤情。
- [ ] 先去拿拖把把地拖干，免得别人再滑倒｜不对。防滑很重要，但先顾受伤的人，可以请别的同事去放提示牌。
:::

:::check
发现有人溺水，你不会游泳，应该怎么做？
- [ ] 马上跳下去救
- [x] 大声呼救，用救生杆、救生圈这类东西施救，同时叫人拨打 120
- [ ] 先跑去找主管，回来再说
解析：不会救生的人跳下水，很可能两个人都出事。用工具施救、大声呼救，同时叫急救。
:::

## 本课小结
- 五条原则：先安全、呼救、报告、不乱动、配合
- 头、脖子、腰受伤的不搬动；急救交给有证的同事，拨打 120
- 打架不参与，停电不乱跑，先保护好客人

# 实操 key=practice：灭火器与疏散演练
- 说出发现火情的四步：喊、报、扑、撤
- 模拟拨打 119：说清在哪里、什么着火、火多大、有没有人被困、联系电话
- 检查灭火器压力表，指针在绿色区域
- 按「提、拔、握、压」演示用灭火器，对准火焰根部
- 演示时站在上风位置，左右扫射
- 说出电器着火、油锅着火的正确处理方法
- 说出离自己岗位最近的两个安全出口和疏散路线
- 说出门店规定的集合点在哪里
- 演示用湿毛巾捂住口鼻、弯腰低姿前进
- 引导「客人」披上浴巾、走安全出口、不坐电梯
- 到集合点后清点人数，向负责人报告
- 检查自己岗位附近的消防通道没有被堵住

- [x] 马上停用，隔开客人，报告工程部
- [ ] 不用管，等它坏了再说
- [ ] 自己拆开修一修
解析：潮湿的地方电线外露很容易漏电伤人。要马上停用、隔开，交给工程同事处理，自己不拆不修。

有同事触电了，人还贴着电线。你应该怎么做？
- [ ] 马上用手把他拉开
- [x] 先断电；一时断不了，用干燥的木棍等不导电的东西把电线挑开，再拨打 120
- [ ] 往他身上泼水
- [ ] 等他自己松开
解析：用手直接去拉，你也会触电。先断电，断不了用不导电的东西挑开电线，人脱离电源后马上拨打 120，请有急救证的同事处理。

- [ ] 要找主管在后台补录

:::question recall skill=巡场打卡 level=2

答：打卡只是记录到过这里，不能代替报告。当场能搬开的马上搬开；搬不了的，马上报告值班经理，说清位置和情况。

:::question judge skill=巡场打卡 level=2
打卡成功，就说明这个场所没有问题。
答案：错
解析：打卡只记谁几点到过哪里。场所有没有问题，要靠你认真看：通道、灭火器、电器、漏水、可疑情况、客人状态。
:::

- [x] 保持镇静，安抚客人原地别动

- [x] 用应急照明

:::question single skill=突发处置 level=1
客人摔倒后说脖子疼，正确的做法是？
- [ ] 马上扶他坐起来
- [x] 让他别乱动，不随意搬动，叫有急救证的同事并拨打 120
- [ ] 让他自己慢慢走到休息区
- [ ] 给他揉一揉脖子
解析：头、脖子、腰受伤的，随意搬动可能加重伤情。让客人别乱动，呼救、报告，交给有急救证的同事和急救人员。
:::
