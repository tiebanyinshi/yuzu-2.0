# 课时 key=order min=7：点单、档口与出品
一位泡完澡的客人在休息厅要了一份点心和一碗糖水，说：「送到我按摩的那间房。」你在点单页上要填什么？厨房怎么知道往哪送？弄清从点单到出品这一路，菜才不会送错、送慢。

## 本课目标
- 学完能用点单页给手牌客人、房间里的客人下单
- 学完能说出出品档口是什么、菜怎么到厨房
- 学完能用好口味备注、整单备注和送达房号

## 点单页怎么用
:::steps 给客人下单
找客人｜填手牌号或房号，至少填一样。只填房号的，系统按这间房现在登记的客人找
选入口｜先选餐厅、水吧或果吧，再按小分类找菜；只显示你有权限下单的出品口
加菜｜点份数，口味要求写在这道菜的备注里，比如少辣、去冰
写整单备注｜整单的要求写在整单备注里，厨房每道菜下面都看得到
下单｜确认后下单。手牌客人的钱记在他的手牌账上
:::

:::tip 送到哪间房
- 手牌号、房号都填：钱记在手牌上，房号写在送达位置
- 只填房号：系统找这间房现在的客人，找不到就下不了单
- 厨房屏和点菜单上会写「送到房」和房号，送餐时照着送
:::

## 档口与出品
档口就是出品的地方，比如中厨、点心、水吧。每道菜下单后，会送到它的档口的厨房屏上。一类菜（比如点心）可以在后台设默认档口，点心就会到点心档口出，不会跑到中厨。

- 厨房屏上一道菜从「待做」到「制作中」，再到「待上菜」
- 做好了，厨房点「出餐」；服务员送到桌上或房间，点「上菜」
- 等得太久的菜会标红；客人催了，在点单页点「催单」
- 点菜单上能看到每道菜上了没有

## 临时项目
菜单上没有的东西，前台可以用「加项目」手工下一个临时项目（要有「手动金额」权限）。临时项目可以选档口：选了档口的，照常出一张单到那个档口；不选的不进厨房，就要另外通知厨房。

:::warn 下单前核对
- 手牌号、房号有没有填错
- 份数、口味备注对不对
- 已经结账离店的手牌，不能再点单
:::

:::check
客人在按摩房里要一碗糖水，手牌号和房号你都知道，应该怎么填？
- [x] 两个都填，钱记在手牌上，厨房屏写送到这间房
- [ ] 只填房号，钱记到房间上
- [ ] 什么都不填，口头告诉水吧
解析：两样都填时，账记在手牌上，房号写在送达位置，按房号送。只靠口头通知容易漏单、错单。
:::

## 本课小结
- 手牌号、房号至少填一样，口味要求写进备注
- 菜按档口到厨房屏，出餐、上菜都要点
- 临时项目选了档口才进厨房

# 课时 key=soldout min=5：沽清
周六中午，一道招牌点心卖得很快，厨房只剩最后两份，服务员还在不停地给客人推荐。客人等了半天，才被告知「没有了」。这就是没有及时沽清的后果。

## 本课目标
- 学完能说清沽清的意思和写法
- 学完能看懂点单页上的「剩 N」和「已沽清」
- 学完能在菜卖完时礼貌地跟客人说明，并推荐别的

## 沽清是什么
沽清就是一道菜今天卖完了、不再接单；也指给一道菜定「今天还能卖几份」。「沽」有卖的意思。门店里一律写三点水的「沽清」，不要写成估计的「估」。

:::cards 翻一翻，记一记
沽清｜一道菜今天卖完、不再接单；也指设定今天还能卖几份
剩 N｜厨房设的今天还能卖 N 份，点单页上会显示
已沽清｜剩 0 份，点单页上变灰，点不了
不限｜没设份数，就是不限量
:::

## 谁设、怎么设
- 厨房有「厨房出品屏」权限的同事，在「沽清」页设：限量几份、沽清，或改回不限
- 沽清只管当天：今天设的份数，管的是今天还能卖几份
- 设好以后，点单页和前台「加项目」里会显示「剩 N」，沽清的变灰
- 下单扣份数，退菜加回去；份数不够时整单下不了，系统会提示今天只剩几份
- 设了售卖时段的菜，不在时段里会自己停售，不用人去设沽清
- 沽清的份数和库存没有关联，要靠厨房按实际情况设

:::warn 及时沽清
食材快用完时，厨房要马上设份数或沽清，前厅也要及时看。不要等客人点了再说没有。
:::

## 菜卖完了怎么跟客人说
:::scenario 客人点的菜已沽清
客人点了一道菜，点单页上显示「已沽清」。你怎么说？
- [x] 「不好意思，这道今天已经卖完了。同类的这道也很受欢迎，您要不要试试？」｜对。先道歉，说清楚，再推荐别的，客人更容易接受。
- [ ] 「没有了。」｜不对。太生硬，客人会觉得不被重视。
- [ ] 先答应客人，回头再跟厨房商量｜不对。沽清的菜下不了单，先答应再变卦，客人等得更久、更不满意。
:::

:::check
点单页上一道菜显示「剩 2」，客人要 3 份，会怎样？
- [ ] 能下单，厨房想办法
- [x] 下不了单，要跟客人说明只剩 2 份
- [ ] 系统自动改成 2 份
解析：份数不够时整单下不了，并提示今天只剩几份。要跟客人说明，问他要 2 份还是换别的。
:::

## 本课小结
- 一律写「沽清」，意思是今天卖完，或者限定今天还能卖几份
- 点单页「剩 N」是今天还能卖的份数，沽清的点不了
- 卖完了先道歉再推荐别的，厨房要及时沽清

# 课时 key=table min=7：桌台、包房与结账
包房里一桌客人结账时，系统提示「低消还差一点」。客人补了差额，结完账正要走，又说：「再来个果盘吧。」可这一单已经结了。这时候怎么办？包房的规矩多，弄懂了才不会手忙脚乱。

## 本课目标
- 学完能说出桌台的几种状态，会清台、并台、拆台
- 学完能说清低消、服务费在结账时怎么算
- 学完能分清挂到手牌、转挂账和返台

## 桌台的状态
:::table 桌台状态
状态｜什么意思｜要做什么
空闲｜可以开台｜带客人入座、开台
用餐中｜有客人在吃｜点单、上菜、结账
待清台｜刚结完账，还没收拾｜收拾好后点「清台」，才能开下一桌
维修中｜桌子坏了，写了原因和预计恢复时间｜修好后点「恢复」
:::

- 待清台、维修中的桌开不了台，也换不过去
- 两桌客人要一起结：在主台「并台」，结账时一起结；要分开结，附台点「拆台」

## 包房：低消、房费与服务费
挂了「包房房型」的桌就是包房。包房怎么收，按房型设：

- **按低消**：这一桌的菜钱不到低消，结账时会提示还差多少。有的房型另有「中消」，在规定的时段里或人数少时按中消算
- **只收房费**：不设低消，结账时记一行房费

服务费按这一桌点了、没退、没赠送的菜钱算，结账时自动记一行；赠送的菜不算服务费。低消、中消、房费、服务费的金额和比例，以及哪些桌收，都以门店设置为准。

## 低消不够怎么办
:::steps 结账时低消不够
补足低消｜客人同意的，收银勾「补足低消」，差额一起收
转挂账｜客人要晚点结，可以「转挂账」：桌台先空出来给下一桌，账单留着之后结
返台｜包房低消没够、客人还想接着点：转挂账的单可以回原桌继续点；已结账补了低消的单，客人没走、桌子还没清台、在时限内，可以返台补低消
:::

:::warn 返台要有权限
返台要「返台」权限（门店默认值班经理及以上和餐饮主管），要写原因。已结账的单返台会先反结账，所以还要有「反结账」权限。清过台的桌不能返台。
:::

## 挂到手牌
洗浴客人在店里点餐，可以直接记在他的手牌账上，离店时在前台一起结。已经结账离店的手牌不能再挂。前台「转单」也能把餐饮的菜转到另一张手牌上，出品单跟着走。

:::check
包房客人结账时菜钱不到低消，下面哪些是可以的做法？
- [x] 客人同意，勾「补足低消」一起收
- [x] 客人要晚点结，先「转挂账」
- [ ] 不告诉客人，自己把低消改掉
- [x] 符合条件的，返台让客人接着点
解析：低消不够可以补足、转挂账，或者在符合条件时返台。门店设好的规则不能私自改。
:::

## 本课小结
- 结完账先待清台，收拾好点「清台」
- 低消、服务费按门店设置，赠送的菜不算服务费
- 低消不够：补足、转挂账，或符合条件时返台

# 课时 key=food-safety min=6：食品安全基本要求
一位客人点了一份炒饭，顺口说了一句「我对花生过敏」。点单的同事没写下来，厨房照常放了花生碎。食品安全出了问题，轻的让客人不舒服，重的可能危及生命。

## 本课目标
- 学完能说出上岗前要有健康证、做好个人卫生
- 学完能做到生熟分开、按规定留样、管好温度
- 学完能在点单时问过敏原，并告诉厨房

## 上岗前
- 接触食品的岗位，要有健康证，按规定定期体检
- 发烧、拉肚子、手上有伤口或化脓的，先告诉主管，不接触食品
- 穿干净的工服、戴帽子，头发不露出来；不留长指甲，不戴戒指、手链
- 上岗前、上完厕所、碰过生食或垃圾以后，都要洗手

《食品安全法》要求餐饮单位管好从业人员的健康，接触直接入口食品的员工要取得健康证明才能上岗。具体怎么办，按门店规定。

## 生熟分开
:::table 生熟分开
东西｜怎么分
刀和砧板｜生的、熟的分开用，最好用颜色区分
容器｜生料和熟食用不同的盆、盘
冰箱｜熟食放上层、生料放下层，或者分开冰箱，都要加盖
手｜碰过生肉、生海鲜，洗了手再碰熟食
:::

## 温度和留样
- 热菜要热着上，凉菜、冷饮要冷着放
- 做好的熟食不要在常温下放太久，按门店规定处理
- 冷藏一般在 0–8℃，冷冻一般在零下 18℃ 以下，以设备标示和门店规定为准；每天看温度显示，不对马上报告
- 按门店规定给菜留样：用干净的留样盒装好，贴上日期、餐次、菜名和留样人，放进专用冰箱，份量和保存时间按门店规定

## 过敏原
:::steps 点单时问过敏原
问｜点单时问一句：「请问有没有什么过敏或者不吃的？」
记｜客人说了，写进这道菜的备注或整单备注
说｜严重的过敏，当面再告诉厨房或出品的同事
确认｜不确定菜里有没有，就说不确定，问清楚厨房再答复，不打包票
:::

:::tip 常见的过敏原
花生和其他坚果、鸡蛋、牛奶、鱼虾蟹贝、大豆、小麦等。菜里具体放了什么，以厨房说的为准。
:::

:::ban 不要这样做
- 不要说「没事，一点点不要紧」
- 掉在地上的食物不能再上桌
- 不要用手直接抓直接入口的食物
:::

:::check
客人说对虾过敏，点单时你应该怎么做？
- [ ] 记在心里就行
- [x] 写进备注，并当面告诉厨房
- [ ] 跟客人说「我们的菜都没有虾」
解析：过敏可能很严重。要写进备注，当面告诉厨房；不清楚菜里有没有，问清楚再答复，不能打包票。
:::

## 本课小结
- 有健康证才上岗，生病、手上有伤先报告
- 生熟分开、管好温度、按规定留样
- 点单问过敏原，写进备注并告诉厨房

- [x] 发烧
- [x] 拉肚子

:::question recall skill=过敏原询问 level=3
客人问「这道菜里有没有花生」，你不确定，怎么回答？
答：如实说不确定，请客人稍等，去问清楚厨房再答复；客人有过敏的，写进备注并当面告诉厨房。不能随口说「没有」或「一点点不要紧」。
:::

- [ ] 记在心里

- [ ] 不用记，厨房会知道
- [ ] 让客人自己去跟厨房说
