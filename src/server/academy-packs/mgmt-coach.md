# 课时 key=why min=6：为什么要带教
前台来了一位新同事。你那几天特别忙，把一叠资料塞给他：「先看这个，看完就会了。」第三天客人买单，他手忙脚乱，收款收错了一笔，客人当场不高兴。

资料看了不等于会做。这一课讲带教为什么重要，新人前 30 天怎么带。

## 本课目标
- 学完能说出 70-20-10 学习法则
- 学完能为新人排出前 30 天的带教安排
- 学完知道带教常见的几个误区

## 70-20-10 学习法则
培训行业有个常用的说法：一个人的本事，大约 70% 是在岗位上做出来的，20% 是跟着别人学、听别人反馈学来的，只有 10% 来自上课和看资料。

:::table 70-20-10 在门店里是什么样
比例｜怎么学｜门店里的例子
70%｜在岗位上做｜真的去接待、结账、巡场、上钟
20%｜跟人学、听反馈｜跟着师傅看、做完听师傅点评
10%｜上课、看资料｜在学堂学课件、做测验和每日一练
:::

所以学堂里的课只是开头，**真本事要在岗位上带出来**。带教就是把这 20% 补上，让那 70% 少走弯路。

## 新人前 30 天
:::steps 前 30 天的带教安排（建议，按岗位调整）
第 1 周｜熟悉环境和同事，学安全底线和服务礼仪；跟在师傅身边看
第 2 周｜在师傅看着下动手做，做完马上点评
第 3 周｜能独立做常见的事，师傅在旁边抽查
第 4 周｜独立上岗，按实操检查项在岗考核，签核通过
:::

:::tip 带教带得好，有这些好处
- 新人少出错，客人少投诉
- 新人心里有底，更愿意留下来
- 团队的做法统一，交接班不乱
:::

:::warn 常见的带教误区
- 只给资料不带人
- 只说不做，或者只做不说
- 一次讲太多，新人记不住
- 新人做错了当众批评
:::

:::check

- [x] 在岗位上做

解析：大约 70% 来自在岗实践，20% 来自跟人学和反馈，10% 来自课程。所以带教要让新人真的上手做。
:::

## 本课小结
- 70-20-10：在岗做、跟人学、上课，学堂的课只是开头
- 前 30 天：看、在师傅看着下做、独立做加抽查、在岗考核
- 不要只给资料，不要一次讲太多，不要当众批评

# 课时 key=fourstep min=7：四步带教法
你要教新同事在收银台处理「结果待确认」。你讲了一遍，他点头说懂了。结果第二天网一断，他还是让客人又扫了一次码。

光讲不练，新人很难真正会。四步带教法就是为这个准备的。

## 本课目标
- 学完能说出四步带教法的每一步
- 学完能用门店里的一件事，按四步带一次
- 学完知道新人当着客人做错时怎么处理

## 四步带教法
:::steps 四步带教法
讲给他听｜说清楚做什么、怎么做、为什么这么做，一次只讲一件事
做给他看｜自己示范一遍，边做边说关键的地方
让他做｜请他做一遍，你在旁边看，先不插手
给他反馈｜做完马上说：哪里做得好，哪里要改，怎么改
:::

## 用一件事走一遍
:::table 带新前台处理「结果待确认」
步骤｜师傅怎么做
讲给他听｜「网断了页面拿不到回复，但钱可能已经收了，所以不能让客人再付，要先查回。」
做给他看｜趁客人不多的时候，对着收银台页面指出三个按钮在哪，示范先点「查回结果」，再讲另外两个
让他做｜请他自己处理一笔，从安抚客人开始说
给他反馈｜「你先请客人稍等，这点很好；查不到时你想重开一笔，这不行，要原样重提或确认作废。」
:::

:::tip 带教小技巧
- 每次只教一件事，时间不要太长
- 让新人复述一遍，听他说得对不对
- 重要的步骤让他多做几遍，直到做顺
- 用真实的场景练，不要只在嘴上说
:::

:::scenario 新人当着客人做错了
新同事在收银台给客人结账，把储值和现金的金额分错了，客人看出来了，有点不耐烦。你就在旁边。
- [x] 先上前帮客人把账结对，向客人致歉；客人走后，再私下和新同事一起看哪里错了、怎么改｜做得对。先顾客人，再带新人；私下反馈，新人听得进去。
- [ ] 当着客人说「你怎么又搞错了」｜不妥。当众批评让客人更不舒服，新人也会更紧张、更容易错。
- [ ] 不管，让他自己处理，吃一堑长一智｜不妥。客人已经不耐烦，带教要在旁边兜底，不能让客人承担新人的错。
:::

:::check
四步带教法的正确顺序是？
- [ ] 让他做、讲给他听、做给他看、给他反馈
- [x] 讲给他听、做给他看、让他做、给他反馈
- [ ] 做给他看、给他反馈、讲给他听、让他做
解析：先讲清楚，再示范，然后让新人做，最后马上给反馈。
:::

## 本课小结
- 四步：讲给他听、做给他看、让他做、给他反馈
- 一次教一件事，让新人复述、多练几遍
- 新人当着客人出错：先顾客人，事后私下反馈

# 课时 key=signoff min=6：实操签核怎么签
新同事说：「师傅，我前台接待的实操课还差您签字，您直接帮我签个通过吧，我都会了。」你还没在岗位上看他完整做过一次。

签核是证明「他在岗位上真的会做」，不是帮忙走个过场。

## 本课目标
- 学完知道实操签核是什么、谁能签
- 学完会按步骤在岗签核
- 学完知道签核的几条红线

## 实操签核是什么
学堂里有的课带一个**实操课时**，列着一条条检查项，比如「起身微笑问候」「收款合计等于应收才结清」。新人光看课件、考测验还不够，要由带教在岗位上看着他做一遍，逐项打勾，签「通过」或「再练」。签「通过」这个课时才算完成。

:::table 签核的规矩（默认，以后台设置为准）
事项｜规矩
谁能签｜有「带教签核」权限的人，签本部门的员工；学堂管理员能签全部
不能签谁｜不能给自己签
签什么｜逐项打勾，签「通过」或「再练」
签了以后｜签核记录只追加，不能改、不能删
签了「再练」｜练好以后可以再签
在哪里签｜学堂首页「待我签核」
:::

## 怎么签
:::steps 在岗签核五步
约时间｜挑一个真实的营业时段，告诉新人要考哪一项
看全程｜在旁边看他完整做一遍，不提示、不插手
逐项打勾｜对着检查项，做到的才打勾
签结论｜全部做到签「通过」，有没做到的签「再练」
当面说｜马上告诉他哪里好、哪里要再练、下次什么时候再考
:::

:::ban 签核红线
- 没在岗看过就签「通过」
- 替别人签，或者互相签
- 给自己签
- 怕得罪人就放水
:::

:::warn 签之前看仔细
签核记录不能改，签错了改不回来。拿不准的项，宁可签「再练」，约个时间再看一次。
:::

:::check
签核记录签错了，可以在系统里直接改。
答案：错
解析：签核记录只追加，不能改、不能删。所以签之前要看仔细；签了「再练」的，练好后可以再签。
:::

## 本课小结
- 实操签核：带教在岗看过，逐项打勾，签「通过」或「再练」
- 只签本部门的员工，不能给自己签，记录不能改
- 没看过不签，不代签、不放水，拿不准就签「再练」

# 课时 key=feedback min=6：怎么给反馈
新同事第一次独立巡场回来，你只说了一句：「不行，再练练。」他站在那儿不知道哪里不行，也不知道怎么练，第二天巡场还是老样子。

反馈不是打分，是告诉他下一次怎么做得更好。

## 本课目标
- 学完能用四步给出一个具体的反馈
- 学完能分清好的说法和不好的说法
- 学完能处理新人情绪低落的情况

## 反馈四步
:::steps 反馈四步
先肯定｜先说一件他做得好的、具体的事
具体指出｜说清哪一步、哪个动作没做到，只说事不说人
给改法｜告诉他下次怎么做，最好示范一下
约下次｜约好什么时候再看一次
:::

:::table 一次完整的反馈
步骤｜师傅说的话
先肯定｜「你今天巡场时看到地上有水马上放了提示牌，这个很好。」
具体指出｜「有位客人在躺椅上脸色不太好，你走过去没停下来问一句。」
给改法｜「看到客人脸色不好，停下来问『您还好吗』，不舒服就报值班经理。」
约下次｜「明天晚上我再跟你巡一次。」
:::

## 好说法和不好的说法
:::cards 换个说法
「你怎么这么笨」｜「这一步漏了核对金额，下次按完先看一眼应收」
「说过多少遍了」｜「这一步我们再一起过一遍」
「不行，再练练」｜「问候和指引都好，就差交代结账方式，下次补上这句」
「你看人家某某」｜「上次你做到了，这次哪里卡住了？」
:::

:::ban 反馈的禁忌
- 不当着客人、不当着很多同事批评
- 不翻旧账，只说这一次
- 不对人只对事，不说「你这个人」
- 不只说哪里不好，不给改法
:::

:::check
下面哪句反馈最符合「具体指出」？
- [ ] 「你态度不好。」
- [x] 「客人问路时你没抬头看他，下次先停下手里的活，看着客人回答。」
- [ ] 「你要多用点心。」
- [ ] 「你还差得远。」
解析：具体指出要说清哪一步、哪个动作没做到，新人才知道改哪里。「态度不好」「多用心」太笼统。
:::

## 本课小结
- 反馈四步：先肯定、具体指出、给改法、约下次
- 只说事不说人，不当众批评，不翻旧账
- 不只说「不行」，一定要给改法
