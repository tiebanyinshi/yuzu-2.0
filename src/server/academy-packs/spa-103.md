# 课时 key=caution min=6：不宜泡汤或要先咨询医生的人
周五晚上，一桌客人吃完饭、喝了不少酒，嚷着要去泡热池、蒸桑拿。另一位女客人问你："我怀孕了，温泉池能泡吗？"这两种情况，你都得会应对。

## 本课目标
- 学完能说出不宜泡汤或要先咨询医生的几类情况
- 学完能讲出每一类为什么有风险
- 学完明白我们是提醒和建议，不是看病

## 这几类情况要特别留意
:::table 不宜泡汤或要先咨询医生的情况
情况｜为什么有风险｜我们的建议
酒后｜血管扩张、反应变慢，容易晕倒、滑倒、呛水｜先在休息区喝水休息，酒劲过了再说
空腹或刚吃饱｜空腹容易低血糖头晕；刚吃饱泡热水容易不舒服｜吃点东西再泡；饭后歇一会儿（一般建议 1 小时左右）再泡
高血压、心脏病等没控制好｜高温、冷热交替让心跳、血压变化大｜请先咨询医生，不建议高温和冷热交替
孕期｜高温对孕妇和胎儿都有风险｜请先咨询医生，不建议高温池和蒸房
发烧、身体明显不舒服｜身体本来就虚，再受热更难受｜建议今天先不泡，好好休息
皮肤有伤口、传染性皮肤病｜伤口容易感染，也可能传给别人｜不下公共池，可以淋浴
经期｜卫生和身体两方面的原因｜建议不下公共池，可以淋浴
:::

:::warn 老人和小孩
- 老人：最好有家人陪着，水温不要太高，时间短一些
- 小孩：家长要全程看护，不能让孩子单独下池、单独进蒸房
:::

## 我们是提醒，不是看病
我们不是医生，不判断客人有没有病。我们做三件事：
1. 看到了、听到了，就提醒
2. 说清楚为什么，给一个替代的办法
3. 客人身体有情况，建议「先咨询医生」

:::ban 不能说的话
- 「你这个病不能泡。」（我们不下诊断）
- 「没事，泡泡就好了。」（我们不做保证）
:::

:::check
下面哪些客人，应该建议先咨询医生或今天先别泡？
- [x] 说自己血压高、最近没吃药的客人
- [x] 刚喝了不少酒的客人
- [x] 腿上有一道还没长好的伤口的客人
- [ ] 刚冲完淋、精神很好的年轻客人
解析：血压没控制好的请先咨询医生；酒后先休息；有伤口的不下公共池，可以淋浴。
:::

## 本课小结
- 酒后、空腹或刚吃饱、心脑血管病没控制好、孕期、发烧、皮肤破损或传染性皮肤病、经期，都要特别留意
- 老人有人陪、时间短，小孩家长全程看护
- 我们提醒、说原因、给替代，身体问题请客人先咨询医生

# 课时 key=faint min=7：晕堂
晚上人多，热池边一位中年男客人站起来时晃了一下，扶着池边说眼前发黑、心慌，额头全是冷汗。这就是常说的「晕堂」。你离他最近，接下来几分钟怎么做，非常关键。

## 本课目标
- 学完能说出晕堂的常见原因和先兆
- 学完能按步骤处置晕堂
- 学完知道什么情况必须马上拨打 120

## 什么是晕堂
在浴池、蒸房里待久了，人出现头晕、眼前发黑、心慌、恶心，甚至晕倒，就是常说的「晕堂」。

常见的原因：
- 高温让血管张开，血往皮肤跑，大脑一时供血不够
- 出汗多，身体缺水
- 空腹，血糖低
- 人多、空气闷
- 泡久了猛一下站起来
- 喝了酒

:::cards 晕堂的先兆，记住这几个信号
头｜头晕，眼前发黑、发花
心｜心慌、胸闷
胃｜恶心、想吐
脸｜脸色发白、出冷汗
手脚｜发软、站不稳
:::

## 处置步骤
:::steps 发现晕堂怎么做
扶离高温｜马上扶客人离开热池、蒸房，自己也要站稳，别一起滑倒
躺下或坐下｜让客人平躺，腿可以稍微垫高；不方便躺就坐下、头放低
通风保暖｜移到通风的地方，松开紧的衣物，用浴巾盖好，保暖也护住隐私
小口喝水｜客人清醒、能自己喝，再给温水小口慢慢喝
通知主管｜叫同事帮忙，马上告诉主管，不留客人一个人
观察｜看脸色、呼吸、说话清不清楚，好了再慢慢起来
:::

:::warn 这些情况，马上拨打 120
- 叫不醒、说话不清楚
- 胸口痛、呼吸困难
- 抽搐
- 休息一会儿还是不见好
拨打 120 的同时报告主管，派人到门口接救护车。
:::

:::ban 不要这样做
- 让刚晕过的客人马上站起来走
- 给不清醒的客人喂水，容易呛着
- 一群人围着看，空气更闷
- 用偏方、乱给药
:::

:::check

- [ ] 让他再泡一会儿缓一缓
- [x] 马上扶他离开热池，到通风的地方躺下或坐下
- [ ] 先去前台查他的消费
- [ ] 给他一大杯冰水让他一口喝完
解析：第一步是离开高温，躺下或坐下。清醒了再小口喝温水。
:::

:::check

- [x] 马上拨打 120，同时报告主管，不离开客人
- [ ] 先喂他喝点水
- [ ] 等十几分钟，看会不会自己醒
解析：叫不醒是危险信号，要马上拨打 120。不清醒的人不能喂水，容易呛着。
:::

## 本课小结
- 晕堂多因高温、缺水、空腹、空气闷、起身太快、酒后
- 扶离高温、躺下或坐下、通风保暖、清醒才喝水、通知主管、观察
- 叫不醒、胸痛、呼吸困难、抽搐、不见好，马上拨打 120

# 课时 key=accident min=7：滑倒、烫伤与溺水的预防与处置
浴区地面湿，一位老人拖鞋一滑，坐在了地上；没过多久，另一位客人被淋浴的热水烫红了手背。水多、热多、人光着脚，这就是浴区最容易出意外的原因。预防在前，处置要对。

## 本课目标
- 学完能说出滑倒、烫伤、溺水的预防做法
- 学完能按公认的急救常识做初步处置
- 学完记住：出了事先保证安全，马上报告

## 总原则
:::tip 出了意外，先记这三条
- 先保证自己和客人的安全，再动手
- 马上叫人、报告主管，该打 120 就打
- 事后如实记录经过
:::

## 滑倒
**预防**：地面积水及时刮干，按门店规定放防滑垫；拖地、刮水时摆「小心地滑」的牌子；提醒客人穿拖鞋、慢慢走，老人和小孩更要多留意。

**处置**：
- 先别急着把人拉起来，问清哪里疼、手脚能不能动
- 撞到头、站不起来、怀疑骨折的，不随便搬动，报告主管，拨打 120
- 轻微的，扶到安全的地方坐下休息，告诉主管

## 烫伤
容易烫着的地方：热水龙头、热池出水口、蒸房的加热器、热饮。

:::steps 烫伤急救五个字
冲｜马上用流动的凉水冲，一般冲 15 分钟以上
脱｜一边冲，一边小心脱掉或剪开衣物，粘住皮肤的不硬扯
泡｜还疼得厉害，可以继续用凉水泡
盖｜用干净的毛巾或纱布轻轻盖住
送｜烫得重、面积大、起大泡的，报告主管，送医院
:::

:::ban 烫伤后不要做
- 涂牙膏、酱油、香油
- 挑破水泡
- 直接用冰块敷
:::

## 溺水
**预防**：定时巡池，多看老人、小孩和喝了酒的客人；喝醉的客人不让下池；孩子必须有家长在旁边。

**处置**：
- 大声呼救，让同事拨打 120、报告主管
- 在保证自己安全的前提下，把人托出水面、移到岸上
- 看有没有反应、有没有正常呼吸
- 没有正常呼吸的，由受过急救培训的同事马上做心肺复苏；门店配有自动体外除颤器（AED）的，按培训使用
- 不要花时间「控水」（倒提起来拍背吐水），会耽误抢救

:::check
客人的手被热水烫红了，下面哪种做法对？
- [ ] 马上涂牙膏
- [x] 马上用流动的凉水冲，一般冲 15 分钟以上
- [ ] 把水泡挑破，好得快
解析：烫伤记住「冲、脱、泡、盖、送」，第一步是凉水冲。不涂牙膏、酱油，不挑水泡。
:::

## 本课小结
- 滑倒：勤刮水、摆提示牌、提醒慢走；撞头、疑似骨折不随便搬，拨打 120
- 烫伤：冲、脱、泡、盖、送，不涂牙膏酱油、不挑水泡
- 溺水：勤巡池，看好老人小孩和喝了酒的；救上岸、看呼吸，不控水

# 课时 key=persuade min=6：怎么礼貌地劝阻客人
一位喝得满脸通红的客人拿着浴巾往蒸房走，嘴里说"出出汗就醒了"。你拦也不是，不拦也不是。劝阻是门技术活：话说对了，客人会感谢你；说错了，好心也会变成冲突。

## 本课目标
- 学完能用「关心、原因、替代、感谢」四步劝阻客人
- 学完知道哪些话不能说、哪些事不能做
- 学完知道客人坚持时怎么办

## 劝阻四步
:::steps 劝阻四步
称呼加关心｜「先生您好，看您……」，先表达关心
说清原因｜为客人身体着想，说出具体的风险
给个替代｜给客人一个能做的选择，比如先去休息区喝杯温水
感谢配合｜「谢谢您理解，有需要随时叫我。」
:::

## 几句常用的话
:::cards 常用话术（点一下翻面）
酒后要进蒸房｜「先生，看您刚喝了点酒，这会儿蒸房温度高，容易头晕。您先到休息区喝杯温水歇一歇，过一会儿再来，舒服些。」
客人说自己血压高｜「血压高的话，高温池和蒸房对心脏负担大一些。要泡的话选温一点的池，时间短一些，最好也听听医生的意见。」
客人说自己怀孕了｜「孕期的话，高温池和蒸房一般建议先听医生的意见。您到休息区歇着，我给您倒杯温水。」
家长走开、孩子在池边｜「您好，小朋友在池边，麻烦您在旁边看着点，地滑，安全第一。」
:::

:::ban 不能这样说、这样做
- 「你喝醉了，不能进！」（当众下结论，伤面子）
- 「你有病就别来泡。」
- 「出了事别怪我们。」（像在威胁）
- 拉扯客人
:::

## 客人坚持怎么办
- 不争吵，语气保持平和
- 马上请主管来处理
- 继续留意这位客人，必要时安排人在附近看着
- 明显危险的（比如醉得站不稳），要坚决劝止，等主管到场

:::scenario 酒后要进蒸房
一位客人刚喝完酒，脸通红，脚步有点晃，拿着浴巾往干蒸房走，说「出出汗就醒酒了」。你就在门口，怎么做？
- [ ] 让他进去，客人的事客人自己定｜酒后进高温蒸房很容易晕倒，出了事后果很重。看到了就要劝。
- [ ] 大声说「你喝醉了，不能进！」｜理由没错，但当众下结论伤客人面子，容易吵起来。
- [x] 走近轻声说「先生，看您刚喝了点酒，蒸房温度高，容易头晕，先到休息区喝杯温水歇一会儿吧」，客人坚持就请主管来｜关心在前、原因说清、给了替代，客人坚持再请主管，这是对的做法。
:::

:::check
劝阻客人时，第一句话最好怎么开口？
- [x] 先称呼，再表达关心
- [ ] 直接说「不行」
- [ ] 先讲门店的规定和后果
解析：先称呼、先关心，客人感到被尊重，后面的原因和建议才听得进去。
:::

## 本课小结
- 劝阻四步：称呼加关心、说清原因、给个替代、感谢配合
- 不当众下结论、不说「你有病」、不威胁、不拉扯
- 客人坚持就请主管，明显危险的坚决劝止

- [x] 不随便搬动，报告主管，拨打 120
- [ ] 马上把他拉起来，走两步试试
- [ ] 让他自己慢慢爬起来
- [ ] 先把地面拖干再说
解析：怀疑骨折、撞到头的，乱搬可能加重伤情。先问清情况，不随便搬动，报告主管并拨打 120。

:::question single skill=意外急救 level=3
你发现池子里有人脸朝下不动，下面哪种做法对？
- [x] 大声呼救，让同事拨打 120、报告主管；在保证自己安全的前提下把人救上岸，看有没有反应和呼吸
- [ ] 先把人倒提起来控水
- [ ] 自己跑去找主管，等主管来了再救
- [ ] 先拍照留证据
解析：溺水救人要快：呼救、拨打 120、救上岸、看呼吸，没有正常呼吸的由受过培训的人做心肺复苏。不要花时间控水。
:::

:::question multi skill=意外急救 level=2
预防滑倒，下面哪些做法对？
- [x] 地面积水及时刮干
- [x] 拖地时摆「小心地滑」的牌子
- [x] 提醒客人穿拖鞋、慢慢走
- [ ] 让客人光着脚走，更防滑

:::

:::question single skill=礼貌劝阻 level=3
一位女客人说自己怀孕了，想去泡最热的池子。你怎么说最合适？
- [x] 「孕期的话，高温池一般建议先听医生的意见。您到休息区歇着，我给您倒杯温水。」
- [ ] 「孕妇不能来这儿。」
- [ ] 「没事，泡吧。」
- [ ] 「出了事我们不负责。」
解析：关心在前、说清原因、给个替代。不赶客人、不放任不管，也不说像威胁的话。
:::
