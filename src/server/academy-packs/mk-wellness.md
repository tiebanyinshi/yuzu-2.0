# 课时 key=clock min=8：钟房规则
你刚上牌，排在第三位。前面两位派出去了，接着系统念出你的工号和花名，叫你到某某房上钟。做完回来，你发现自己排到了最后。这是为什么？弄懂钟房规则，才知道自己什么时候上钟、为什么排在这里。

## 本课目标
- 学完能说清上牌、轮钟、点钟、扩钟、加钟这几种叫法
- 学完能说出暂离、下牌、休假、停牌对排位的影响
- 学完能听到叫号后按规矩上钟、下钟

## 先认识钟房
钟房负责派钟、记上钟和下钟、管排位。这些操作在门店系统的「钟房」里做，技师按叫号和钟房的安排做事。排位的具体规则（比如什么时候排到队尾）以门店的钟房规则设置为准，下面讲的是门店现在的默认做法。

## 排位与上钟方式
:::cards 几种叫法，翻一翻
上牌｜到岗后在钟房上牌，进入轮钟排队，按上牌的先后排
轮钟｜按排位轮流派钟。派到你以后，你的牌排到队尾（派钟时还是下钟时排尾，看钟房规则）
点钟｜客人在店里点名要你。默认点钟下钟后排到队尾
扩钟｜客人在店外跟你约好，再到店来做。派钟、下钟都不排尾，原来排第几，做完还是第几
加钟｜客人做完想让你接着做，在原来的钟单上加，不另派一张新钟
:::

- 排位按工种分开排：排第几，只在同一工种里数。
- 轮钟要跳过排在前面的技师时，钟房必须写原因（比如客人要女技师、要力度重的），被跳过的人不动牌。
- 客人预约了你，从预约开始前一段时间（门店默认 30 分钟）起，你就锁给这位客人，和预约时间撞上的钟不会再派给你。

:::tip 给自己的客人加钟
客人想继续让你做，走「加钟」，不要另派一张点钟。加钟记在原来的钟单上，按加钟那时的价目表计价。
:::

## 一个钟怎么走
:::steps 从派钟到下钟
派钟｜钟房按排位，或按客人点名派钟，同时叫号
叫号｜系统念「请某号（工号和花名），到某某房上钟」；还不知道房间时念「准备上钟」
上钟｜到房间开始服务，钟房记上钟、开始计时；快到钟时系统会提醒（门店默认提前 5 分钟）
下钟｜服务做完，钟房记下钟；客人结账时还在钟上的，按结账的时间一起下钟
:::

:::warn 叫到你要马上去
听到叫号马上去。叫钟不到、拒钟的，钟房可以把你排到队尾，并写明原因。
:::

## 离开队列的几种情况
:::table 离开队列与回来
情况｜什么意思｜对排位的影响
暂离｜吃饭、上厕所这类短时间离开｜离开队列，回牌后排到队尾
下牌｜下班或离店｜离开队列，下次要重新上牌
休假｜当天休假，或者走休假单休几天｜休假期间不进排位；休假单休完自动上牌，排到队尾
停牌｜因故暂停接钟，要写原因｜一直停到复牌；复牌后要重新上牌才进队列
:::

钟房里技师的状态有：空闲、待中（已派待上）、上钟、已带、暂离、休假、未上牌，另外还有停牌。「已带」是今天已经做过钟、现在在岗、手上没钟，还在排位里等下一钟。

## 退钟、转钟、换项目
- **退钟**：这一钟作废，技师回到派钟前的位置；连续被退 3 次排到队尾（门店默认）
- **转钟**：客人要换技师，钟房转给另一位，原来的技师按退钟的规矩回位
- **换项目**：上钟后 15 分钟内可以换（门店默认），再晚要先退钟再重新派

:::check

- [ ] 点钟

解析：在店外约好、到店来做的是扩钟。扩钟派钟、下钟都不排尾，做完还在原来的排位。点钟是客人在店里点名。
:::

:::check

:::

## 本课小结
- 轮钟按排位轮流派，点钟是店里点名，扩钟是店外约好、排位不动
- 加钟在原钟单上加，给自己的客人加钟不要另派点钟
- 暂离、下牌、休假、停牌都会离开队列，回来按规则排

# 课时 key=service min=6：一次完整的服务流程
叫号叫到你，客人是第一次来做全身按摩。他一进门就问：「会不会很疼？我腰不太好。」接下来你说的每一句话，都决定了客人这一钟放不放心。

## 本课目标
- 学完能按五步完成一次服务：迎宾、确认、询问、沟通、结束
- 学完能在服务前问清客人的身体状况和力度
- 学完能在结束时提醒客人，并引导他去下一处

## 五个步骤
:::steps 一次完整的服务
迎宾｜按时到房间，敲门再进，微笑问好，报工号或花名
确认项目与时长｜核对项目和时长，和钟单一致；有疑问请钟房确认，不自己改
问身体状况与力度｜问有没有不舒服、受过伤、哪里不能按，喜欢轻一点还是重一点
服务中沟通｜开始时力度轻一些，再慢慢调；中途问一两次力度、温度合不合适
结束提醒与引导｜提前说快结束了，提醒慢慢起身、喝点温水、带好随身物品，引导去下一处
:::

## 开口怎么说
:::table 常用说法
时候｜可以这样说
进门｜「您好，我是某号，今天由我为您服务。」
确认｜「您今天做的是这个项目，时长是这些，对吗？」
问身体｜「您最近身体有没有哪里不舒服，或者受过伤、做过手术？」
问力度｜「这个力度可以吗？重了轻了您随时告诉我。」
结束｜「今天的服务快结束了，您慢慢起身，别着急。」
:::

## 为什么一定要问身体状况
有的客人身体情况不适合按摩，或者某些部位不能碰。问清楚，是保护客人，也是保护你自己。

客人说有发热、皮肤破损、怀孕、刚喝过酒、刚吃饱，或者有严重疾病的，先停下，告诉钟房或主管，按门店规定处理。拿不准的，建议客人先咨询医生。

:::warn 项目和时长以钟单为准
客人想改项目、加时间，你不能自己答应。请钟房处理：加钟在原钟单上加，换项目由钟房按规则换。
:::

## 结束以后
- 提醒客人带好手机、手牌等随身物品
- 客人想加钟，告诉钟房按「加钟」办
- 客人不满意，先道歉、听清楚，再报告主管，不跟客人争
- 整理房间、换好布草，等下一钟

:::check
服务开始前，下面哪一项一定要先问客人？
- [ ] 客人在哪里工作
- [x] 身体有没有不舒服、受伤或不能按的地方
- [ ] 客人一个月来几次
解析：问身体状况，是为了判断能不能做、哪里不能按。和服务无关的私事不要问。
:::

## 本课小结
- 五步：迎宾、确认、询问、沟通、结束
- 项目和时长以钟单为准，要改请钟房
- 力度先轻后重，随时问客人的感受

# 课时 key=boundary min=7：禁忌与服务边界
一位客人边按边说：「你按得这么好，能不能帮我把腰间盘突出治好？」另一位客人提出了超出项目范围的要求。遇到这些情况，怎么说、怎么做，就是服务的边界。

## 本课目标
- 学完能说出哪些情况不宜按摩
- 学完能得体地拒绝医疗承诺和不当要求
- 学完能保护客人隐私，守好男女宾规范

## 哪些情况不宜按摩
:::warn 先停下，按门店规定处理
- 发热、感冒发烧
- 皮肤有破损、伤口、皮疹、烫伤
- 怀孕
- 刚喝过酒，或刚吃饱
- 有严重的心脏病、高血压控制不好、出血性疾病，或刚做过手术
- 骨折、扭伤还没好的部位
:::

拿不准的，不要自己判断。告诉钟房或主管，请客人先咨询医生。

## 不做医疗承诺
按摩能让人放松、舒缓，但它不是治疗。你可以介绍项目做什么、感受怎么样，不能说能治什么病。

:::table 不要说和可以说
不要说｜可以说
「这个能治好你的腰」｜「这个项目主要是放松背部，身体有问题建议先看医生」
「按几次就排毒了」｜「做完很多客人觉得比较放松」
「你这是湿气重，要多做」｜「您觉得舒服可以再来，身体的问题建议问问医生」
:::

## 绝不做的事
:::ban 红线
- 不做任何不当服务，不说不当的话，不做不当的动作
- 不碰客人的私密部位
- 费用按门店价目表、走门店的账，不私下收钱
- 客人提出不当要求：礼貌而坚决地拒绝，停止服务，马上报告主管
:::

## 保护隐私
- 客人的身体情况、说过的话、消费情况，不外传、不议论
- 服务时用毛巾或浴巾盖好客人不按的部位
- 不拍照、不录像，服务时不打电话、不玩手机
- 进门先敲门，同事要进来先打招呼

## 男女宾规范
- 按门店规定安排技师；客人对技师性别有要求的，尊重客人，请钟房安排
- 进出男宾区、女宾区按门店规定，不随意进入异性区域
- 服务全程举止得体，保持专业距离

:::scenario 客人要你「治病」
做背部按摩时，客人说：「我腰椎不好，你多按按，能给我按好吧？」你怎么回答？
- [x] 「我帮您把背部放松一下，力度您随时告诉我。腰椎的问题建议您去医院看看。」｜对。说清能做什么，不承诺治疗，再建议看医生，既诚实又让客人放心。
- [ ] 「放心，多做几次保证给您按好。」｜不对。这是医疗承诺。按摩不是治疗，这样说会误导客人，也会给门店带来麻烦。
- [ ] 「腰椎不好就别做了。」｜不够好。可以先问清情况，告诉钟房或主管；拿不准的请客人先咨询医生，不用一口回绝。
:::

:::check
客人提出超出项目范围的不当要求，你应该怎么做？
- [ ] 看是不是熟客再决定
- [x] 礼貌而坚决地拒绝，停止服务，报告主管
- [ ] 不说话，假装没听见继续做
解析：不当服务是红线，任何情况都不做。拒绝时语气礼貌、态度坚决，并马上报告主管，保护自己也保护门店。

## 本课小结
- 发热、皮肤破损、孕期、酒后饱餐后、严重疾病等，先停下按规定处理
- 只说放松、舒缓，不做医疗承诺
- 不当服务是红线，客人隐私要保护

# 课时 key=hygiene min=5：卫生与自我保护
连着做了三个钟，你的手腕有点酸。下一位客人已经在房间里等，你顺手擦擦手就要进去。手洗没洗、姿势对不对，关系到客人的卫生，也关系到你能不能长久地做这一行。

## 本课目标
- 学完能做好手部卫生和个人卫生
- 学完能做到布草和用品一客一换
- 学完能用正确的姿势发力，保护好自己

## 手部与个人卫生
:::steps 每一钟前后
剪指甲｜指甲剪短磨平，不留长指甲、不做美甲，免得划伤客人
摘饰物｜服务时摘下戒指、手链、手表
洗手｜服务前、服务后都用洗手液认真洗，洗到手心、手背、指缝、指尖和手腕
擦干｜用干净的纸巾或毛巾擦干
:::

## 布草和用品
- 床单、毛巾、按摩巾一客一换，用过的放进回收筐
- 按摩油、精油用门店提供的，看清有没有过期，用完盖好
- 用具按门店规定清洁消毒后再用
- 工服保持干净，有汗渍、污渍及时换

:::warn 自己身体不舒服时
感冒发烧、手上有伤口或皮肤病的，先告诉主管，不要硬撑着上钟。
:::

## 职业防护
:::tip 发力的小窍门
- 用身体的重量带动，不只靠手指和手腕硬按
- 调好按摩床的高度，腰背尽量挺直，不长时间弯腰
- 两只手交替用力，一钟做完活动一下手腕和肩膀
- 每天下班前拉伸一下；手腕、腰背长期疼，要及时看医生
:::

:::ban 遇到不安全的情况
- 客人有骚扰、威胁等行为，马上停止服务、离开房间，报告主管
- 不要一个人忍着，门店会保护你
:::

:::check

解析：长指甲容易划伤客人，也容易藏脏东西。洗手、摘饰物、有伤口先报告，都是为了客人和自己的安全。
:::

## 本课小结
- 指甲剪短、饰物摘下、服务前后洗手
- 布草一客一换，用品按规定清洁
- 用身体重量发力，遇到不安全的情况马上离开并报告

# 实操 key=practice：一次完整的服务
- 接到叫号后按时到房间，敲门再进，问好并报工号或花名
- 核对项目和时长，与钟单一致
- 询问客人身体状况：有没有不适、伤处、不能按的部位
- 询问力度偏好，开始时力度轻一些
- 服务前洗手，指甲剪短，饰物摘下
- 用毛巾盖好客人不按的部位
- 服务中至少问一次力度和温度是否合适
- 介绍项目只说放松、舒缓，不做医疗承诺
- 提前提醒客人服务快结束
- 提醒客人慢慢起身、带好随身物品，并引导去下一处
- 客人想加钟时，说出要请钟房按「加钟」办理
- 结束后整理房间、更换布草

- [ ] 排到第一
- [ ] 要重新上牌
解析：扩钟派钟、下钟都不排尾，上牌时排第几，做完还是第几。

:::question judge skill=钟房规则 level=1
