# 课时 key=departments min=6：店里的一天与各部门分工
你在休息区巡场，一位客人拦住你：「我房间空调不凉，水龙头也不太出热水。」你是新人，不知道这事该找谁，只好说「我帮您问问」，然后在走廊里转了好几圈。

知道每个部门管什么，客人的事才能一次交到对的人手上。

## 本课目标
- 学完能说出门店主要部门各管什么
- 学完遇到客人的需求，知道该交给哪个部门
- 学完能做到「首问负责」

## 各部门管什么
:::table 部门分工（以门店实际分工为准）
部门｜主要做什么
前厅部｜迎宾、发手牌、收银结账、会员充值、登记客诉
男宾部｜男宾浴区的服务、卫生与安全
女宾部｜女宾浴区的服务、卫生与安全
保健部｜技师按摩等服务，钟房排钟、派钟
康美部｜康美类项目服务，也能在水吧、果吧为客人点单
餐饮部｜餐厅、水吧、果吧的点单和送餐服务
出品部｜后厨，按单做菜、做饮品
娱乐部｜娱乐区域的服务
工程部｜水、电、空调、设备的维修保养
财务部｜对账、核对日结、付款
人力行政部｜招聘、考勤排班、工资条、培训
:::

另外还有总经办（门店经营管理）、外联部（物资与采购）、大客户部（大客户与协议单位）。

## 一天里各部门在忙什么
:::steps 跟着营业日走（时间以门店安排为准）
开门｜前厅开始发牌，浴区、餐饮、钟房做好准备
午后｜客人多起来，技师上钟，浴区、休息区巡场
傍晚｜餐饮、出品最忙，送餐要核对手牌或房号
晚上｜清台、清房，房态中心看哪些房待清、维修
深夜｜收银交班，值班经理和财务核对日结
:::

## 首问负责：不归我管也要接住
:::tip 三步接住客人的事
- 先回应：「好的，我马上帮您处理。」
- 再转交：用对讲机或当面交给负责的部门
- 后告知：告诉客人大概多久有人来，回头确认办好了没有
:::

:::cards 遇事找谁
空调不凉、水不热、灯不亮｜工程部；先报值班经理或本部门负责人
想加钟、换技师｜钟房（保健部）
想吃点东西、喝点饮品｜餐饮部，在点单页挂到客人手牌上
结账、充值、换手牌｜前台（前厅部）
投诉、客人情绪激动｜值班经理
:::

:::check
客人说房间的灯不亮，你应该先交给哪个部门处理？
- [ ] 财务部
- [x] 工程部
- [ ] 人力行政部
- [ ] 出品部
解析：水、电、空调、设备的维修归工程部。按门店规定，可以先报值班经理或本部门负责人，再由他们通知工程部。
:::

## 本课小结
- 前厅管接待收银，男宾部、女宾部管浴区，保健部管技师和钟房，工程部管维修
- 客人的事找对部门，一次交到位
- 首问负责：先回应、再转交、后告知

# 课时 key=tags min=7：手牌与消费
女宾浴区，一位客人着急地跑来找你：「我的手牌不见了！柜子打不开，里面还有手机！」她越说越急。

手牌是客人在店里最重要的东西。这一课讲手牌怎么用，丢了、坏了怎么办。

## 本课目标
- 学完能说清手牌是什么、消费怎么记
- 学完知道丢牌、换牌的处理办法
- 学完知道手牌押金是怎么回事

## 手牌是什么
手牌是客人在店的**消费凭证**，也对应着客人的柜子。客人进门，前台发一张手牌；客人在店里点的项目、吃的喝的、做的按摩，都挂在这张手牌上（系统里叫「挂账」）。客人离店时，到收银台按手牌统一结账。门票一般按在店时长算，结账时一起算。

:::steps 一次完整的消费
发牌｜客人进门，前台发手牌，同行的客人绑在一起
消费｜各部门把项目挂到这张手牌上
买单｜客人离店，到收银台按手牌结账
交还｜结清以后手牌空出来，可以发给下一位客人
:::

## 丢了、坏了怎么办
:::table 换牌的几种情况
情况｜前台怎么处理
手牌丢失｜换新牌，锁定原手牌，按门店规定收丢牌赔偿
柜锁故障｜换新牌，原手牌不锁
手牌损坏｜换新牌，原手牌不锁
客人要求换柜｜换新牌，原手牌不锁
:::

为什么手牌丢了要**锁原牌**？因为原手牌上挂着客人的账。万一别人捡到拿去消费，就记到了这位客人头上。锁上以后，这张牌就不能再用了。

## 手牌押金
客人要外出留牌、去其他区域，或者借用物品时，前台可能会收一笔**手牌押金**，金额按门店规定。押金可以用现金、微信、支付宝、银行卡收，也可以从这张手牌上会员的储值里扣。客人回来可以一键退，结账时也可以直接抵扣。押金不算营业额。

:::ban 不能做
- 不能把客人的手牌借给别人用
- 不能把项目挂到别人的手牌上
- 捡到手牌不能自己留着，马上交前台
:::

:::scenario 客人手牌丢了
女宾浴区一位客人说手牌丢了，柜子打不开，手机还在柜子里，她很着急。
- [x] 先安抚客人，陪她回忆可能落在哪里，同时马上通知前台办理换牌、锁定原手牌｜做得对。先稳住客人，尽快锁住原手牌防止被冒用，再按门店规定开柜、换牌。
- [ ] 让客人自己去前台说｜不妥。客人穿着浴衣、很着急，应该你来联系前台，不要让她跑来跑去。
- [ ] 找把工具帮她把柜子撬开｜不行。开柜要按门店规定由前台或主管核对身份后处理，不能自己撬柜。
:::

:::check
客人的手牌丢了，前台换牌时为什么要锁定原手牌？
- [ ] 为了多收一笔钱
- [x] 防止别人捡到后用原手牌消费，记到这位客人账上
- [ ] 因为原手牌坏了
- [ ] 系统规定所有换牌都要锁
解析：原手牌上挂着客人的账，锁上以后就不能再用了。柜锁故障、手牌损坏、客人要求换柜这几种情况，原手牌不用锁。
:::

## 本课小结
- 手牌是消费凭证，项目都挂在手牌上，离店到收银台统一结账
- 手牌丢失才锁原牌并收赔偿，其他换牌原因不锁
- 手牌押金按门店规定收，可一键退、可结账抵扣，不算营业额

# 课时 key=member min=6：会员与储值常识
一位会员客人在休息区叫住你：「小伙子，我卡里还剩多少钱？剩下的能不能退点现金给我？」你不知道怎么回答，又怕说错。

会员的钱是客人存在店里的钱，每一分都要清清楚楚。

## 本课目标
- 学完能说清储值是什么、怎么扣
- 学完知道哪些事员工不能做主
- 学完遇到会员问题，知道交给谁

## 储值是什么
会员在店里充值，钱存进**会员钱包**，就是「储值」。储值里有两部分：自己充的**本金**，和店里按规则送的**赠金**。会员消费时，系统按规则从钱包里扣（一般先扣本金、再扣赠金，以门店规则为准），每一笔都有记录，随时能查。

会员还有**等级**。系统里用 L0 到 L6 这样的档阶表示，等级不同，能享受的权益也不同。具体有哪些档位、各有什么权益，以门店的会员规则为准。前台和收银台刷手牌时，能看到客人的档阶和余额。

国家有专门管预付消费的规定，比如《单用途商业预付卡管理办法（试行）》，管的就是储值卡这类先付钱、后消费的经营；《消费者权益保护法》保护客人知情、公平交易这些权利。所以储值的事，一定按规定、按系统来办。

## 员工能做什么、不能做什么
:::table 会员的事怎么接
客人问｜你怎么做
还剩多少钱、什么等级｜请前台刷手牌或查会员帮他看
有什么权益、能不能打折｜请前台查，以门店会员规则为准
能不能退储值、退现金｜不要答应，交给前台主管或值班经理按规定办
钱扣得不对、有疑问｜记下情况，交给前台主管或值班经理核对
:::

:::ban 绝对不能做
- 不能自己答应给客人退储值、退现金
- 不能私下帮客人把余额转给别人
- 不能用客人的会员身份给别人消费
- 不能把会员的手机号、余额告诉别人
:::

:::tip 一句话应对
「您的余额和权益，前台一查就清楚，我带您过去 / 我请前台同事帮您看一下。」
:::

:::check
会员客人要求把储值退一部分现金给他，你应该怎么做？
- [ ] 余额够就直接答应
- [ ] 告诉客人「储值一律不能退」
- [x] 不自己做主，请前台主管或值班经理按规定办理
- [ ] 让客人找收银员私下处理
解析：退储值涉及会员钱包和国家对预付消费的规定，员工不能自己答应，也不能随口说「一律不能退」，要交给前台主管或值班经理按规定办。
:::

## 本课小结
- 储值就是会员钱包，有本金和赠金，按规则扣，每笔有记录
- 等级、权益以门店会员规则为准，前台刷手牌能查
- 退储值、退现金、扣款有疑问，都交给前台主管或值班经理

# 课时 key=safety min=7：安全卫生底线与遇事上报
晚上你在休息区巡场，看见一位客人脸色发白，靠在躺椅上一动不动，身边没有同伴。你叫了他一声，他只是哼了一下。

这时候每一分钟都很重要。这一课讲安全卫生的底线，和遇到突发情况先做什么、报给谁。

## 本课目标
- 学完能说出安全卫生的几条底线
- 学完遇到客人不适、打架、漏水漏电、可疑物品，知道先做什么
- 学完会按「四要素」上报

## 安全卫生的底线
- 公共用品按规定一客一换、清洗消毒，脏的、破的不给客人用。
- 地面有水马上处理，湿滑处放好提示牌。
- 酒后、明显不舒服的客人，劝他先别泡汤、别进蒸房。
- 消防通道、安全出口不堆东西，灭火器不挪位置。

这些要求来自《公共场所卫生管理条例》、GB 37487-2019《公共场所卫生管理规范》和《消防法》等，具体做法以门店规定为准。

## 遇到突发情况
:::table 先做什么、报给谁
情况｜先做什么｜报给谁
客人不适、晕倒｜扶到安全处坐下或平躺，不离开他，不乱喂药｜马上报值班经理，严重时拨打 120
客人争吵打架｜不参与，不动手，先让周围客人离开｜马上报值班经理，必要时报警
漏水、漏电、冒烟｜自己远离，拦住客人，不碰电线电器｜报工程部和值班经理，着火拨打 119
可疑物品、可疑的人｜不碰、不挪，记住位置和特征｜报值班经理
:::

:::warn 记住先后
先保证人的安全，同时尽快上报。不要一个人硬扛，也不要等「搞清楚了再报」。
:::

## 上报的四要素
:::steps 用对讲机或当面说清这四样
在哪里｜例如「女宾休息区靠窗那一排」
什么事｜例如「一位客人脸色发白，叫不太醒」
现在怎样｜例如「我在他身边，他还有呼吸」
我做了什么｜例如「已经让他平躺，请值班经理马上过来」
:::

:::ban 不能做
- 不隐瞒、不拖延，出了事不怕说
- 不在客人面前慌张大喊
- 不私下处理纠纷、不和客人争执
- 不擅自给客人吃药
:::

:::check
发现客人晕倒，下面哪种做法是对的？
- [ ] 先去找同事商量，再回来看
- [ ] 给客人喂点自己带的药
- [x] 留在客人身边，让他平躺，同时马上报值班经理，严重时拨打 120
- [ ] 拍照发工作群，等主管回复
解析：客人不适要先确保他的安全，人不离开，同时马上上报；严重时直接拨打 120。不能擅自喂药。
:::

## 本课小结
- 底线：用品一客一换、地面防滑、劝阻酒后泡汤、通道不堵
- 突发情况先保人安全，同时报值班经理；不适、漏电、着火分别想到 120、工程部、119
- 上报说清：在哪里、什么事、现在怎样、我做了什么

你发现男宾浴区一个插座在冒烟，旁边有客人在淋浴。你应该先做什么？
- [ ] 拿湿毛巾去盖住插座
- [ ] 自己去拔插头
- [x] 让附近的客人离开，自己不碰电器，马上报工程部和值班经理，着火时拨打 119
- [ ] 继续巡场，等交班时再说
解析：漏电冒烟先保证人的安全：拦住客人、自己远离、不碰电器，同时马上上报。用湿毛巾或手去碰都可能触电。
:::

:::question single skill=安全上报 level=3
两位客人在休息区吵起来，其中一个推了另一个。你应该？
- [ ] 上去拉开，必要时动手制止
- [ ] 劝其中一方忍一忍
- [x] 不参与、不动手，先请周围客人离开，马上报值班经理，必要时报警
- [ ] 等他们吵完再处理
解析：遇到争吵打架，员工不参与、不动手，先保护其他客人和自己，马上报值班经理，情况严重时报警。
:::

:::question recall skill=安全上报 level=3
你在休息区发现一位客人脸色发白、叫不太醒，身边没人。说出你要做的事。
答：留在他身边，让他平躺或扶到安全处；用对讲机马上报值班经理，说清在哪里、什么事、现在怎样、我做了什么；情况严重时直接拨打 120；不擅自喂药。
:::
