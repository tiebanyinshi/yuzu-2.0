# 课时 key=journey min=6：客人的一天
一位客人下午到店，泡汤、蒸房、按摩、吃饭、睡一觉，晚上才走。他这一天要经过前台、浴区、保健、餐饮好几个部门，和十几位员工打交道。哪一站让他不舒服，他记住的都是"这家店"。

## 本课目标
- 学完能说出客人在店里的一天要经过哪几站
- 学完能说出每一站客人最在意什么
- 学完明白开头和结尾为什么特别重要

## 客人的一天
:::steps 客人旅程七站
到店｜门口迎接、前台发手牌，第一印象在这里
更衣｜找柜子、换拖鞋浴衣，最怕找不到、等太久
泡汤｜池水干净、温度合适、地面不滑
休息｜有地方坐、有水喝、安静
按摩｜技师准时、手法用心、力度合适
餐饮｜上菜快、饭菜热、口味对，挂在手牌上一起结
离店｜结账快、账目清楚、有人送别
:::

## 每一站的关键时刻
服务行业常说「关键时刻」：客人和我们接触的那短短几十秒，就决定了他对整家店的看法。

:::table 每一站，客人在想什么
一站｜客人心里想｜我们的关键动作
到店｜「有人理我吗？」｜三米内微笑，主动问候
更衣｜「柜子在哪？」｜主动指引，带一段路
泡汤｜「干净吗？安全吗？」｜勤巡池、勤刮水、及时补用品
休息｜「能好好歇会儿吗？」｜保持安静，主动送水
按摩｜「技师靠谱吗？」｜准时到，先问力度和哪里不舒服
餐饮｜「要等多久？」｜告诉客人大概时间，慢了主动说明
离店｜「账对不对？」｜账目说清楚，道一声「慢走，欢迎再来」
:::

## 开头和结尾最要紧
心理学上有个说法：人回想一段经历，印象最深的是**最好或最差的那一刻**，和**最后那一刻**。所以：
- 到店的第一句问候、离店的最后一声送别，一定要做好
- 中间哪一站出了问题，要在客人走之前补回来

:::tip 一句话记住
客人的一天是一条线，我们每个人都是线上的一个点。
:::

:::check
按「开头和结尾最要紧」的说法，下面哪个时刻特别要做好？
- [ ] 客人在池里泡着的时候
- [x] 客人离店结账、送别的时候
- [ ] 客人在更衣室换衣服的时候
解析：人对一段经历印象最深的是最好或最差的一刻和最后一刻，离店是最后一站，一定要做好。
:::

## 本课小结
- 客人的一天：到店、更衣、泡汤、休息、按摩、餐饮、离店
- 每一站都有关键时刻，几十秒就能决定客人的印象
- 开头和结尾最要紧，中间出了问题要在离店前补回来

# 课时 key=details min=6：关键时刻与细节
一位老会员上次来说过：按摩喜欢轻一点，吃饭不要香菜。这次他刷手牌点餐，服务员就问："还是不放香菜对吧？"客人笑了："你们还记得啊。"让客人有这种感觉，靠的是细节，也靠系统帮忙。

## 本课目标
- 学完能做到「三米微笑、一米问候」
- 学完知道怎么让系统记下、在哪里看到客人的偏好
- 学完能在服务中多走「主动一步」

## 三米微笑，一米问候
:::steps 三米一米
三米｜客人走到三米左右，看着客人，微笑
一米｜走到一米左右，主动问候：「您好，欢迎光临。」
称呼｜知道姓的叫「X 先生」「X 女士」，比「喂」「哎」亲切得多
:::

## 记住客人的偏好：系统帮你记
柚子系统里，客人的偏好可以记下来，**全店刷手牌的地方都能看到**：
- 前台在客人卡上「填偏好」，默认三格：**忌口、按摩力度、其他**（门店可以在后台改）
- **会员的偏好记在会员身上，下次来自动带出**；散客的只记这一次
- 点单页找到客人后、钟房派钟填了手牌后、房态中心的房间详情里，都会显示这位客人的类别、偏好和备注
- 能填偏好的，是有发牌或结账权限的同事；结了账就不能再改

:::tip 偏好怎么用
- 客人跟你说了偏好（不吃辣、按摩要轻），告诉前台记上
- 点单、派钟、进房前，先看一眼这一条
- 照着做，再自然地确认一句：「还是不要香菜对吧？」
:::

:::warn 记什么、不记什么
- 只记客人告诉我们的、对服务有用的事
- 不记客人的隐私，不写评价客人的话（比如「难伺候」）
- 不当着别人的面大声念客人的偏好
:::

## 主动一步
比客人想到的早一步：
- 客人刚从蒸房出来，递上一杯温水
- 客人四处张望，主动问「您找什么？我带您去」
- 客人说明天要早起，提醒前台或客房的同事
- 客人带着孩子，提醒地滑，帮着拿东西

:::check
一位会员上次说过按摩喜欢轻一点。这次你在钟房给他派钟，怎么做最好？
- [ ] 不用管，技师自己会问
- [x] 看系统里显示的偏好，提前告诉技师「这位客人喜欢轻一点」
- [ ] 让客人再跟前台说一遍
解析：会员的偏好会自动带出，派钟时就能看到。提前告诉技师，客人不用再说一遍，这就是细节。
:::

## 本课小结
- 三米微笑、一米问候，能叫出称呼更好
- 偏好请前台记进系统，会员的下次自动带出，全店刷手牌都能看到
- 主动一步：比客人想到的早一点

# 课时 key=complaint min=7：客诉处理
一位客人气冲冲地走到前台："我点的饭等了快一个小时还没上！你们怎么搞的？"周围的客人都看了过来。这时候你说的第一句话，决定了这件事是变小还是变大。

## 本课目标
- 学完能用「倾听、道歉、解决、感谢」四步处理客诉
- 学完知道哪些话、哪些做法会让事情变大
- 学完知道解决不了的怎么报、怎么记进客诉台账

## 四步法
:::steps 客诉处理四步
倾听｜让客人把话说完，不打断，看着客人，记下要点
道歉｜为客人的不愉快道歉：「真抱歉，让您久等了。」
解决｜能当场解决的当场解决；解决不了的马上请主管，告诉客人大概要多久
感谢｜「谢谢您告诉我们，我们一定改进。」
:::

道歉不是认错、推责任，而是对客人的感受负责。**先处理心情，再处理事情。**

:::ban 处理客诉三不
- 不推诿：不说「这不归我管」「是厨房的问题」
- 不争辩：不说「不可能」「别的客人都没说」
- 不拖延：不让客人干等，没进展也要回个话
:::

## 你能做什么、不能做什么
- 能做：倾听、道歉、马上去催、帮客人换一个、请主管来
- 不能做：自己答应打折、免单。**优惠、免单要值班经理及以上当场授权**，其他补偿听主管安排
- 第一个接到客诉的人要跟到底：交给主管以后，也回头看看客人那边解决了没有

## 记进客诉台账
解决不了的、客人情绪很大的，报给值班主管，同时在系统里留下记录：

:::table 客诉在系统里怎么记
谁｜做什么
前台（有发牌或结账权限的同事）｜在客人卡或收银台的备注板块写一条备注，选「客诉」标签；需要特别照顾的选「特殊关照」
值班经理及以上｜在「前台 → 客诉台账」里看到这条，处理后点「标已处理」，写上处理结果
:::

台账能按日期、状态（没处理 / 已处理）、标签筛选，也能打印。标了已处理就不能再改，所以处理结果要写清楚。其他部门的同事遇到客诉，先告诉主管或前台，由他们来记。

:::check
客人投诉饭菜上得慢。听他说完后，你的第一句话最好是？
- [ ] 「今天人多，厨房忙不过来，没办法。」
- [x] 「真抱歉让您久等了，我马上去问，几分钟内给您回话。」
- [ ] 「不可能等一个小时，我们一般很快的。」
解析：先道歉、再给出马上能做的事和回话的时间。找借口、争辩都会让事情变大。
:::

:::check
一位客人要求打折作为补偿，你是普通服务员，怎么做？
- [ ] 自己答应给他打折
- [x] 先道歉，告诉客人马上请值班经理来处理
- [ ] 直接拒绝，说「没有这个规定」
解析：优惠、免单要值班经理及以上当场授权，普通员工不能自己答应。先安抚客人，再请值班经理。
:::

## 本课小结
- 倾听、道歉、解决、感谢；先处理心情，再处理事情
- 不推诿、不争辩、不拖延；优惠、免单要值班经理及以上当场授权
- 解决不了的报主管；前台记「客诉」备注，值班经理在客诉台账里标已处理

# 课时 key=recovery min=7：服务补救与超出期待
客人约了按摩，技师晚到了二十分钟。客人一开始很不高兴，走的时候却说："你们处理得挺好，下次还来。"出了错不可怕，补救得好，客人反而更信任你。

## 本课目标
- 学完能说出服务补救的五个步骤
- 学完能在一连串的情景里做出合适的选择
- 学完知道怎么做到「超出期待」

## 补救做得好，客人更信任
服务业里常说：问题处理得好，客人的满意度有时比没出问题还高，因为客人看到了你们的态度。反过来，小问题拖着不管，就会变成大客诉。

:::steps 服务补救五步
快｜发现问题马上回应，别等客人来找
诚｜真诚道歉，不找借口
解｜把问题解决掉：换、补、催、重做
补｜需要补偿的，按门店规定、由主管决定
跟｜客人离店前再问一句「刚才的事，现在还满意吗」；事后把问题记下来，避免再犯
:::

## 多步情景：技师晚到了
:::scenario 第一步：客人找上门
客人约了按摩，到点了技师还没来。等了二十分钟，客人在休息区叫住你：「我等了这么久，人呢？」
- [ ] 「技师的事我不清楚，您去问保健部吧。」｜这是推诿。客人会觉得被踢皮球，火气更大。
- [x] 「真抱歉让您久等了！我马上帮您问，五分钟内给您回话。」｜先道歉，再给出明确的回话时间，客人知道有人在管，情绪会缓下来。
- [ ] 「今天客人多，大家都在等。」｜这是找借口，客人听着像在说「你活该等」。
:::

:::scenario 第二步：问清情况
你问了钟房，原来前一位客人加了钟，这位技师还要十五分钟才能来。你怎么回复客人？
- [ ] 先不回去，等技师来了让他自己解释｜说好五分钟回话却不回，客人会更生气。
- [x] 回去如实说明，请客人选：再等十五分钟，还是换一位现在能来的技师；同时告诉主管｜如实说、给选择，让客人自己做主。超出你权限的补偿，交给主管。
- [ ] 「马上就到了，您再等等。」｜不说实话，十五分钟后客人还在等，就是第二次失望。
:::

:::scenario 第三步：客人离店前
客人选了再等，按摩做完，准备结账走了。你还能做什么？
- [ ] 事情过去了，不用再提｜补救少了最后一步，客人记住的可能还是那二十分钟。
- [x] 走过去问一句「刚才让您久等了，按摩还满意吗？」，并跟主管说一下这次的情况｜「跟」这一步让客人感到被重视；主管知道了，门店才能改进。
- [ ] 主动跟客人说「我给您免单」｜免单要值班经理及以上当场授权，你不能自己答应。
:::

## 超出期待：小事上多想一步
超出期待不是送很多东西，而是让客人觉得「你们真用心」。

:::tip 不花钱也能超出期待
- 记得客人上次的偏好，这次不用他再说
- 客人等了一会儿，主动告诉他进度
- 客人遇到过问题，走之前专门去问一句
:::

:::check
服务补救五步的顺序是？
- [x] 快、诚、解、补、跟
- [ ] 补、解、诚、快、跟
- [ ] 跟、快、补、诚、解
解析：先快速回应、真诚道歉，再解决问题、按规定补偿，最后跟进并记下来改进。
:::

## 本课小结
- 补救做得好，客人反而更信任
- 快、诚、解、补、跟；补偿按门店规定，由主管决定
- 超出期待靠用心，在小事上多想一步
