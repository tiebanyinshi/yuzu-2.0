# 课时 key=law min=6：沐浴场所为什么管得严
卫生监督部门的人来门店检查，要看卫生许可证、员工健康证，还翻看了毛巾的消毒记录。新同事小声问："就是个洗澡的地方，怎么管得这么细？"这节课就讲讲原因，和管我们的几部法规、标准。

## 本课目标
- 学完能说出沐浴场所为什么要管得严
- 学完知道卫生许可证、健康证、卫生知识培训是怎么回事
- 学完能说出三项国家标准分别管什么

## 为什么管得严
- **人多**：一天进出很多客人
- **贴身**：毛巾、浴衣、拖鞋直接碰皮肤，池水大家一起泡
- **湿热**：又暖又潮的地方，细菌、霉菌长得快
- **一出事就是一片**：一个人带进来的病，可能传给很多人

## 管我们的法规
**《公共场所卫生管理条例》**和它的**实施细则**，把公共浴室列为要管的公共场所。里面有几条和我们每个人都有关：

:::table 和我们有关的几项要求
要求｜意思
卫生许可证｜门店要取得卫生许可证才能营业，并在显眼的地方公示
健康证｜直接为客人服务的员工，体检合格、拿到健康合格证明才能上岗，每年体检一次
卫生知识培训｜员工要接受卫生知识培训，合格了才能上岗
暂停服务｜患有某些传染病、化脓性或渗出性皮肤病等的员工，治好之前不能直接为客人服务
:::

## 三项国家标准，各管一块
:::cards 三项国家标准（点一下看它管什么）
GB 37487-2019《公共场所卫生管理规范》｜管「怎么管」：卫生管理制度、员工健康和培训、公共用品清洗消毒、通风设施维护、防蚊蝇虫鼠、卫生检测等
GB 37488-2019《公共场所卫生指标及限值要求》｜管「合不合格」：室内空气、水质、公共用品等的卫生指标要达到什么要求
GB 37489.4-2019《公共场所设计卫生规范 第4部分：沐浴场所》｜管「怎么建」：沐浴场所的功能分区、更衣、浴池、通风、给排水、消毒间等设施怎么设计
:::

这三项都是强制性国家标准，门店必须照做。具体数值由门店管理人员、工程部和检测机构把关，我们记住自己岗位的要求就行。

:::tip 检查来了，怎么配合
- 礼貌接待，马上报告主管
- 问到自己岗位的事，照实回答
- 拿不准的不乱说，请主管来答
- 证件、记录由主管统一出示
:::

:::check
员工健康证的要求，下面说得对的是？
- [ ] 入职时体检一次，以后不用再查
- [x] 体检合格、拿到健康合格证明才能上岗，每年体检一次
- [ ] 只有厨房员工才要健康证
解析：直接为客人服务的员工都要体检合格才能上岗，并且每年体检一次。
:::

## 本课小结
- 沐浴场所人多、贴身、湿热，容易传播疾病，所以管得严
- 《公共场所卫生管理条例》及实施细则：卫生许可证、健康证、卫生知识培训
- 三项国标：37487 管怎么管，37488 管合不合格，37489.4 管沐浴场所怎么建

# 课时 key=linen min=6：公共用品用具「一客一换一消毒」
高峰时浴巾不够用了，有同事想把客人刚换下来、看着挺干净的浴巾叠一叠先拿出去。就这一下，可能把一位客人身上的病菌，传给下一位客人。

## 本课目标
- 学完能说出「一客一换一消毒」管哪些东西、怎么做
- 学完能按「收、洗、消、存、发」处理公共用品
- 学完明白脏的和干净的为什么必须分开

## 一客一换一消毒
**客人用过的，换下来；换下来的，消毒后才能再给下一位。**

常见的公共用品用具：
- 毛巾、浴巾、浴衣
- 拖鞋
- 杯具（茶杯、水杯）
- 搓澡巾、修脚工具等直接碰皮肤的用具（按门店规定）

## 处理流程
:::steps 收、洗、消、存、发
收｜用过的放进专门的回收车或筐，不落地，不和干净的混放
洗｜按门店规定清洗干净
消｜按门店规定的方法消毒，比如高温、消毒柜、消毒液浸泡
存｜消毒好的放进保洁柜或干净区，有标识
发｜从干净区拿给客人，拿之前手要干净
:::

清洗、消毒、保洁要分开，用过的和干净的不能放在一起。按门店要求做好消毒记录。

:::ban 绝对不能做
- 用过的毛巾晾一晾、叠一叠，再给下一位
- 拿客人用过的毛巾、浴巾擦地、擦桌子
- 杯子用水冲一下就再给客人用
- 拖鞋不消毒直接摆回去
- 干净的布草放在地上
:::

:::scenario 浴巾不够了
晚上客人特别多，浴巾快发完了，干净的还没送来。同事说：「先把那堆刚换下来的，挑干净的叠一叠拿出去吧。」你怎么办？
- [ ] 照同事说的做，反正看着挺干净｜看着干净不等于没有病菌。用过的布草没消毒就再发，是卫生上的大忌，也违反规定。
- [x] 不这么做，马上报告主管，催送干净的；跟客人说「稍等几分钟，马上给您拿干净的」｜宁可让客人等一会儿，也不能发用过的。客人能理解，主管也能想办法调。
- [ ] 让客人自己去别的区找｜把问题推给客人，体验很差，客人还可能拿到不干净的。
:::

:::check
「一客一换一消毒」是什么意思？
- [x] 客人用过的要换下来，消毒后才能再给下一位客人
- [ ] 每天换一次、消一次毒就行
- [ ] 客人要求换才换
解析：每一位客人用过的都要换、都要消毒，不是按天算，也不是等客人要求。
:::

## 本课小结
- 毛巾、浴衣、拖鞋、杯具等，一客一换一消毒
- 收、洗、消、存、发，脏净分开，不落地
- 宁可让客人等，也不发没消毒的

# 课时 key=pool min=6：池水与空气
早班巡池，你发现一个池子的水有点浑，水面还漂着几根头发；更衣室里也闷得透不过气。客人还没多起来，现在处理正是时候。

## 本课目标
- 学完知道池水为什么要换水、消毒、检测
- 学完能说出军团菌是什么、平时怎么防
- 学完知道发现池水或通风不对怎么报

## 池水：换水、消毒、检测
池水大家一起泡，最容易出卫生问题。门店会按规定做三件事：
- **换水、补水**：按规定定期换水、补充新水
- **消毒**：按规定的方法持续消毒
- **检测**：门店按要求自己检测，并请有资质的机构定期检测

多久换一次、指标多少，由门店管理人员和工程部按规定把关。我们一线员工要做的是：**看、劝、报**。

:::steps 看、劝、报
看｜巡池时看水清不清、有没有异味和漂浮物，池边干不干净
劝｜提醒客人先冲淋再下池，不在池里搓澡、洗东西
报｜水浑、有异味、有呕吐物或粪便，马上请客人离开这个池，报告主管和工程部
:::

## 热水系统里的「军团菌」
军团菌是一种细菌，喜欢温热、不怎么流动的水，容易在热水管道、淋浴喷头、空调冷却设备、按摩池里滋生。人吸进带菌的细小水雾，可能得肺炎。

:::warn 防军团菌，平时这样做
- 热水系统、淋浴喷头、空调通风设备，要定期清洗消毒
- 按检测要求定期检测
- 很久没用的淋浴喷头，按门店规定先放一会儿水，再给客人用
- 发现喷头堵、水发黄、有异味，报工程部
:::

## 空气：通风换气
浴区、蒸房、更衣室又热又湿，人一多，空气就闷。空气不好，客人容易晕堂，霉菌也容易长。

:::tip 通风和环境，要注意
- 排风、换气设备开着、转着，坏了马上报修
- 室内公共区域不吸烟（门店设了吸烟区的，按门店规定）
- 墙角发霉、有异味，报告主管
- 看到蚊蝇、蟑螂、老鼠，及时报告
:::

:::check
池子里发现了呕吐物，第一步做什么？
- [ ] 用网捞掉就行，客人照常泡
- [x] 请客人离开这个池，马上报告主管和工程部，按规定处理
- [ ] 等下班后再处理
解析：池水被污染，先让客人离开，再由主管和工程部按规定停用、处理，不能捞一捞就继续用。
:::

## 本课小结
- 池水按规定换水、消毒、检测，一线员工负责看、劝、报
- 军团菌喜欢温热、不流动的水，热水系统和喷头要定期清洗消毒
- 浴区要通风，设备坏了及时报修，室内公共区不吸烟

# 课时 key=health min=6：员工个人卫生与健康管理
一位技师早上起来有点发烧，还拉肚子。他想："今天有客人约了，忍一忍吧。"这一忍，可能把病传给客人和同事。员工自己的健康，也是门店卫生的一部分。

## 本课目标
- 学完知道健康证怎么管、过期了怎么办
- 学完能做好个人卫生的几件基本事
- 学完知道哪些身体情况要主动上报、暂停接触客人

## 健康证
- 上岗前体检合格，拿到健康合格证明
- 每年体检一次，快到期了提前安排
- 健康证过期了，按门店规定先停下直接接触客人的工作，补办好再上岗
- 餐饮、出品岗位接触直接入口的食品，按《食品安全法》也要每年体检、持健康证明上岗

## 个人卫生
:::cards 个人卫生五件事（点一下翻面）
勤洗手｜接触客人用品前后、上厕所后、处理脏东西后都要洗
指甲｜剪短、干净，按摩和餐饮岗位不留长指甲
工服｜干净整齐，按门店规定穿戴
头发｜整齐，餐饮岗位按规定戴帽
工作区｜不在服务区吃东西、吸烟
:::

## 这些情况要上报
:::warn 有这些情况，先告诉主管
- 发烧
- 拉肚子、呕吐
- 皮肤上有化脓、渗出的伤口或皮疹，有传染性皮肤病
- 咳嗽得厉害
- 得了传染病，或者医生让隔离
:::

上报以后，按主管安排**暂停直接接触客人的岗位**（按摩、浴区服务、餐饮出品、布草等），治好了、按要求确认后再回来。手上有小伤口的，包好、戴手套，按主管安排工作。

:::ban 不能做
- 生病了瞒着不说，硬撑着上岗
- 借别人的健康证、用过期的健康证
- 带着化脓的伤口给客人按摩、端菜
:::

## 处理呕吐物、排泄物
戴好手套和口罩，按门店规定用消毒剂处理，处理完洗手。用过的工具单独清洗消毒。

:::check
早上起来发烧、拉肚子，你该怎么做？
- [ ] 吃点药，照常上岗，别耽误客人
- [x] 马上告诉主管，按安排暂停接触客人的岗位
- [ ] 不说，跟同事换个班就行
解析：生病了要主动上报，暂停直接接触客人的岗位，治好了再回来。瞒着上岗可能把病传给客人和同事。
:::

## 本课小结
- 健康证上岗前办、每年体检，过期先停下接触客人的工作
- 勤洗手、剪指甲、工服干净，服务区不吃东西、不吸烟
- 发烧、腹泻、皮肤病等主动上报，暂停接触客人的岗位
