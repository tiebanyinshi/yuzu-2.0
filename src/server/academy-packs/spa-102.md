# 课时 key=water min=5：温泉水与普通热水
客人泡在池子里问你："你们这是真温泉吗？泡了能降血压吗？"两个问题都不难，但答错哪一个都麻烦：一个可能是瞎说，一个可能是乱许功效。

## 本课目标
- 学完能用大白话说清温泉一般指什么
- 学完能按门店统一说法介绍我们的池水
- 学完知道哪些功效的话不能对客人说

## 温泉一般指什么
一般来说，温泉是从地下自然涌出、或者打井取上来的热水。它有两个特点：
- 水温比较高，从地下出来就是热的
- 水里溶着一些矿物质，不同地方的温泉成分不一样

有的温泉有股特别的气味，比如常说的硫磺泉，闻着有点像臭鸡蛋。

自来水、井水烧热了，也干净、也舒服，但它不是温泉。

## 我们的水，照门店的说法讲
门店池子里用的是什么水，有没有加浴盐、花草、药材，**以门店的统一说明为准**。上岗前问清楚主管，客人问到时照着说。

:::steps 客人问"这是温泉吗"
先问清｜上岗前问清门店池水的统一说法
照实说｜是什么就说什么，不往大了说
不清楚｜「您稍等，我帮您问一下」，问清楚再回复
不乱编｜拿不准的事，不顺口说「是」
:::

## 能说的和不能说的
泡汤的好处，我们只说客人自己能感受到的：**放松、舒缓、暖身、解乏**。

:::ban 不能对客人说的话
- 「泡了能治风湿、治关节炎」
- 「能降血压、降血糖」
- 「能排毒、能减肥」
- 「能美白、能治皮肤病」
:::

为什么不能说？第一，这些话没有根据，客人信了可能耽误看病。第二，乱说功效就是虚假宣传，门店要担责任。

:::tip 客人问"泡这个对身体有什么好处"
可以这样说：「泡一泡能放松、解解乏、暖暖身子。身体有什么情况，还是要听医生的。」
:::

:::check

- [x] 「泡汤主要是放松、解乏。血压的事要听医生的，血压高的话，泡之前最好先问问医生。」

解析：我们不做医疗承诺。只说放松、舒缓，身体问题请客人先咨询医生。
:::

## 本课小结
- 温泉一般是地下来的热水，水温较高、含矿物质
- 门店的水是什么，照门店统一说法讲，不清楚就问
- 只说放松、舒缓、暖身、解乏，不说治病、降压、排毒

# 课时 key=temperature min=6：水温与身体的感受
一位阿姨刚下热池两分钟，就说"太烫了，心里慌"；旁边的小伙子却嫌不够热。同一池水，每个人感受差别很大。知道水温和身体的关系，才能给客人合适的建议。

## 本课目标
- 学完能说出热水、温水、冷水的大致范围和身体感受
- 学完知道热水池一次泡多久比较合适
- 学完知道发现水温不对该怎么办

## 三种水温，三种感受
:::table 一般的水温与感受（以门店设定为准）
类型｜一般范围｜身体的感受
温水｜一般在 36–38℃ 左右，接近体温｜舒服、不累，适合先泡、泡得久一点
热水｜一般在 39–42℃ 左右｜很快出汗、心跳加快，泡久了容易口渴、头晕
冷水｜一般在十几度到二十度左右，明显低于体温｜一进去倒吸一口气，皮肤发紧、心跳加快
:::

上面是行业里常见的大致范围。**门店每个池子的实际温度，以门店设定和池边标示为准。**

## 为什么热水泡久了会心慌
热水让皮肤的血管张开，血往皮肤上跑，心脏就要跳得更快；同时人在出汗、丢水分。所以泡久了会口渴、头晕、心慌。老人、身体弱的人反应更明显。

冷水正好反过来：血管一下子收紧，心跳、血压都会跟着变。心脏、血压不好的人，不建议突然进冷水。

## 泡多久合适
:::tip 一般建议
- 热水池一次泡 10–15 分钟左右，起来歇一歇再泡
- 水位泡到胸口以下，心脏负担小一些
- 觉得头晕、心慌、胸闷，马上起来休息
- 老人、第一次来的客人，时间再短一些
:::

## 发现水温不对怎么办
:::steps 水温异常的处理
看｜巡池时看池边的温度显示，按门店规定记录
问｜客人说太烫、太冷，问清是哪个池、什么感觉
报｜明显不对的，马上报告主管和工程部
提醒｜修好之前，提醒客人先别泡这个池
:::

:::ban 不能做
- 自己去动加热设备、阀门
- 客人说烫，回一句「不烫啊，别人都没说」
:::

:::check

- [ ] 想泡多久泡多久
- [x] 10–15 分钟左右
- [ ] 至少一个小时
解析：一般建议热水池一次泡 10–15 分钟左右，分几次泡；头晕心慌马上起来。具体以门店提示为准。
:::

## 本课小结
- 温水接近体温最舒服，热水让人出汗、心跳快，冷水让血管收紧
- 热水池一般一次 10–15 分钟左右，分几次泡，水位到胸口以下
- 水温不对，报告主管和工程部，自己不动设备

# 课时 key=sauna min=6：桑拿、蒸房与汗蒸
客人问："干蒸和湿蒸有什么区别？我该先蒸哪个？"还有一位客人在干蒸房里一坐就是半个多小时，出来时脸色发白。蒸房是最受欢迎的地方，也是最要留神的地方。

## 本课目标
- 学完能说清干蒸、湿蒸、汗蒸的区别
- 学完能告诉客人一次蒸多久、怎么补水
- 学完知道巡查蒸房时要看什么

## 干蒸、湿蒸、汗蒸
:::table 三种蒸法对比（数字是一般范围，以门店设定为准）
蒸法｜温度｜湿度｜感觉
干蒸（芬兰式桑拿）｜高，一般在 70–90℃ 左右｜低，空气干｜热得干脆，出汗快
湿蒸（蒸汽房）｜较低，一般在 40–50℃ 左右｜很高，满屋白雾｜闷热，像在云里
汗蒸｜比干蒸低不少｜不高｜躺着慢慢出汗，比较温和
:::

为什么湿蒸温度低，反而觉得很热？因为湿度高，身上的汗不容易蒸发，身体散不了热，所以照样觉得很热。干蒸空气干，汗一出来就蒸发，能带走热量，所以温度高也待得住。

## 蒸多久、怎么补水
:::tip 一般建议
- 一次一般不超过 10–15 分钟，第一次来或不常蒸的人更短一些
- 蒸前、蒸后各喝点温水，补回出汗丢的水
- 蒸完先在外面歇一歇，再进下一轮
- 觉得头晕、心慌、恶心，马上出来
:::

## 蒸房里的安全
:::ban 要劝阻的情况
- 喝了酒的客人进蒸房
- 在蒸房里睡着
- 用手直接碰加热器、热石头
- 往加热器上泼东西、搭毛巾（能不能往石头上浇水，按门店规定）
:::

:::steps 巡查蒸房看什么
看人｜有没有人待太久、睡着、脸色不好
看设备｜温度显示正常吗，加热器周围有没有毛巾等杂物
看地面｜门口、台阶有没有积水
看饮水｜饮水点有没有水、有没有杯子
:::

:::scenario 客人在干蒸房待太久
巡房时你发现，一位客人二十多分钟前就进了干蒸房，现在还坐在里面，满脸通红，眼睛半闭着。你怎么做？
- [ ] 客人自己有数，不去打扰｜在高温里待太久、迷迷糊糊，很可能已经快晕了，不能等。
- [x] 走过去轻声问：「先生，您蒸了有一会儿了，出来歇一歇、喝点温水吧？」并留意他起身稳不稳｜关心在前，请他出来补水，同时看有没有头晕、站不稳，有不对就扶着并报告主管。
- [ ] 直接把蒸房的温度调低｜设备不能自己动，而且调温解决不了这位客人已经待太久的问题。
:::

:::check
湿蒸房温度比干蒸房低，为什么人反而觉得很闷热？
- [ ] 湿蒸房的温度计不准
- [x] 湿度高，汗不容易蒸发，身体散不了热
- [ ] 湿蒸房里人多
解析：湿度高时汗蒸发不了，热量散不出去，所以温度不高也觉得很热。
:::

## 本课小结
- 干蒸温度高、湿度低；湿蒸温度较低、湿度高；汗蒸比较温和
- 一次一般不超过 10–15 分钟，蒸前蒸后喝温水
- 巡房看人、看设备、看地面，酒后和睡着的要劝阻

# 课时 key=order min=6：冷热交替与正确的泡汤顺序
一位年轻客人进门直接跳进最热的池子，泡完立刻冲进冷水池，起身时眼前一黑，差点摔倒。其实只要顺序走对，这些都能避免。客人问"怎么泡最舒服"，你要能说得清。

## 本课目标
- 学完能按顺序讲出正确的泡汤步骤
- 学完知道冷热交替要注意什么、哪些人不建议做
- 学完能在客人问"怎么泡"时给出建议

## 正确的泡汤顺序
:::steps 泡汤七步
先冲淋｜洗干净身体，也让身体先适应水温
由温到热｜先泡温水池，再进热水池
分次泡｜热水池一次 10–15 分钟左右，起来歇一歇
补水｜中间喝点温水
量力冷热交替｜想泡冷池的，先冲凉水适应，时间要短
起身慢｜从池里起来扶着扶手，慢慢站
收尾｜冲淋、擦干、穿好，到休息区歇一会儿，再喝点水
:::

## 为什么要这样
- **先冲淋**：洗掉汗和污垢，池水才干净；也给身体一个适应的过程
- **由温到热**：一下子进最热的池，心跳、血压变化太猛，容易头晕
- **起身慢**：泡久了血都在皮肤上，猛一站起来，脑子供血跟不上，会眼前发黑、摔倒

## 冷热交替要量力
不少客人喜欢「蒸一会儿、冲个凉、歇一歇」轮着来，觉得很爽。可以，但要注意：

:::warn 冷热交替的注意
- 进冷池前先冲凉水，从脚往上慢慢适应
- 冷池待的时间短，一般几十秒到一两分钟就够
- 每一轮中间要休息
- 高血压、心脏病的客人，老人、孕期的客人，不建议冷热交替，要做先咨询医生
:::

:::cards 记一记：泡汤口诀
第一步｜先冲淋，再下池
温度｜由温到热，不一步到最热
时间｜分次泡，一次十来分钟
喝水｜泡的中间、泡完以后都喝点温水
起身｜扶扶手，慢慢站
:::

:::check
客人刚从热水池出来，想马上冲进冷水池。下面哪种提醒最合适？
- [ ] 「快去，越快越爽。」
- [x] 「您先冲一下凉水，从脚开始慢慢适应，冷池待一会儿就上来。」
- [ ] 「冷池不能泡，谁都不行。」
解析：冷热交替可以做，但要先适应、时间短；冷池不是谁都不能泡，血压心脏不好的才不建议。
:::

## 本课小结
- 先冲淋、由温到热、分次泡、补水、起身慢
- 冷热交替先适应、时间短、中间休息
- 血压心脏不好、老人、孕期的客人，不建议冷热交替

:::question recall skill=泡汤顺序 level=3
客人问你"怎么泡最舒服"，你怎么建议？
答：先冲淋，再由温到热；热水池一次泡 10–15 分钟左右，起来歇一歇；中间和泡完都喝点温水；想冷热交替的先冲凉水适应，冷池时间短；起身扶扶手、慢慢站；身体有情况，先咨询医生。
:::
