# 课时 key=issue min=6：发卡台怎么发牌
客人走到前台，你在发卡台按下 F2，弹出「接待发牌」。读卡器亮着，你把手牌往上一放，牌号自己填好了。可是接下来按哪里？会员怎么选？

这一课一步步教你在发卡台发牌。

## 本课目标
- 学完会用「接待发牌」完成一次发牌
- 学完看得懂手牌板上各种颜色和标记
- 学完会在客人卡上换牌、处理异常

## 发牌的步骤
:::steps 接待发牌
打开｜按 F2，或在手牌板上点一张空闲手牌的「点此发牌」
看读卡器｜对话框顶上一行写读卡器已连接还是没连上；没连上就手输牌号
刷手牌｜把手牌放到读卡器上，牌号填进当前这位客人那一行，这时还没发出去
选客人｜查找会员，或按散客接待；可以选客人类别，填预约的技师（选填）
看提示｜黑名单会拒绝；未结离店要经理授权；当天重复到店、有预约会提示
确认｜核对无误后按回车，或点「确认发牌」
:::

几个小技巧：

- 同一次接待里重复刷了同一张，会提示「本次已刷」。
- 读不出来时，对话框会写明原因，比如这张卡没绑手牌、牌已在店、已锁定，随时可以手输。
- 不在输入框里时，直接在键盘上敲牌号，会自动进牌号框，这叫「盲打」。

## 看懂手牌板
:::table 手牌板上的标记
样子｜意思
空闲｜可以发，点它就能发牌
在店｜客人正在用，会员卡片上还写着档阶，比如 L3
锁定｜被锁住了，比如手牌丢失换牌后锁的原牌
暂停使用（柚黄色）｜暂时不发，点了会提示换一张
维修中（深色底、带扳手）｜柜子或手牌在修，不能发
超 12、24、72 小时（黄、橙、红色带）｜客人在店时间很长，要留意
外出｜客人临时外出，牌照旧占着，不能发给别人
:::

## 客人卡上能做什么
点一张在店的手牌，右边出现**客人卡**：会员身份、档阶、储值余额、能用的权益、票种、同行、已挂的项目。下面的操作：

- 换牌、再发一张同行手牌、与在店客人同行、退出同行组、明细转到别的手牌
- 异常处置：提醒、加收、上报、临时外出、手牌丢失、未结离店
- 写备注、填客人类别与偏好、去收银台结账

:::warn 换牌和撤销要选对
- 换牌原因选「手牌丢失」，才会默认锁定原手牌并收丢牌赔偿；柜锁故障、手牌损坏、客人要求换柜都不锁
- 「撤销误开的牌」只用于开错牌、客人还没入场，撤销后手牌马上空出来
:::

:::check
在接待发牌对话框里刷了手牌，牌号已经填好，这时客人就已经发好牌了。
答案：错
解析：刷手牌只是把牌号填进去，不会提交。核对无误后按回车或点「确认发牌」才真正发出去。
:::

## 本课小结
- F2 打开接待发牌：看读卡器、刷牌、选客人、看提示、确认发牌
- 柚黄是暂停使用、深色带扳手是维修中，都不能发
- 客人卡上换牌、同行、异常处置；只有手牌丢失才锁原牌

# 课时 key=bill min=8：收银台挂项目与结账
客人走到收银台说：「买单。」你还没打开他的手牌，就先按了 F9。屏幕弹出「选手牌」，你刷了一下牌，结账对话框直接打开了。

收银台用熟了，又快又不容易错。

## 本课目标
- 学完会用快捷键操作收银台
- 学完会加项目、打单项折扣、看预结账
- 学完会在结账对话框里正确收款

## 快捷键
:::table 收银台常用快捷键
键｜做什么
F1｜充卡（会员充值）
F3｜备注
F4｜加项目
F6｜买角（敲数字代号回车加一份）
F7｜组合或拆分同行手牌
F8｜预结账
F9｜买单（结账）
F10｜打单（打预结单）
?｜看快捷键一览
:::

- 没打开手牌时按，会先弹「选手牌」，刷牌或输牌号回车，接着就做。
- 有对话框开着时按，会提示先按 Esc 关掉现在的对话框。
- 苹果笔记本要按住 fn 再按 F 键。

## 打开客人、挂项目
左边是**待结账清单**，直接敲牌号回车就打开。可以筛「有消费」「同行」「超 12 小时」，可以按牌号、金额、在店时长排。

右边是账单，每一行上面写经办人（工号、姓名、手机尾号、时间）。改过价的行标「改价」，打过折的标「折」，免单的标「赠」。

- **加项目**（F4）、**买角**（F6）：挂到这张手牌上。买角的代号清单在后台设，没设时会写明还没配置。
- **作废、退菜**：要写原因；退菜小额能直接退，超过的请值班经理及以上当场授权。
- **单项打折**：点这一行右边的「折」，选几折，或直接填折后价；超出你的权限会弹「请经理授权」；打错了点「恢复原价」。
- **押金**：账单里「押金」一块，「收押金」「一键退」。

## 预结账、打单与买单
:::steps 结账三步
预结账（F8）｜按门票、餐饮、客房、服务、优惠、押金六列，先和客人核对
打单（F10）｜需要时打一张预结单给客人看，上面写明不是结账单
买单（F9）｜打开结账对话框收款，结清后打印结账单
:::

在结账对话框里：

- 没选票种的要先补选。
- 每加一笔收款，金额默认填「还差」的部分；「会员储值」那一笔默认填到余额为止，再点「现金」就是剩下的。每笔后面有「补齐到应收」。
- 底部写「还差」「多收」或「已等于应收」，等于应收才能结清。
- 客人买单时才说自己是会员：点「查会员」，查到了「记到手牌」，没查到可以「现场建档」。
- 有技师还在钟上，结账时会自动下钟；还没上钟的，要先到钟房取消派钟再结账。

:::tip 打单被拦住了
点「打单」没反应、提示打印窗口被拦下，就在浏览器地址栏右边点允许本站弹出窗口，再按一次。
:::

:::check
收银台还没打开任何手牌时按 F9，会怎样？
- [ ] 什么都不发生
- [x] 先弹出「选手牌」，选好后直接打开结账
- [ ] 打开充值页面
- [ ] 浏览器刷新
解析：没打开手牌时按快捷键，会先让你选手牌，刷牌或输牌号回车后接着做，不用再按一次。
:::

:::check
结账对话框底部显示「还差」时，能点结清吗？
- [ ] 能，差的下次补
- [x] 不能，几笔收款加起来要等于应收才能结清
- [ ] 能，只要经理在场
解析：收款合计要正好等于应收才能结清。可以在某一笔后面点「补齐到应收」。
:::

## 本课小结
- F4 加项目、F8 预结账、F9 买单、F10 打单，不会就按「?」
- 单项打折点行右边的「折」，超权限请经理授权
- 结账时合计等于应收才能结清；客人临时说是会员就「查会员」

# 课时 key=pending min=5：页面显示「结果待确认」时怎么办
你刚给客人加了一个项目，点确认的一瞬间，网络卡住了。对话框里出现一块提示：「上一笔挂账结果待确认」，下面三个按钮。你不知道该点哪个。

## 本课目标
- 学完认得出「结果待确认」出现在哪里
- 学完会用三个按钮处理
- 学完知道哪些情况要到哪个台处理

## 它长什么样
- **对话框里**：「上一笔某某结果待确认」，下面三个按钮：「查回结果」「按原内容重新提交」「确认作废，重新填写」。这时表单是锁住的，不能改内容再交。
- **页面顶上**：一条提醒「几笔前台操作结果待确认，处理前请勿对同一手牌重复登记」，右边有「去处理」。刷新页面、重新登录，它还在。

## 怎么处理
:::steps 三个按钮怎么用
查回结果｜先点这个。已经生效的会提示「只生效了一次」，什么都不用再做
按原内容重新提交｜查不到时可以点。用的是原来的编号，服务器保证只生效一次
确认作废，重新填写｜服务器先把原编号作废，原请求之后就算到了也不生效，然后才能重新填
:::

:::warn 记住这几点
- 查不到，不等于没成功，原请求可能还在路上
- 重新提交被明确拒绝，也不能断定之前那次不会生效，先作废再下结论
- 页面明确写着「这次没有发出去」的，才是真的没发出去，填的内容还在，网络恢复后再提交
:::

**网络恢复后**：发牌会自动按原编号查回，没生效的自动重提一次；挂账、换牌、结账要人来处理。

:::scenario 客人说要再付一次
客人用微信付完款，你点了结账确认，网就断了，对话框显示「上一笔结账结果待确认」。客人说：「要不我再扫一次？」
- [x] 请客人稍等，先点「查回结果」；查到已生效就打印结账单，查不到再按原内容重新提交｜做得对。先查回，绝不让客人重复付钱。
- [ ] 让客人再扫一次，多收的再退｜不行。可能重复收款，退钱还要另走手续，客人也不高兴。
- [ ] 关掉对话框，重新打开这张手牌再结一次｜不行。原来那笔可能已经生效，再结一次就是重复结账。
:::

:::table 回哪个台处理
在收银台处理｜在发卡台处理
结账、退款单｜发牌、换牌
挂账（加项目）｜明细转到别的手牌
:::

:::ban 不要这样做
- 不另开一笔重新挂、重新收
- 不清浏览器数据，不换电脑重做
- 本机提示存不下「结果待确认」时，这笔不会提交，请换一台终端办理
:::

:::check
「结果待确认」时点了「查回结果」，提示暂时查不到。下面哪种说法是对的？
- [ ] 查不到就是没成功，另开一笔重做
- [x] 不能断定没成功，可以按原内容重新提交，或确认作废后重新填写
- [ ] 只能等第二天再处理
解析：查不到只代表此刻还没查到已提交的结果。按原内容重新提交不会重复生效；确认作废后原请求到了也不生效。
:::

## 本课小结
- 对话框里三个按钮，顶上提醒条点「去处理」
- 先查回；查不到就原样重提或确认作废，绝不另开一笔
- 结账、退款单、挂账回收银台；发牌、换牌、转明细回发卡台

# 课时 key=shift min=5：交班
凌晨两点，你准备下班。打开「交班」页面，系统写着应有现金多少，你数了一遍钱箱，差了一点。是数错了，还是哪笔收错了？

## 本课目标
- 学完会开班、加入或离开钱箱
- 学完会填实点现金、写交班备注、打印交班表
- 学完知道交班时要注意什么

## 开班
在「财务 → 交班」页面开班。充值、结账、反结账之前都要先开班；没开班就去收款，系统会先弹出开班，开好了再接着办这一笔。

:::table 两种交班方式（门店用哪种以后台设置为准）
方式｜开班｜下班
按人交班｜登记抽屉里的备用金，开自己的班｜自己交自己的班
按钱箱交班｜选你所在的钱箱；已经开班的点「加入」，还没开班的登记备用金开班｜可以「离开钱箱」，钱等交班时一起点
:::

按钱箱交班时，你是钱箱上最后一个人，离开以后钱箱的班次还开着，下一位点「加入」接着收。要点钱交班，就直接确认交班。

## 交班
:::steps 交班四步
数钱｜把钱箱里的现金数清楚
填数｜在「实点现金」里填数，看系统显示「与应有一致」还是长款、短款
写备注｜对不上时在「交班备注」里写原因，例如短款原因
确认并打印｜确认交班，点「打印交班表」
:::

交班表上有：各收款方式的笔数和金额、结账现金、充值现金、押金（客房、手牌押金，不算营业额）、次卡、反结账、退款；按钱箱交班的还列「各人经办」。页面每 15 秒自动刷新。

:::warn 交班时注意
- 班次跨了营业日，会提示「请先交班」，不要拖
- 收款开始时所在的班次，在入账前已经交班了，这笔会被整笔拒绝，要重新办理
- 页面提示今天有几笔结账收款时没有开班，这几笔不在交班合计里，要告诉值班经理
:::

:::check
交班时实点现金和应有现金对不上，正确做法是？
- [ ] 改一下实点金额让它对上
- [x] 照实填实点现金，在交班备注里写清原因
- [ ] 先不交班，等明天再说
- [ ] 用自己的钱补上，不用写
解析：照实填、写清原因，交给值班经理核对，不能改数凑平，也不能拖着不交。
:::

## 本课小结
- 收款前先开班；按钱箱交班可以加入、离开钱箱
- 交班四步：数钱、填数、写备注、确认并打印
- 跨营业日要先交班；没开班的收款要告诉值班经理

收银台结账前要按哪几个键、做哪几步？
答：先按 F8 预结账，和客人按门票、餐饮、客房、服务、优惠、押金核对；需要时按 F10 打预结单；然后按 F9 买单，在结账对话框里收款，合计等于应收后结清并打印结账单。
:::

:::question single skill=结果待确认 level=1
页面出现「结果待确认」，应该先点哪个按钮？
- [x] 查回结果
- [ ] 按原内容重新提交
- [ ] 确认作废，重新填写
- [ ] 关掉浏览器
解析：先查回。已经生效的会提示只生效了一次，不用再做；查不到再选重新提交或确认作废。
:::

:::question single skill=结果待确认 level=3
你给客人挂了一个项目，结果待确认。同事说：「别管了，另外再挂一笔就行。」你应该？
- [ ] 听同事的，另外再挂一笔
- [ ] 把浏览器数据清掉重来
- [x] 不另挂，先在收银台点「查回结果」，查不到再按原内容重新提交或确认作废
- [ ] 去发卡台处理
解析：另挂一笔可能重复记账。挂账的待确认在收银台处理：先查回，查不到再原样重提或确认作废。
:::

:::question single skill=交班操作 level=1
在系统里开班时要登记什么？
- [ ] 当班收了多少钱
- [x] 钱箱抽屉里的备用金
- [ ] 下一班是谁
- [ ] 今天的营业额
解析：开班登记抽屉里的备用金，交班时系统按备用金加上收的现金、减去退的现金算出应有现金。
:::

:::question single skill=交班操作 level=3
门店用「按钱箱交班」。你要下班了，钱箱里还有同事在收款。你应该？
- [ ] 直接确认交班，把同事也一起交掉
- [x] 点「离开钱箱」，钱箱的班次照常开着，等交班时一起点钱
- [ ] 什么都不点，直接走
- [ ] 把钱箱里的钱拿走一半
解析：按钱箱交班时，下班的人点「离开钱箱」，之后你的收款不再记到这个钱箱；班次照常开着，交班时由在上面的人或值班经理一起点钱。
:::

:::question recall skill=交班操作 level=2
交班的四步是什么？
答：数清钱箱里的现金；在「实点现金」里填数，看是否与应有一致；对不上在「交班备注」里写原因；确认交班并打印交班表。
:::
