# 课时 key=boards min=5：登录与四个板块
新同事入职第一天，人事给了你一个账号，说：「以后打卡、请假、看工资条都在柚子里。」你登录进去，看到四张大卡片：CRM、ERP、WCP、Design，有两张是灰的点不开。

## 本课目标
- 学完会登录柚子，知道手机上怎么打开
- 学完能说出四个板块各管什么
- 学完知道账号安全要注意什么

## 一个账号，四个板块
柚子是门店用的系统。登录一次，按你的岗位看到自己能进的板块；进不去的板块照样在那儿，只是不开。

:::table 四个板块
板块｜管什么
CRM｜客人与前台营业：发卡台、收银台、房态、钟房与技师、餐饮、会员与储值、流水与日结
ERP｜财务与经营管理：库存、采购、货款、合同、费用，审批都走一处
WCP｜员工工作台：排班、考勤打卡、审批、通讯录、工资条、学堂
Design｜品牌与设计：素材库、电子菜单的版面、对客导览、官网
:::

**WCP 人人都有**，这一门课讲的就是它。WCP 取的是英文 Workplace 的意思，就是员工的工作台。

## 手机上怎么打开
:::steps 用手机打开 WCP
扫码｜用微信扫门店给的二维码，打开的是外网的 https 地址
登录｜页面写着「员工登录」，输入自己的账号和密码
用｜登录后直接进 WCP，底部有四个 Tab
:::

:::warn 为什么一定要用门店给的二维码
打卡要用到定位和摄像头，只有 https 的地址才拿得到。如果页面提示拿不到定位、开不了摄像头，多半是地址不对，请找人事要正确的二维码。
:::

:::ban 账号安全
- 不把账号借给别人用，也不用别人的账号
- 不把密码告诉任何人，包括同事
- 用完公用电脑要退出登录
:::

改密码、退出登录在「我的」页的设置里。

:::check
打卡要用定位和摄像头，所以手机上要用门店给的 https 地址打开 WCP。
答案：对
解析：门店内网的 http 地址在微信里拿不到定位，打不了卡。要扫门店给的二维码，打开外网的 https 地址。
:::

## 本课小结
- 四个板块：CRM 管前台营业，ERP 管财务经营，WCP 是员工工作台，Design 管品牌设计
- 手机扫门店的二维码打开 WCP，用自己的账号登录
- 不借账号、不说密码，用完公用电脑要退出

# 课时 key=mobile min=6：手机上的 WCP
你打开手机上的 WCP，底部有四个按钮，顶上有个铃铛带着红点，中间一格格的小图标。你想找上个月的工资条，不知道该点哪里。

## 本课目标
- 学完能说出底部四个 Tab 各放什么
- 学完会在工作台找到常用功能
- 学完会看消息、通知和公告

## 底部四个 Tab
:::table 底部四个 Tab
Tab｜放什么
工作台｜顶上「今天」打卡卡片，下面是功能宫格
消息｜同事聊天和系统通知，分两栏
学堂｜培训课程、每日一练、考试与证书、知识库
我的｜头像、部门岗位、假期余额、本月排班、人脸录入状态、设置
:::

顶栏有门店名和通知铃铛；Tab 首页下面有一行搜索框，在工作台可以按名字找功能。不是 Tab 首页的页面，左上角有「返回」。

## 工作台
**「今天」卡片**写着今天上什么班、上下班卡打了没有、下一张该打什么卡。

**功能宫格**常用的有：

- 打卡、我的排班、我的考勤、补卡
- 审批（请假、加班、出差、报销、补卡、用章）
- 假期余额、工资条、人脸录入
- 通讯录、公告、通知、消息

有排班权限的会多一个「排班管理」，有管理权限的会多一个「WCP 设置」。

:::cards 想做这件事，点哪里
看这个月上什么班｜工作台「我的排班」，或「我的」页的月历
看工资条｜工作台「工资条」
请假｜工作台「审批」，发起请假
找同事电话和部门｜工作台「通讯录」
改密码、退出登录｜「我的」页的设置
:::

## 消息、通知和公告
- **消息** Tab 分「聊天」和「系统通知」两栏，Tab 上的红点是两边未读加起来的数。
- 排班发布、审批结果、工资条、考勤异常这些提醒，都在系统通知里。
- **公告**在工作台，有「全部」和「未读」，置顶的在最上面；点开看过就记为已读。

:::tip 养成习惯
每天上班先看一眼工作台的「今天」卡片和消息红点，排班变了、审批回来了都在这里。
:::

:::check
想看自己上个月的工资条，在手机 WCP 上应该去哪里？
- [ ] 消息 Tab
- [x] 工作台的「工资条」
- [ ] 学堂
- [ ] 问同事
解析：工资条在工作台的功能宫格里，只能看到本人已发放的工资条。
:::

## 本课小结
- 底部四个 Tab：工作台、消息、学堂、我的
- 工作台顶上看今天的班和打卡，下面宫格找功能
- 排班、审批、工资条的提醒都在消息的系统通知里

# 课时 key=attendance min=7：打卡、排班、请假与工资条
你上的是晚班，下班时已经过了零点，一忙就忘了打卡。第二天一看「我的考勤」，显示「缺下班卡」。还有，下周想请两天假，不知道怎么提。

## 本课目标
- 学完会看排班、正确打卡
- 学完会看考勤结果，会补卡、请假
- 学完会看工资条、确认签收

## 排班
排班由管理人员排好、**发布了才生效**，发布后你会收到「排班已发布」的通知。在「我的排班」月历上点某一天，下面显示班次和时间；跨天的班会写「至次日」几点。

## 打卡
:::steps 打一次卡
打开｜工作台点「打卡」，看定位状态
确认范围｜在打卡点范围内，点大按钮「打卡」
需要人脸时｜考勤组要人脸的，先自拍一张再打卡
范围外｜不在范围内会提示，可以改成「外勤打卡」，写事由、拍一张照片
:::

- 打卡按**排班的时间窗口**来算，不是按当天第一次打卡算上班。
- 上班卡算第一次，下班卡算最后一次，重复打不算异常。
- 连着上两个班的，交接时打两次：第一次算前一班下班，第二次算后一班上班。
- 要人脸的考勤组，要先在「人脸录入」拍三张照片（正面、稍向左、稍向右），人事审核通过后才能打卡。

## 考勤结果与补卡
「我的考勤」顶上是这个月的汇总，可以只看「异常」。结果有：正常、迟到、早退、缺上班卡、缺下班卡、旷工，还有请假、出差。出现异常会收到通知。

缺卡的那一行有「补上班卡」或「补下班卡」，点了自动带出日期和班次，填漏卡原因提交审批。**补卡只能补 30 天以内的。** 跨零点的夜班，下班卡也记在上班的那一天。

:::scenario 忘打下班卡
你昨晚上夜班，下班时忘了打卡，今天「我的考勤」显示昨天那一班「缺下班卡」。
- [x] 在「我的考勤」那一行点「补下班卡」，写清漏卡原因提交审批｜做得对。审批通过后系统写一张补卡，缺卡就消了。
- [ ] 让同事用你的账号帮你补打一次｜不行。账号不能借，代打卡也不算数，补卡要走审批。
- [ ] 不管它，反正就差一张卡｜不妥。缺卡算考勤异常，要及时补。
:::

## 请假和其他审批
在「审批」里发起：请假、加班、出差、报销、补卡、用章等。

:::tip 请假要知道
- 选假种、开始和结束（日期加上午或下午），以半天为单位
- 时长按你的排班自动算，休息日不算
- 管余额的假种（比如年假），余额不够提交不了
- 要证明的假种（比如病假）要带附件
:::

审批有四个页签：待我审批、我发起的、抄送我的、我处理过的。没人通过的可以撤销，可以催办，被驳回的可以改了再提交。

## 工资条
工资条只列本人已发放的，列表里不显示金额，点开才看明细。核对无误点「确认签收」；有问题点「有异议」，会打开「工资条异议」审批，由人力行政部处理。

:::check
下面关于打卡的说法，哪个是对的？
- [ ] 当天第一次打卡一定算上班卡
- [x] 打卡按排班的时间窗口算，上班卡取第一次、下班卡取最后一次
- [ ] 不在打卡点范围内就完全不能打卡
解析：打卡按排班的上下班窗口匹配。范围外可以改成外勤打卡，写事由并拍照。
:::

:::check
发现自己 20 天前有一次缺下班卡，还能在系统里补卡吗？
- [x] 能，在「我的考勤」点那一行的「补下班卡」提交审批
- [ ] 不能，过了当天就不能补
- [ ] 只能找人事口头说明
解析：补卡可以补 30 天以内的，在「我的考勤」的异常行一键发起，审批通过后缺卡就消了。
:::

## 本课小结
- 排班发布了才生效；打卡按排班窗口算，范围外用外勤打卡
- 缺卡 30 天内在「我的考勤」一键补卡；请假以半天为单位、按排班算
- 工资条点开看明细，核对后确认签收，有问题点「有异议」

# 课时 key=academy min=6：学堂怎么用
人事告诉你：「新员工入职要学完必修课，学堂里有，每天还可以做做每日一练。」你打开学堂，看到学习地图、每日一练、考试与证书、知识库四个入口，还有一个排行榜。

## 本课目标
- 学完知道学堂首页有什么
- 学完知道课怎么算学完、学分怎么拿
- 学完会用每日一练和问柚子

## 学堂首页
从上往下是：搜索、继续学习、四个入口（学习地图、每日一练、考试与证书、知识库）、我的必修、学习地图、知识中心、榜单。

- **我的必修**：按你的部门、岗位自动派给你的课，有截止日，新员工入职就带上。
- **学习地图**：按岗位排好顺序的一组课，一站一站往下学，学完发证书。
- **知识中心**：按分类放的课程，有汤崎之道、应知应会、行业通识、岗位技能、系统小课堂、安全、管理。
- **知识库**：原来员工培训里的培训资料和各部门文件。

## 怎么算学完
:::table 课时怎么算完成、给几个学分（默认，以后台设置为准）
课时｜怎么算完成｜学分
图文课件｜读到最后，课中小测答过｜1
视频、文件｜打开看过｜1
测验｜及格（默认 5 题、80 分）｜2
实操｜带教在岗看过，签「通过」｜3
:::

另外每日一练答完当天的题给 1 分，学完一张学习地图再给 5 分。**同一件事只给一次学分**，重学、重考不会多给。测验可以重考，第一次及格时给学分。

学习时长只在页面开着、打开课时的时候计。学分攒够了会升级，从「初试水温」开始往上升。

## 每日一练
:::steps 每天 10 题
先复习｜先出到期该复习的题，忘得快的出得勤
再学新｜再补几道新题，来自你已经开始学的课和派给你的课
答题｜选择题自动判对错；问答卡看完答案，自己评「忘了、模糊、记得、很熟」
拿学分｜答完当天的题得 1 学分，还记连续天数
:::

系统会按你答题的情况算每个知识点掌握得怎么样，在「我的」里列出薄弱的知识点，测验也会多抽你没掌握的。

## 问柚子
课程页里可以问柚子问题。柚子**只按这门课的课件回答**，并写明出自哪个课时；课件里没讲到的，它会请你去问主管。每人每天能问的次数有上限。

:::warn 别想着刷分
同一件事只给一次学分；问答卡评分要诚实，评「很熟」但其实不会，下次就很久才出，最后吃亏的是自己。
:::

:::check
同一门课的测验第二次又考及格了，会再给一次学分吗？
- [ ] 会，每次及格都给
- [x] 不会，学分只在第一次及格时给
- [ ] 会，而且翻倍
解析：学分流水同一件事只给一次，重学、重考不会多给。测验可以重考，但学分只在第一次及格时给。
:::

## 本课小结
- 学堂首页：继续学习、四个入口、我的必修、学习地图、知识中心、榜单
- 图文读完、测验及格、实操签「通过」才算完成，同一件事只给一次学分
- 每日一练每天 10 题；问柚子只按课件回答，课件没讲的问主管
