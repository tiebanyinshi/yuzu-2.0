# 课时 key=intro min=6：走进汤崎
上班第一天，你在大厅整理拖鞋。一位客人走过来问：「你们这儿除了泡澡，还能干点啥？」你张了张嘴，一下子说不全。

这一课就帮你把门店「是做什么的」说清楚。

## 本课目标
- 学完能用一两句话向客人介绍门店有哪些服务
- 学完能说出我们平时服务的几类客人
- 学完能说出门店一天里几个关键的时间段

## 我们是做什么的
汤崎（汤崎汤泉生活）是一家汤泉门店。客人来这里，可以泡汤、洗浴、做按摩放松，也能吃饭、休息、住宿和娱乐。

:::table 门店的几块业务
业务｜客人在这里做什么
汤泉与浴区｜泡汤、淋浴、蒸房、搓澡、休息
保健按摩｜按摩、足疗等放松项目
餐饮｜在餐厅用餐，在水吧、果吧点饮品和水果
客房｜休息、过夜，或订派对房和朋友聚会
娱乐｜在娱乐区域休闲、和朋友一起玩
:::

具体有哪些项目、多少钱，**一律以门店价目表为准**。客人问到价格，带他看价目表或请前台说明，不要凭记忆报数。

:::tip 一句话介绍门店
「我们这里能泡汤洗浴、做按摩放松，也能吃饭、休息和住宿。进门领一张手牌，全店消费都记在手牌上，走的时候到前台一起结账。」
:::

## 我们服务谁
- **散客**：第一次来或偶尔来的客人，最需要我们主动介绍和指引。
- **会员**：在店里充值办卡的客人，系统里能看到他的等级和余额。
- **结伴的客人**：家人、朋友一起来，前台会把他们的手牌绑成「同行」。
- **需要特别照顾的客人**：老人、儿童、外宾、港客等。前台发牌时可以标上客人类别（比如儿童、外宾、港客），全店刷手牌都看得到。

不管哪类客人，我们给的用心是一样的。

## 门店的一天
:::steps 跟着营业日走（时间以门店当天安排为准）
开门发牌（上午）｜发卡台刷手牌，会员是谁、还剩多少、有没有要提醒的事一眼就有；发牌前系统先过一遍风控
上钟（午后起）｜钟房按手牌排钟、派钟、加钟，技师在不在钟上、还剩几分钟都看得到
开饭（傍晚）｜点单直接进后厨的出品口，水吧、果吧各管各的；填了房号就知道送到哪间房
清台清房（晚上）｜房态中心看全部房间：在用、待清、维修；退房、换房、打扫完成都在一张图上
交班日结（深夜）｜每个钱箱各自交班，日结单把储值、现金、线上收款一行行对齐，对不上先说出来
:::

:::cards 记一记这几个词
手牌｜客人在店的消费凭证，项目都挂在上面，离店到前台统一结账
上钟｜技师开始为客人服务
钟房｜给技师排钟、派钟、加钟的地方
日结｜一天营业结束后，把各种收款对齐、核清
:::

:::check
客人在店里点了按摩和饮品，一般什么时候付钱？
- [ ] 每点一样，当场付一样
- [x] 都挂在手牌上，离店时到前台统一结账

解析：手牌是客人在店的消费凭证，各部门把项目挂到手牌上，客人离店时到收银台按手牌统一结账。
:::

## 本课小结
- 汤崎是汤泉门店：汤泉浴区、保健按摩、餐饮、客房、娱乐都有
- 一张手牌全店通用，离店统一结账；价格以门店价目表为准
- 一天大致是：开门发牌、上钟、开饭、清台清房、交班日结

# 课时 key=service min=7：我们的服务理念
你抱着一摞毛巾往浴区走，看见池边一位老人慢慢挪步，脚下有一摊水。你手上的活很急。这时候，先送毛巾，还是先管老人？

这一课讲我们做服务的几条理念，每一条都落到「具体怎么做」。

## 本课目标
- 学完能说出五条服务理念
- 学完能把每条理念变成一个具体动作
- 学完遇到冲突时，知道先顾哪一头

## 五条服务理念
:::table 理念与做法
理念｜意思｜要做到
以客为先｜客人的需要排在前面｜客人开口时停下手里的活，先回应
主动服务｜不等客人叫｜看到、听到、想到，就先开口问
细致入微｜小事做到位｜拖鞋摆正、毛巾叠好、提醒带好随身物品
安全第一｜人的安全最重要｜有危险先处理，别的事往后放
团队协作｜一家店是一个整体｜不归我管的事也接住，交到对的人手上
:::

## 主动服务的三个时机
:::tip 看到、听到、想到
- 看到：客人东张西望、拿着手牌找柜子，主动问「请问需要帮忙吗」
- 听到：客人说「好热」「有点渴」，主动建议休息、递水
- 想到：客人要去浴区，提醒「地面湿滑，请慢走」
:::

## 首问负责
客人第一个问到谁，谁就负责到底。不是说你要自己全部解决，而是要把事情**交到对的人手上**，并告诉客人接下来会怎样。

比如客人说房间空调不凉：你不会修，但你要说「我马上请工程部的同事过来，您稍等几分钟」，然后真的去报。

:::ban 这些话不要说
- 「不知道。」
- 「这不归我管。」
- 「你自己去前台问。」
- 「规定就是这样。」（不解释原因）
:::

## 安全永远排第一
:::warn 有冲突时这样排
- 先管人的安全，再管手上的活
- 先管眼前的危险，再管事后的追责
- 拿不准时，先报值班经理
:::

:::scenario 池边的老人
你抱着毛巾往浴区走，看见一位老人在湿滑的池边慢慢走，脚下有一摊水。毛巾那边也在催。
- [x] 先把毛巾放到干净安全的地方，上前扶老人走过湿滑地面，再通知同事拖干｜做得对。安全第一，毛巾晚几分钟没关系，老人滑倒后果很严重。
- [ ] 先把毛巾送到，回来再看老人｜不妥。这几分钟里老人可能已经滑倒，安全的事不能往后放。
- [ ] 远远喊一声「小心地滑」就走｜不够。喊一声有用，但老人行动慢，最好上前扶一把，并把水处理掉。
:::

:::check
客人问你一件不归你管的事，下面哪种做法符合「首问负责」？
- [ ] 告诉客人去找负责的部门
- [x] 自己把事情转给负责的同事，并告诉客人大概多久有人来
- [ ] 说「我是新来的，不清楚」
解析：首问负责不是要你什么都会，而是要你把事情交到对的人手上，并让客人知道接下来会怎样。
:::

## 本课小结
- 五条理念：以客为先、主动服务、细致入微、安全第一、团队协作
- 首问负责：不会的也接住，交到对的人手上
- 有冲突时，人的安全永远排第一

# 课时 key=etiquette min=8：服务礼仪基本功
走廊里，一位客人迎面走来想问路。你正低着头看手机，一只手插在口袋里。客人犹豫了一下，转身去找别人了。

礼仪不是摆样子，它让客人一眼就敢来找你。

## 本课目标
- 学完能按要求整理好仪容仪表
- 学完能用规范的问候、称呼和手势引领客人
- 学完会接电话、用对讲机，会正确递物

## 仪容仪表
:::table 上岗前对照检查
项目｜要求
工服｜干净平整，扣子扣好，按门店规定穿着
工牌｜戴在规定位置，正面朝外
头发｜干净整齐，长发按门店规定束起
手和指甲｜干净，指甲短，不涂夸张的颜色
气味｜没有烟味、酒味和刺鼻香水味
首饰｜按门店规定，简单不夸张
:::

## 微笑与问候
:::steps 见到客人这样做
看｜客人走近时抬头，看着客人的眼睛
笑｜面带自然的微笑
问候｜走到跟前时主动开口：「您好，欢迎光临。」
询问｜「请问有什么可以帮您？」
:::

**称呼**：成年男士称「先生」，女士称「女士」；知道姓的用「姓氏加先生或女士」；小朋友叫「小朋友」。不叫「喂」，不叫「哎」，不用外号。

## 站姿与引领
- 站姿：抬头挺胸，双手自然交叠放在身前，不倚墙、不靠台、不抖腿。
- 引领：走在客人侧前方一两步，五指并拢、手心向上指方向，说「这边请」。
- 转弯、上下台阶、地面湿滑的地方，提前提醒「请小心台阶」「地面湿滑，请慢走」。

## 电话与对讲机
:::tip 接电话
- 尽快接起，先报部门再问候：「您好，前台。」
- 听清需求，重要内容复述一遍再确认
- 等对方先挂断，再轻轻放下
:::

:::ban 对讲机里不能说的话
- 不在客人听得见的地方说客人的姓名、手机号、余额
- 不抱怨、不开玩笑、不说脏话
- 不占着频道聊天，说完就松开
:::

对讲机的说法：先叫对方，再报自己，再说事。例如：「前台呼叫工程部，我是前台，男宾浴区有一处漏水，请过来看一下。」

## 递物
- 用双手递，身体稍向前倾。
- 单据、卡片文字正面朝向客人。
- 笔、剪刀这类尖的东西，尖头朝向自己。

:::check
引领客人去浴区时，下面哪种做法是对的？
- [ ] 走在客人正后方，用手指一指方向
- [x] 走在客人侧前方一两步，五指并拢指方向，湿滑处提前提醒
- [ ] 告诉客人「直走右拐」，自己继续忙
解析：引领要走在侧前方、手心向上五指并拢，遇到转弯、台阶、湿滑地面提前提醒。
:::

:::check
在客人能听见的地方，用对讲机说客人的手机号和余额也没关系。
答案：错
解析：客人的姓名、手机号、余额都是个人信息，不能在客人听得见的地方通过对讲机说。
:::

## 本课小结
- 上岗前照表检查仪容仪表
- 看、笑、问候、询问；称呼用「先生、女士」，不叫「喂」
- 电话先报部门，对讲机先叫对方再报自己，递物用双手、尖头朝自己
