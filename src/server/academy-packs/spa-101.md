# 课时 key=china min=6：中国的汤泉与沐浴传统
一位老先生泡完汤，在休息区跟你闲聊："你们叫汤泉，'汤'不是喝的汤吗？"你笑了笑，却不知道怎么接。这节课讲讲中国人洗澡的老传统，下次客人问起，你能聊上几句。

## 本课目标
- 学完能说出「汤」「沐浴」这几个字的老意思
- 学完能讲出一两个历史上有名的温泉地和老行当
- 学完能说清北方洗浴中心是怎么来的

## 「汤」原来是热水
古人把热水叫「汤」。成语「赴汤蹈火」里的「汤」，就是滚烫的开水。

所以温泉在古代常被叫作「汤泉」「温汤」。今天不少地名带「汤」字，比如北京的小汤山、南京的汤山，都和温泉有关。

「沐浴」两个字也有讲究：**「沐」是洗头，「浴」是洗身子**。汉代官员有固定的「休沐」日，就是放假回家洗洗、歇一歇。

## 历史上有名的温泉地
最有名的是西安骊山脚下的**华清池**。唐代皇家在这里修了华清宫。白居易的《长恨歌》里写「春寒赐浴华清池，温泉水滑洗凝脂」，说的就是这里。

## 宋代的「香水行」
到了宋代，城里有了对外营业的公共浴堂。宋代的笔记里记着，杭州人把开浴堂的叫作**「香水行」**。

那时已经有给人搓背的师傅。苏东坡在浴堂里写过一首小词，有一句「寄语揩背人，尽日劳君挥肘」。「揩背人」就是搓背的师傅。

## 近代的澡堂：搓澡、修脚
明清到民国，城里的澡堂子越来越多：有大池子，有搓澡、修脚、敲背的师傅，洗完还能躺下喝茶、聊天、睡一觉。

扬州有句老话叫「早上皮包水，晚上水包皮」：早上喝茶吃点心，晚上去澡堂泡澡。修脚刀和厨刀、剃头刀一起，被叫作「扬州三把刀」。

## 北方洗浴中心
近几十年，北方（特别是东北）兴起了大型洗浴中心：洗浴、搓澡、汗蒸、按摩、自助餐、休息大厅都在一个地方，可以待一整天，甚至过夜。今天的汤泉门店，很多做法就是从这里发展来的。

:::steps 一条时间线
唐代｜华清宫里的皇家温泉
宋代｜城里有了公共浴堂「香水行」，已有搓背师傅
明清到民国｜澡堂子遍布城里，搓澡、修脚、喝茶休息
近几十年｜北方大型洗浴中心兴起，吃喝休息都在里面
今天｜汤泉门店：汤、蒸、按、食、休、娱一站式
:::

:::cards 翻一翻：老词新说
汤｜古人说的热水，所以温泉也叫汤泉、温汤
沐｜洗头
浴｜洗身子
香水行｜宋代人对公共浴堂的叫法
揩背人｜宋代对搓背师傅的叫法
:::

:::tip 跟客人聊文化，注意分寸
- 客人有兴趣再聊，不硬讲
- 只说有把握的，没把握就说「听说」
- 聊天不耽误手上的服务
:::

## 本课小结
- 「汤」是热水，温泉古称汤泉；「沐」是洗头，「浴」是洗身
- 唐代华清池、宋代香水行、近代澡堂，一路传下来
- 北方洗浴中心把洗、蒸、按、吃、休息放在一起，是今天汤泉门店的前身之一

# 课时 key=world min=6：世界的沐浴方式
一位刚从日本旅游回来的客人问你："你们这儿毛巾能放进池子吗？在日本可不行。"另一位客人说想试试"芬兰那种蒸法"。客人见多识广，我们也要知道外面的人是怎么洗澡的。

## 本课目标
- 学完能说出日本、芬兰、土耳其、古罗马、韩国五种沐浴方式的特点
- 学完能听懂客人说的「钱汤」「桑拿」「哈曼浴」「汗蒸」是什么

## 日本：温泉和钱汤
日本有很多天然温泉。城里还有烧热水的公共澡堂，叫「钱汤」，就是交钱洗澡的地方。

日本泡汤规矩多：先在池外把身体洗干净再下池；毛巾不放进池水里；不在池里搓洗。这些规矩都是为了让池水保持干净。

## 芬兰：桑拿
芬兰桑拿是一间木头小屋，炉子把石头烧热，人坐在木凳上出汗。往热石头上浇一勺水，会腾起一阵热蒸汽。蒸完去冲冷水，有人还会跳进湖里，再回来接着蒸。

芬兰的桑拿文化已被列入联合国教科文组织的人类非物质文化遗产名录。

## 土耳其：哈曼浴
土耳其浴叫 hammam（哈曼浴）。它是大理石砌的蒸汽浴室，中间常有一块温热的大理石台，人躺在上面慢慢出汗。然后搓澡师傅戴着粗糙的手套给你搓澡，再打上厚厚的泡沫清洗、按摩。和我们的搓澡有点像。

## 古罗马：公共浴场
古罗马时期，城里建了很多大型公共浴场。里面有热水池、温水池、冷水池，还有运动场、花园。人们在这里洗澡、聊天、谈事情，洗澡在古罗马是一件社交的事。

英文里的 spa，一般认为来自比利时一个以矿泉出名的小镇 Spa。

## 韩国：汗蒸
韩式汗蒸房温度不像桑拿那么高，墙面、地面常用黄土、玉石、盐之类的材料，人躺着慢慢出汗。客人穿统一的汗蒸服，男女可以在公共区域一起休息，很多人喜欢吃烤鸡蛋、喝甜米露。

:::table 五种沐浴方式一张表
地方｜叫法｜最大的特点
日本｜温泉、钱汤｜先洗净再下池，毛巾不进池
芬兰｜桑拿｜烧热石头、浇水出蒸汽，蒸完冲冷水
土耳其｜哈曼浴｜大理石蒸汽房，搓澡加泡沫
古罗马｜公共浴场｜冷、温、热几种池子，是社交场所
韩国｜汗蒸｜温度较低，穿汗蒸服，男女可在公共区一起休息
:::

:::tip 客人提到这些，可以这样接
- 「我们这儿也是先冲淋再下池，和日本的讲究一样，池水更干净。」
- 「我们的干蒸房就是桑拿那一类，温度高、空气干。」
- 具体有哪些池子、蒸房，按门店实际介绍
:::

:::warn 只讲特点，不比较
- 介绍别处的沐浴方式，只讲特点，不说谁好谁坏
- 不拿别的门店来比
:::

## 本课小结
- 日本讲究先洗净再下池，芬兰桑拿蒸完冲冷水，土耳其哈曼浴搓澡加泡沫
- 古罗马浴场是社交场所，韩式汗蒸温度较低、男女可在公共区一起休息
- 客人提起时只讲特点，不比较、不贬低

# 课时 key=today min=6：今天的汤泉门店是什么
新来的同事问："我在餐饮部上班，又不管泡澡，学这些干嘛？"其实客人来一趟，泡汤、吃饭、按摩、休息都在我们这儿。哪一站没做好，客人记住的都是"这家店"。

## 本课目标
- 学完能说出「汤、蒸、按、食、休、娱」六件事分别是什么
- 学完能说出客人来汤泉门店的几种常见原因
- 学完明白自己的岗位在客人这一天里的位置

## 一站式：六件事
:::table 汤、蒸、按、食、休、娱
一个字｜指什么｜主要由谁负责
汤｜各种泡池、淋浴｜男宾部、女宾部（浴区）
蒸｜干蒸、湿蒸、汗蒸｜浴区
按｜按摩等保健项目｜保健部、康美部的技师
食｜自助餐、点餐、饮品｜餐饮部、出品部
休｜休息大厅、客房过夜｜休息区、客房
娱｜棋牌、游戏等娱乐｜娱乐部
:::

前厅收银管客人的进和出，工程部在背后保证水、电、热、设备正常。具体有哪些项目，以门店实际为准。

## 客人为什么来
- 放松解乏：忙了一周，来泡一泡、蒸一蒸、按一按
- 朋友家人聚会：一起泡汤、吃饭、聊天，一待半天
- 招待客户：请人来放松一下
- 过夜休息：太晚了不想回家，或者出差、等车
- 天冷暖暖身子，节假日找个去处

## 客人买的是一整天的感受
客人不会分开打分："池子不错，饭一般。"他记住的是"这家店舒不舒服"。所以：
- 每个部门都是这条链上的一环
- 前台快一点、浴区干净一点、技师用心一点、饭菜热一点，加起来才是好体验
- 一个环节出了问题，别的环节要帮着补

:::tip 通用的服务理念
让客人放心地来、舒服地待、满意地走。（门店有自己的说法，以门店为准）
:::

:::scenario 客人问到别的部门的事
你在餐厅上菜，一位客人问你："干蒸房几点关？"你不太清楚。怎么做？
- [ ] 「我是餐厅的，不知道。」｜话没错，但客人听到的是"别问我"。客人分不清部门，只认这家店。
- [x] 「您稍等，我帮您问一下，马上告诉您。」问清楚再回来回复｜客人的问题在你这里有了着落，这就是一站式服务该有的样子。
- [ ] 随口说一个大概的时间｜说错了，客人白跑一趟，还会觉得被骗。
:::

:::check
汤泉门店说的「汤、蒸、按、食、休、娱」里，「按」指什么？
- [ ] 按时营业
- [x] 按摩等保健项目
- [ ] 按价目表收费
解析：「按」指保健部、康美部技师做的按摩等保健项目。
:::

## 本课小结
- 汤泉门店把汤、蒸、按、食、休、娱放在一起，客人可以待上一整天
- 客人来是为了放松、聚会、招待、过夜休息，买的是一整天的感受
- 每个岗位都是链条的一环，客人问到别的部门的事，先帮着问清楚
