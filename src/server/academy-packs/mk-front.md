# 课时 key=reception min=6：前台接待流程
周六晚上八点，前台排起了队。一家三口走进来，孩子在大厅里跑，妈妈问：「我们三个，孩子要不要门票？我上次办的卡还能用吗？」后面的客人也在等。

越忙越要按流程来，才不会发错牌、漏问事。

## 本课目标
- 学完能按五步完成一次接待
- 学完知道发牌时系统会提示哪些情况
- 学完能照顾到儿童、老人、外宾等客人

## 接待五步
:::steps 前台接待五步
迎宾｜客人进门，起身、微笑、问候：「您好，欢迎光临。」
问清｜几位、男宾还是女宾、有没有会员、有没有预约
发牌｜刷手牌或输牌号发牌，同行的客人一起发、绑成同行
交代｜手牌是消费凭证，项目都挂在上面，离店到前台结账；贵重物品请妥善保管
指引｜指明更衣和浴区的方向，需要时引领过去
:::

## 发牌时系统会提示什么
刷会员时，系统马上显示会员是谁、什么档阶、余额多少、有没有要提醒的事。发牌前还会过一遍**风控**：

:::table 发牌前的风控提示
提示｜意思｜怎么办
黑名单｜这位客人登记在黑名单里｜系统拒绝发牌，请值班经理处理
未结离店｜上次有账没结清就走了｜要值班经理及以上当场授权才能发
今天第几次到店｜当天来过又来了｜只是提示，照常发牌
预约｜今天有技师或客房预约｜系统带出来，发牌成功后自动标「已到店」
:::

发牌时还可以选**客人类别**（比如儿童、外宾、港客），填**预约的技师**，全店刷手牌都看得到。同一个区连续发了很多张，系统会提示换区，只是建议，不拦你。

:::warn 特别留意这几类客人
- 儿童：提醒家长全程看护，不让孩子单独进池、进蒸房
- 老人：提醒慢走、注意防滑，泡汤时间不要太长
- 酒后的客人：劝他先休息，别马上泡汤、进蒸房
:::

:::check
发牌时系统提示这位会员有「未结离店」，你应该？
- [ ] 当没看见，照常发牌
- [ ] 直接拒绝客人进店
- [x] 请值班经理及以上当场授权后再发牌
- [ ] 让客人先把上次的钱用微信转给你
解析：未结离店要值班经理及以上当场授权才能发牌，授权人和原因会记在这次来访上。不能私下收钱。
:::

## 本课小结
- 接待五步：迎宾、问清、发牌、交代、指引
- 黑名单拒绝发牌，未结离店要经理授权，重复到店只提示
- 儿童、老人、酒后客人要多提醒一句

# 课时 key=cashier min=8：发卡台与收银台
客人在收银台买单，看了一眼账单说：「按摩这项给我打个八折吧，我经常来。」你记得自己好像能打折，但不确定能打多少。

收银台上的每一个按钮都连着钱，规矩要先弄清楚。

## 本课目标
- 学完能说清发卡台和收银台各做什么
- 学完知道有哪些收款方式、怎么组合
- 学完知道打折、免单、押金的规矩

## 两个台各做什么
:::table 发卡台与收银台
发卡台（客人进门）｜收银台（客人买单）
接待发牌、换牌｜加项目、买角
同行组合与拆分｜作废、退菜、改票种
异常处置（提醒、外出、上报等）｜单项打折、手牌押金
写备注（客诉、特殊关照）｜预结账、打单、买单
:::

:::warn 「挂账」有两个意思
- 把项目记到客人的手牌上，系统叫「挂账」，就是挂项目
- 收款方式里的「挂账」，是协议单位记账、以后统一回款，要按门店规定办
:::

## 收款方式
结账时可以用：现金、微信、支付宝、银行卡、会员储值、团购券、次卡、券抵扣、协议单位挂账等。几种方式可以混着用，比如一部分刷会员储值、剩下的付现金。**几笔加起来正好等于应收**，才能结清。

## 打折和免单的规矩
- **单项打折**：账单每一行可以打折。每个岗位能打到的最低折扣不一样，后台设置；超过自己权限的，页面会弹「请经理授权」，由有权限的人当场授权。
- 门票不能单项打折，要降价请改票种。
- 打过单项折扣的行，不再用会员折扣、券、次卡，不会折上加折。
- **整单优惠、免单**、改成免票等，要值班经理及以上当场授权，收银员不能自己抹零。
- 改价、打折、赠送的行都会标出来，写清是谁打的、谁授权的。

## 手牌押金
客人外出留牌、去其他区域、借用物品时，可以「收押金」，金额默认按门店规定。可以收现金、微信、支付宝、银行卡，或从这张手牌上会员的储值扣。回来点「一键退」，结账时也可以抵扣。押金不是营业额，现金押金交班时算进应有现金。

:::ban 收银禁忌
- 不用个人收款码收客人的钱
- 不自己抹零，不私下给折扣
- 不替客人「先记着下次再付」
- 不在客人面前和同事讨论客人的消费
:::

:::scenario 客人要打八折
客人买单时说：「按摩这项给我打个八折吧，我经常来。」八折超出了你这个岗位能打的范围。
- [x] 礼貌地说「我帮您请示一下经理」，在系统里申请经理授权，经理同意后再打｜做得对。超出权限的折扣走「请经理授权」，授权人会留名，账清清楚楚。
- [ ] 为了留住熟客，自己先打了，事后再跟经理说｜不行。超出权限系统也不会让你打；私下给折扣是收银的大忌。
- [ ] 直接说「不能打折」就结账｜不够好。客人的要求可以请示，按规矩走授权，不要一口回绝。
:::

:::check
客人要求抹零时，收银员可以自己把整单的零头抹掉。
答案：错
解析：整单优惠、免单要值班经理及以上当场授权，收银员不能自己抹零。
:::

## 本课小结
- 发卡台管进门：发牌、换牌、同行、异常；收银台管买单：加项目、打折、押金、结账
- 收款方式可以组合，合计等于应收才能结清
- 超权限的打折、整单优惠、免单都要经理当场授权

# 课时 key=pending min=7：「结果待确认」与交班
你正在给客人结账，刚点了确认，网突然断了。页面转了半天，跳出「结果待确认」。客人皱着眉问：「我到底付成功没有？要不要再扫一次？」

这时候最怕的，是重复收客人的钱。

## 本课目标
- 学完知道「结果待确认」是什么意思、为什么不能当没成功
- 学完会按正确的顺序处理「结果待确认」
- 学完会开班、交班，知道长款短款怎么写

## 为什么不能当没成功
网断了、超时了、服务器出错了，页面拿不到回复，但**这笔可能已经记上了**。如果你当它没成功，再收一次，客人就被扣了两次钱。所以系统会把这笔记在本机，标成「结果待确认」。

:::steps 正确的处理顺序
先稳住｜告诉客人「我核对一下，请稍等」，不让客人再付一次
查回结果｜在对话框里点「查回结果」，或点页面顶上的「去处理」
查到已生效｜这一笔已经成功，而且只生效一次，不用再做
查不到｜不能断定没成功；可以「按原内容重新提交」（同一个编号只生效一次），或「确认作废，重新填写」
:::

:::ban 千万别这样做
- 不换一个新单重新收一遍
- 不让客人再扫一次码、再刷一次卡
- 不清浏览器数据，不换电脑重做同一笔
:::

如果本机连「结果待确认」都存不下，系统**这一笔就不提交**，提示你换一台终端办理。这是为了防止断网以后重复收款。

## 开班与交班
收款之前要先**开班**：登记钱箱里的备用金。门店用「按人交班」还是「按钱箱交班」，以后台设置为准：

- 按人交班：一人一个班次，自己交自己的班。
- 按钱箱交班：同一个钱箱的人「加入」同一个班次；下班时可以「离开钱箱」，钱等交班时一起点。

**交班**时数清钱箱里的现金，填「实点现金」。系统按备用金加上收的现金、减去退的现金算出「应有现金」。对得上显示「与应有一致」；对不上会显示长款或短款，要在「交班备注」里写清原因，再打印交班表。

:::warn 交班要注意
- 收款开始时所在的班次，在入账前已经交班了，这一笔会被整笔拒绝，要重新办理
- 现金押金算进应有现金；储值扣的押金不算钱箱里的钱
- 一天结束后，值班经理和财务会把储值、现金、线上收款对齐做日结
:::

:::check
结账时页面显示「结果待确认」，查回结果暂时查不到。下面哪种做法是对的？
- [ ] 查不到就是没成功，请客人再扫一次码
- [x] 按原内容重新提交，或确认作废后再重新填写
- [ ] 换另一台电脑重新结一次
- [ ] 先让客人走，下次来再说
解析：查不到不能断定没成功。按原内容重新提交用的是同一个编号，服务器保证只生效一次；或者先确认作废，再重新填写。
:::

:::check
交班时实点现金比应有现金少，这叫什么？
- [ ] 长款
- [x] 短款
- [ ] 平账
解析：实点比应有少是短款，多是长款。对不上都要在交班备注里写清原因。
:::

## 本课小结
- 「结果待确认」可能已经成功，绝不能重复收款
- 先查回；查不到就按原内容重新提交，或确认作废后重填
- 收款前先开班；交班实点现金，长短款写清原因

# 课时 key=special min=6：客诉与特殊情况
晚上十一点，一位客人带着很重的酒气走到前台，大声说：「给我开个牌，我要去泡最热的那个池子！」同行的朋友在旁边扶着他。

前台是客人进门的第一站，也是很多问题的第一站。

## 本课目标
- 学完能劝阻醉酒客人泡汤，并安排照看
- 学完知道客人丢了东西、员工捡到东西怎么办
- 学完会按五步处理客诉，并在系统里登记

## 醉酒的客人
:::tip 怎么劝
- 语气温和，先关心：「您今天喝了点酒，现在泡热池容易头晕。」
- 给替代建议：先到休息区喝点水、休息一会儿再说
- 请同行的朋友帮忙照看，不让他一个人进浴区
- 在客人卡上写备注（选「特殊关照」），提醒全店同事留意
- 客人吵闹、不听劝，马上报值班经理
:::

:::scenario 醉酒客人要泡热池
一位酒气很重的客人坚持要马上去泡最热的池子，朋友扶着他，他有点站不稳。
- [x] 温和劝他先去休息区喝水休息，请朋友照看，写一条「特殊关照」备注，并告诉值班经理｜做得对。先保安全，再给替代办法，让全店同事都知道要留意他。
- [ ] 客人是上帝，他要泡就让他去｜不行。酒后泡热池容易晕厥、滑倒，出了事后果很严重。
- [ ] 板着脸说「喝酒的不让进」｜不妥。可以劝阻，但要讲清原因、给出替代办法，态度要好。
:::

## 丢失物品
- **客人说丢了东西**：先安抚，问清什么时候、在哪里、什么东西；马上报值班经理，按门店规定登记、查找。不随口承诺赔偿。
- **员工捡到东西**：交到前台，按门店规定登记，等失主来认领。不私藏，不随便交给自称失主的人。

## 客诉五步
:::steps 处理客诉
倾听｜让客人把话说完，不打断，不辩解
致歉｜为客人的感受道歉：「让您不愉快了，非常抱歉。」
记录｜记下时间、地点、事情经过和客人的要求
处理或上报｜自己权限内的马上办，办不了的交给值班经理
跟进｜处理完回访客人，确认他满意
:::

**在系统里登记**：在发卡台或收银台的客人卡上写一条「备注」，标签选「客诉」或「特殊关照」，收银台的待结账清单上就会标出来。值班经理在「客诉台账」里看所有客诉，处理完点「标已处理」写结果，还可以打印台账。

客人在店时间特别长、或者挂账金额特别高时，手牌会标红「高风险」，发卡台顶上会写「高风险几位」。看到了要留意，按门店规定提醒客人或报值班经理。

:::check
处理客诉时，下面哪一步应该放在最前面？
- [x] 让客人把话说完，不打断
- [ ] 先解释是客人自己的问题
- [ ] 先告诉客人「这不归我管」
- [ ] 先说门店的规定
解析：客诉五步：倾听、致歉、记录、处理或上报、跟进。先让客人说完，情绪才能降下来。
:::

## 本课小结
- 醉酒客人：温和劝阻、给替代办法、请人照看、写备注、报经理
- 丢物：问清、上报、登记，不乱承诺；捡到交前台
- 客诉五步：倾听、致歉、记录、处理或上报、跟进；备注选「客诉」标签

# 实操 key=practice：前台接待与结账全流程
- 起身微笑问候，问清人数、男宾女宾、是不是会员、有没有预约
- 刷手牌或手输牌号发牌，同行客人一起发、绑成同行
- 看清并正确处理风控提示：黑名单、未结离店、重复到店、预约
- 向客人交代手牌的用途和离店结账，指引更衣方向
- 买单前打开预结账，和客人逐项核对明细与门票
- 按客人选择收款，合计等于应收才结清，储值和押金处理正确
- 单项打折、免单、改票种按权限办理，超出权限请经理授权
- 遇到「结果待确认」先查回，不重复收款
- 递交结账单、礼貌道别，提醒客人带好随身物品
- 交班时实点现金，长短款写明原因，打印交班表

- [ ] 这笔一定没成功
- [ ] 这笔一定成功了
- [x] 页面没拿到回复，这笔可能已经成功，要先核对
- [ ] 系统坏了，要重启电脑
解析：网断、超时或服务器出错时，页面拿不到回复，但请求可能已经记上了，所以要先查回核对。
:::

:::question single skill=结果待确认 level=3
结账时网断了，页面显示「结果待确认」。客人说：「我再扫一次码吧，省得你麻烦。」你应该？
- [ ] 让客人再扫一次，多收的下次退
- [x] 请客人稍等，先点「查回结果」核对，不让客人重复付款
- [ ] 换一台电脑给客人重新结账
- [ ] 让客人先走，等网好了再说
解析：「结果待确认」时最怕重复收款。先请客人稍等，查回结果；查到了就不用再做，查不到再按原内容重新提交或确认作废。
:::

:::question recall skill=结果待确认 level=2
「结果待确认」时查回结果查不到，可以怎么做？
答：查不到不能断定没成功。可以「按原内容重新提交」，同一个编号只生效一次；或者「确认作废，重新填写」，作废以后原来的请求就算到了也不会生效。
:::

:::question single skill=交班日结 level=2
交班时，「应有现金」大致怎么算？
- [ ] 当班所有收款加起来
- [x] 备用金加上收的现金，减去退的现金
- [ ] 实点多少就是多少
- [ ] 只算会员储值
解析：应有现金按备用金加上本班收的现金、减去退给客人的现金来算，微信、支付宝、储值不在钱箱里。
:::

:::question single skill=交班日结 level=3
交班时实点现金比应有现金多了一些，你应该？
- [ ] 把多出来的钱拿走，账就平了
- [ ] 不说，下次短款时补上
- [x] 照实填实点现金，在交班备注里写清可能的原因，交给值班经理核对
- [ ] 改一下备用金让它对上
解析：长款、短款都要照实填，在交班备注里写原因，由值班经理核对。不能拿走、不能拖、不能改数凑平。
:::

:::question single skill=客诉处理 level=3
一位酒气很重的客人坚持要去泡热池，同伴扶着他。你怎么做最合适？
- [ ] 他是成年人，自己负责，让他去
- [ ] 直接说「喝酒的不让进」
- [x] 温和说明酒后泡热池的风险，建议先到休息区喝水休息，请同伴照看，写「特殊关照」备注并告诉值班经理
- [ ] 收一笔押金后让他去
解析：酒后泡热池容易头晕、晕厥。要温和劝阻、给替代办法、请同伴照看，在系统里写备注让全店留意，并报值班经理。
:::

:::question multi skill=客诉处理 level=2
客诉处理五步包括哪些？
- [x] 倾听
- [x] 致歉
- [x] 记录
- [x] 跟进
- [ ] 争辩
解析：客诉五步是倾听、致歉、记录、处理或上报、跟进。和客人争辩只会让情况更糟。
:::

:::question recall skill=客诉处理 level=1
在系统里怎么登记一条客诉？
答：在发卡台或收银台的客人卡上写一条「备注」，标签选「客诉」或「特殊关照」。值班经理在「客诉台账」里查看，处理完点「标已处理」写结果。
:::
