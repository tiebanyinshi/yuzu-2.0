# 课时 key=patrol min=6：浴区岗位与巡查
周末晚上，浴区客人很多。你刚接班，就看见热池边有一摊沐浴露泡沫，一位老先生正扶着墙慢慢走过来。这时候你先做什么？浴区岗位最要紧的事，就是在出事之前把问题看出来。

## 本课目标
- 学完能说出浴区巡查要看的四样：地面、水温、设施、客人状态
- 学完能按固定路线巡一圈，不漏地方
- 学完能分清哪些事当场处理、哪些事马上报告

## 浴区岗位做什么
浴区岗位不只是递毛巾、收拖鞋。你是客人在浴区里离得最近的员工。

- **看**：客人安不安全，地面、池子、设施正不正常
- **管**：布草够不够、干不干净，物品摆没摆好
- **帮**：客人找东西、问路、不舒服时，你第一个到
- **报**：自己处理不了的，马上报告当班主管

:::warn 男宾区、女宾区
- 浴区岗位一般由同性员工负责，按门店规定安排
- 异性同事（比如维修人员）要进浴区，按门店规定先通报、提醒客人，由本区员工陪同
- 浴区里不拍照、不录像，也不让别人拍
:::

## 按固定路线巡
巡查要按门店规定的时间、走门店定好的路线，每次完整走一圈。路线固定了，才不会漏掉角落。

:::steps 巡一圈的顺序（示例，以门店实际路线为准）
入口与更衣区｜地面有没有水，拖鞋摆没摆好，有没有客人落下的东西
淋浴区｜冷热水、水压正不正常，洗浴用品够不够，地漏有没有堵
池区｜看水温显示，池水清不清，池边有没有积水杂物，池里客人状态
桑拿房与蒸房｜先从门上的窗看里面有没有人倒下，再看温度显示
休息区与卫生间｜有没有客人睡着叫不醒、喝多了、身体不舒服
回到岗位｜把发现的问题处理掉或报告，补齐布草
:::

## 巡查看什么
:::table 四样必看
看什么｜正常的样子｜要处理的情况
地面｜干，没有泡沫和头发｜有积水、泡沫、碎玻璃，防滑垫翘起
水温｜显示在门店规定的范围内｜明显偏高或偏低，显示坏了
设施｜灯亮，门好开，扶手牢固｜漏水、漏电、有异响，门打不开
客人状态｜神态正常，走路稳｜脸色发白、走路摇晃、叫不醒、酒气重
:::

:::tip 当场处理还是马上报告
- 地面湿滑、有杂物、布草不够：当场处理
- 设备坏了、漏水漏电、水温异常：先把客人隔开，再报告
- 客人不舒服、醉酒、受伤：先照看客人，同时叫同事报告主管
:::

:::warn 别只站在岗位上看
很多意外发生在没人看的角落。巡查要走到每个地方，不能隔远望一眼就算。
:::

:::check
巡查时发现淋浴区地漏堵了、地面积水，正确做法是？
- [ ] 等下一班的同事来了再说
- [x] 先放「小心地滑」提示、清理积水，处理不了的马上报告
- [ ] 只提醒客人小心
解析：积水容易让客人滑倒。先把危险隔开（放提示牌、清理），自己处理不了的设施问题再报告。
:::

## 本课小结
- 浴区岗位要做到「看、管、帮、报」
- 按固定路线巡一圈，每个地方都要走到
- 四样必看：地面、水温、设施、客人状态

# 课时 key=pools min=6：池水、温度与设施检查
开门前你走到热池边，伸手一试，感觉比平时烫，可温度显示看起来正常。是信手感，还是信显示？两样都别只信一样：觉得不对就报告，请工程同事核实。

## 本课目标
- 学完能说出热池、冷池、桑拿房、蒸房各要检查什么
- 学完能看懂温度显示，发现异常知道怎么处理
- 学完能判断池水出现什么情况要马上报告

## 先看显示，再看实物
温度以设备显示和门店规定为准。下面是行业里一般的情况，只用来帮你判断「明显不对」。

:::table 常见区域的一般情况（以门店规定为准）
区域｜一般温度｜重点看
热池｜一般 38–42℃｜水温显示，池水清不清，池边防滑
冷池｜一般 10–18℃｜水温，池边扶手，客人进出别太急
桑拿房（干蒸）｜一般 70–90℃，比较干｜温度显示，炉子护栏，木凳有没有裂
蒸房（湿蒸）｜一般 40–50℃，湿度很高｜蒸汽出口护罩，地面湿滑，照明
:::

## 池水看什么
- **清**：能看清池底。浑浊、发绿、有漂浮物都不对
- **味**：有臭味，或者消毒水味特别刺鼻，要报告
- **量**：水位正常，溢水口没有堵
- **净**：池边没有头发、杂物、垃圾

池水的循环过滤、消毒、换水，由工程或专人按门店规定做。国家标准 GB 37488-2019《公共场所卫生指标及限值要求》对池水的卫生指标有要求，怎么检测由专人负责。你的事是及时发现、及时报告。

:::warn 池水被污染了
- 有呕吐物、粪便、血迹：马上请客人离开这个池，放提示牌，报告主管按门店流程处理
- 浑浊、有异味：报告，等专人确认后再开放
- 不要自己往池里加药剂
:::

## 设施检查
:::steps 开门前和巡查中
看温度显示｜热池、冷池、桑拿房、蒸房的显示亮着，读数在门店规定的范围里
看门和窗｜桑拿房、蒸房的门推得开，门上的玻璃窗看得清里面
看紧急呼叫｜有紧急呼叫按钮的，确认它没有被挡住、好按
看扶手和台阶｜扶手牢固，台阶的防滑条没有脱落
看电和水｜没有漏水，没有电线露在外面，没有焦味
:::

:::ban 不要这样做
- 不要在桑拿炉上放毛巾、衣物，容易起火
- 不要自己拆修设备，交给工程同事
- 温度明显异常时，不要继续让客人使用
:::

:::check
热池水温显示明显比门店规定的高，你应该怎么做？
- [ ] 跟客人说水热一点更舒服
- [x] 提醒池里的客人先出来，放提示牌，报告工程同事核实
- [ ] 自己去把加热开关关掉
解析：水温过高容易烫伤、晕堂。先保护客人，再交给工程同事处理，不自己动设备。
:::

## 本课小结
- 温度以设备显示和门店规定为准，明显不对就报告
- 池水看清、味、量、净，被污染了马上停用这个池
- 设备的问题交给工程同事，自己不拆不修

# 课时 key=safety min=7：客人安全
一位男宾刚吃完饭、喝了不少酒，说要去桑拿房「蒸一蒸醒醒酒」。几分钟后你巡到桑拿房，看见他靠在墙上，脸色发白。浴区又热又滑，客人出事往往就在几分钟之内。

## 本课目标
- 学完能说出浴区五类常见风险：滑倒、醉酒、晕堂、老人小孩、贵重物品
- 学完能在客人晕堂时按步骤处理
- 学完能礼貌地劝阻不适合泡汤的客人

## 防滑
- 地面随时保持干，发现积水马上拖
- 防滑垫要铺平，翘起来的压好或换掉
- 拖地时放「小心地滑」提示牌
- 提醒客人慢慢走、扶好扶手，特别是进出池子、上下台阶的时候

## 哪些客人要多留意
:::table 多留意的客人
客人｜风险｜怎么做
喝了酒的｜容易晕倒、滑倒、溺水｜劝他先到休息区喝水休息，不进热池和桑拿
刚吃饱或空着肚子的｜容易头晕、恶心｜建议先休息一会儿再泡
老人｜体力弱，起身容易头晕｜提醒慢慢起身，进出池子时多看着
小孩｜容易滑倒、溺水｜要有大人陪着，按门店规定
说自己有心脏病、高血压或怀孕的｜高温下风险高｜提醒不要高温久泡，身体不适先咨询医生
:::

:::tip 劝阻怎么说
先关心，再说原因，最后给个别的办法。例如：「您刚喝了酒，热池和桑拿容易头晕，先到休息区喝点温水歇一会儿，好吗？」
:::

## 晕堂怎么处理
晕堂是在高温的地方待太久，出现头晕、心慌、恶心、脸色发白、出冷汗，严重的会晕倒。

:::steps 发现客人晕堂
喊人｜大声叫附近的同事帮忙，请一个人去报告主管
离开高温｜扶客人离开池子或桑拿房，到通风、凉快的地方坐下或平躺
照看｜松开过紧的浴巾，用温凉的毛巾擦脸；客人清醒、能喝的，再慢慢喝点温水
叫急救｜叫不醒、呼吸不正常、抽搐、说胸口痛的，马上拨打 120，请有急救证的同事处理
报告｜事后把时间、经过如实告诉主管
:::

:::ban 晕堂时不要
- 不要让客人马上冲冷水、跳冷池
- 不要给晕过去、叫不醒的客人灌水
- 不要让客人自己走开就不管了
:::

## 贵重物品与隐私
- 提醒客人：手机、首饰、现金不要带进池区，按门店规定保管
- 捡到客人的东西，按门店的拾遗流程交上去登记，不私自保管
- 浴区不许拍照、录像。看到有人拍，礼貌制止并报告主管

:::scenario 喝了酒要进桑拿
一位客人酒气很重，走路有点晃，说要进桑拿房出出汗。你怎么做？
- [x] 关心客人，说明酒后桑拿容易晕倒，劝他先到休息区喝水休息，并请同事多留意他｜对。先关心再说原因，给出别的办法，再请同事帮着看，既礼貌又安全。
- [ ] 客人要进就让他进，自己不管｜不对。酒后进高温的地方容易晕倒，出了事后果严重。你看到了就要劝。
- [ ] 大声说「喝了酒不准进」｜不对。道理没错，但语气太硬，容易起冲突。先关心，再讲原因。
:::

:::check
客人在桑拿房里说头晕、心慌、想吐，第一步做什么？
- [x] 叫同事帮忙，扶客人离开桑拿房，到通风凉快的地方
- [ ] 让客人在桑拿房里再坐一会儿缓缓
- [ ] 带客人去冷池泡一下
解析：头晕、心慌、想吐是晕堂的表现，要先离开高温的地方，同时叫人帮忙。马上泡冷水对身体刺激大，不要这样做。
:::

## 本课小结
- 地面保持干；酒后、饱餐后、身体不适的客人要劝阻高温久泡
- 晕堂：喊人、离开高温、照看，严重的拨打 120
- 贵重物品提醒客人保管，浴区不许拍照

# 课时 key=linen min=5：布草与一客一换一消毒
一位女宾拿到浴衣，发现领口有一块黄印，当场就不高兴了。布草干不干净，客人一眼就看得出来。这关系到卫生，也关系到门店的口碑。

## 本课目标
- 学完能说出「一客一换一消毒」指的是什么
- 学完能把干净的布草和用过的布草分开放、分开送
- 学完能挑出不合格的布草

## 什么是一客一换一消毒
毛巾、浴巾、浴衣、拖鞋这些公共用品，每位客人用过以后都要换下来，清洗消毒以后才能给下一位客人用。《公共场所卫生管理条例》和 GB 37487-2019《公共场所卫生管理规范》都对公共用品用具的清洗消毒提出了要求。

:::cards 翻一翻，记一记
一客｜每位客人用一套，不能把别人用过的给下一位
一换｜客人用完就收走，换上干净的
一消毒｜收回来的要清洗消毒合格，才能再用
拖鞋｜用过的收回消毒，或者按门店规定用一次性拖鞋
:::

## 干净的和用过的分开
:::steps 布草怎么走
收｜用过的毛巾、浴衣放进专门的布草车或回收筐，不扔在地上
送｜送去洗涤消毒；脏的和干净的不用同一辆车、同一个筐
存｜消毒好的放进干净的柜子，关好柜门，不放在潮湿的地上
发｜发给客人之前看一眼，叠整齐再给
:::

:::warn 挑出不合格的
有污渍、破洞、发黄、有异味、没干透的，一律挑出来，不发给客人，按门店规定送回重洗或报损。
:::

:::ban 不要这样做
- 不要把客人用过的毛巾抖一抖就再发出去
- 不要用客人的毛巾擦地、擦设备
- 不要把干净的布草堆在地上或淋浴区旁边
:::

:::check
下面哪些做法符合「一客一换一消毒」？
- [x] 客人用过的浴衣收回来，清洗消毒以后再发
- [x] 有污渍的毛巾挑出来不发
- [ ] 看起来干净、客人没用多久的毛巾，直接给下一位
- [x] 干净的布草和用过的布草分开放
解析：只要客人用过，看起来再干净也要清洗消毒。脏的、干净的分开放，不合格的挑出来。
:::

## 本课小结
- 毛巾、浴衣、拖鞋要一客一换一消毒
- 干净的和用过的分开收、分开送、分开放
- 有污渍、破损、异味、没干透的挑出来不发

# 实操 key=practice：浴区巡查一圈
- 按门店规定的路线完整巡一圈，每个区域都走到
- 检查地面，没有积水、泡沫、头发和杂物
- 遇到湿滑地面，放好「小心地滑」提示并清理干净
- 读出热池、冷池的温度显示，说出是否在门店规定的范围里
- 从门窗查看桑拿房、蒸房里客人的情况，读出温度显示
- 检查池水清澈、没有漂浮物和异味
- 检查扶手、台阶防滑条、照明和门是否正常
- 说出紧急呼叫或报警的方式（按门店设置）
- 观察客人状态，能指出需要多留意的客人
- 检查布草数量够用，干净的和用过的分开放
- 把发现的问题当场处理，或报告主管并说清位置和情况
- 礼貌劝阻一位酒后要进热池的客人（由带教扮演）

- [ ] 等客人自己发现
解析：池水被污染要先停用，请客人离开、放提示牌，再报告主管按流程处理。不要自己加药剂，也不能装作没看见。
:::

:::question recall skill=池温与设施 level=2
为什么不能在桑拿炉上放毛巾、衣物？
答：桑拿炉温度很高，毛巾、衣物放在上面容易烤焦起火。发现有人这样放，要马上拿开并提醒客人。
:::

:::question multi skill=客人安全 level=2
下面哪些客人不适合马上进热池或桑拿房？
- [x] 刚喝了不少酒的客人
- [x] 刚吃得很饱的客人
- [x] 说自己心脏不太好的客人
- [ ] 洗完澡、精神很好的客人
解析：酒后、饱餐后、有心脏病高血压等情况的客人，在高温里容易头晕甚至晕倒，要劝他们先休息，身体不适先咨询医生。
:::

:::question recall skill=客人安全 level=3
一位客人喝了酒，坚持要进桑拿房「出出汗醒酒」，你怎么劝？
答：先关心，再说原因，最后给办法。例如：「您刚喝了酒，桑拿温度高，容易头晕，先到休息区喝点温水歇一会儿，好吗？」同时请同事多留意这位客人；客人不听、情况不对的，报告主管。
:::

:::question single skill=晕堂处置 level=3

- [ ] 把客人抬进冷池降温

- [ ] 先去找客人的朋友来
解析：叫不醒、呼吸不正常是危急情况，要马上呼救、拨打 120、请有急救证的同事处理。不能给昏迷的人灌水，也不能泡冷水。
:::

:::question recall skill=晕堂处置 level=1
晕堂一般有哪些表现？
答：头晕、心慌、恶心想吐、脸色发白、出冷汗，严重的会晕倒。
:::

:::question single skill=晕堂处置 level=2
客人刚晕堂，醒着但还有点头晕。下面哪种做法是对的？
- [ ] 带客人去冲冷水，清醒得快
- [x] 让客人在通风凉快的地方坐下或躺下，慢慢喝点温水，有人在旁边看着
- [ ] 让客人回桑拿房继续坐着
- [ ] 让客人自己回休息区，不用管了
解析：晕堂后要离开高温，在通风凉快的地方休息，清醒的客人慢慢喝点温水，并且有人照看。马上冲冷水刺激太大。
:::
