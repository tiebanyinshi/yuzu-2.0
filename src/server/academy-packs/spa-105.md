# 课时 key=items min=6：常见项目认识
一位第一次来的客人看着价目表问：「足疗和推拿有什么不一样？精油 SPA 又是什么？」你要是只能说「都挺好的」，客人就很难选。把常见项目讲清楚，是专业的第一步。

## 本课目标
- 学完能用一两句话介绍足疗、推拿、精油 SPA、拔罐、刮痧这类项目
- 学完能说出每类项目客人事先要知道什么
- 学完能做到介绍项目不夸大、不说疗效

## 常见项目
门店里项目叫什么、做多久、多少钱，以门店的价目表为准。下面是行业里一般的说法。

:::table 常见项目一览（一般介绍）
项目｜一般是什么｜客人事先要知道的
足疗｜先泡脚，再按揉脚部和小腿｜泡脚水先试温度，脚上有伤口要提前说
推拿 / 按摩｜用手法按、揉、推，放松肩颈、背部或全身｜力度可以随时说，哪里不舒服先告诉技师
精油 SPA｜用按摩油或精油在皮肤上推按，节奏比较舒缓｜对精油、香味过敏的要提前说
拔罐｜把罐具吸在皮肤上停留一会儿｜皮肤上会留下圆形的印子，一般过几天慢慢消退
刮痧｜用刮痧板在涂了油的皮肤上刮｜皮肤会发红或出现痧痕，一般过几天慢慢消退
采耳｜清理、放松耳部｜耳朵有炎症、疼痛的不要做
:::

拔罐、刮痧这类项目，门店做不做、怎么做，以门店的项目为准，只由经过培训的技师操作。

## 介绍项目只说事实
:::tip 怎么介绍
- 说清做什么、做多久、大概是什么感受
- 说清做完可能会怎样，比如拔罐会留下印子
- 价格、时长以价目表为准
- 让客人自己选，不强推
:::

:::ban 不要这样介绍
- 「这个能治颈椎病」「刮一次就排毒」
- 「做完保证不疼了」
- 拿别人家来比较、贬低别人
:::

按摩带给客人的是放松、舒缓的感受。身体有问题，要请客人去看医生。

:::check
给客人介绍拔罐时，下面哪句话最合适？
- [ ] 「拔一次就能把湿气拔掉。」
- [x] 「拔罐会在皮肤上留下圆形的印子，一般过几天会慢慢消退。」
- [ ] 「拔得越紫，说明病越重。」
解析：介绍项目只说做什么、会有什么情况，不说疗效，也不替客人判断身体状况。
:::

## 本课小结
- 项目名称、时长、价格以门店价目表为准
- 介绍项目说清做什么、什么感受、做完会怎样
- 不说「治病、排毒、保证」这类话

# 课时 key=contra min=7：不宜按摩的情况
一位客人进门就说：「我这两天有点发烧，想来按一按出出汗。」你知道这时候不适合按摩，可怎么跟客人说，才不会让他觉得你在推辞，或者在吓唬他？

## 本课目标
- 学完能说出常见的不宜按摩的情况
- 学完能在服务前用合适的方式问清客人的身体状况
- 学完能在拿不准时，建议客人先咨询医生

## 常见的不宜按摩的情况
:::table 不宜按摩或要特别小心（一般情况，以门店规定为准）
情况｜为什么｜怎么做
发热、感冒发烧｜身体本来就虚，按摩可能更难受｜建议休息，好了再来
皮肤破损、感染、皮疹、烫伤｜按压会加重，也可能传染｜这些部位不按，严重的不做
孕期｜孕期身体变化大｜按门店规定，一般不做，或在客人咨询医生后只做门店允许的项目
刚吃饱（一般饭后一小时内）、刚喝了酒｜容易恶心、头晕｜建议休息一会儿再做
严重的心脏病、高血压控制不好、出血性疾病、刚做过手术｜按压和换姿势可能有风险｜不做，建议先咨询医生
骨折、扭伤还没好｜按压会加重伤情｜这个部位不按
:::

:::warn 拿不准就先停
你不是医生，不要替客人判断病情。客人说的情况你拿不准，先停下，告诉钟房或主管，建议客人先咨询医生。
:::

## 怎么问
:::steps 服务前问三句
问身体｜「您最近身体有没有不舒服，比如发烧、受伤，或者做过手术？」
问特殊情况｜「有没有哪里不能按，或者需要我特别注意的地方？」女宾可以问：「方便的话，告诉我是不是在孕期？」
问饮食｜「您刚吃过饭，或者喝过酒吗？」
:::

## 怎么劝
- 先关心：「您身体不舒服，先照顾好身体最要紧。」
- 再说明：「这种情况下按摩可能会更难受。」
- 给办法：「您先休息，好了再来；也可以先问问医生。」
- 不吓唬客人，也不说「你这是什么病」

:::scenario 客人想「按一按出出汗」
客人说：「我有点发烧，按一按出出汗就好了。」你怎么回应？
- [x] 「您发烧的时候身体比较虚，按摩可能会更难受。建议您先休息，必要时看看医生，好了再来，我们给您安排。」｜对。先关心，说清原因，给出办法，不做医疗判断。
- [ ] 「好的，那我按重一点帮您出汗。」｜不对。发热不宜按摩，加重力度更不合适。
- [ ] 「发烧还来干什么？」｜不对。道理没错，语气伤人，客人会觉得被冒犯。
:::

:::check
客人说自己有高血压，一直在吃药，问能不能做全身按摩。你怎么做？
- [ ] 告诉客人「吃了药就没事」
- [x] 告诉钟房或主管，按门店规定处理，建议客人先咨询医生
- [ ] 直接拒绝，让客人离开
解析：你不能替客人判断身体能不能承受。按门店规定处理，拿不准的请客人先咨询医生；态度要礼貌。
:::

## 本课小结
- 发热、皮肤破损、孕期、饭后酒后、严重疾病、伤处，不宜按摩或这个部位不按
- 服务前一定要问，拿不准就先停下报告
- 劝客人：先关心、再说明、给办法，不做医疗判断

# 课时 key=pressure min=5：力度沟通与客人体验
一位客人从头到尾没说话，可你注意到他的肩膀一直绷着，偶尔皱一下眉。结束时他说「还行」，之后再也没来过。很多客人不会主动说「太重了」，要靠你问、靠你看。

## 本课目标
- 学完能做到先轻后重，随时问客人的感受
- 学完能从客人的表情和身体看出力度合不合适
- 学完能照顾好房间温度、遮盖、安静这些细节

## 先轻后重
- 开始时力度轻一点，让客人的身体先放松下来
- 慢慢加，加到客人觉得舒服为止
- 疼不等于好，客人说疼就要减轻
- 不同部位力度不一样，骨头突出的地方要轻

:::cards 常用的问法
开始时｜「这个力度可以吗？」
换部位时｜「这里需要重一点还是轻一点？」
客人皱眉时｜「是不是有点重了？我轻一点。」
快结束时｜「还有哪里需要多按一会儿吗？」
:::

## 看懂客人的反应
:::table 客人的信号
你看到的｜可能是｜你要做的
肌肉绷紧、身体往回缩｜力度太重｜减轻，问一句
皱眉、屏住呼吸｜疼或者不舒服｜马上停一下，问客人感受
呼吸变慢、身体放松｜比较舒服｜保持现在的力度和节奏
一直搓手、缩脚｜可能冷了｜盖好毛巾，调一下空调
:::

## 照顾好细节
- 房间温度适中，客人不按的部位用毛巾盖好
- 灯光、音乐按客人喜欢的调；客人想安静，就少说话
- 服务时不接打私人电话，不玩手机，不和同事聊天
- 结束时提醒客人慢慢起身，喝点温水

:::tip 客人想聊天还是想安静
有的客人喜欢聊几句，有的想睡一会儿。先观察：客人不主动说话，你就安静地做。
:::

:::check
按摩时客人皱眉、身体往回缩，最可能说明什么？
- [x] 力度可能太重，要减轻并问一句
- [ ] 客人很享受，可以再加重
- [ ] 不用管，客人没说话就是没问题
解析：很多客人不好意思说「重了」。皱眉、往回缩是不舒服的信号，要主动减轻、主动问。
:::

## 本课小结
- 先轻后重，疼不等于好
- 多问、多看，客人的身体会说话
- 温度、遮盖、安静这些细节，决定客人的体验

# 课时 key=ethics min=6：服务边界与职业操守
服务快结束时，客人问：「你们这个精油是不是能减肥？能的话我办张卡多做几次。」说一句「能」，卡也许就办了；可这句话一出口，就越过了职业的边界。

## 本课目标
- 学完能说出服务中不能越过的几条边界
- 学完能如实介绍项目和用品，不夸大功效
- 学完能保护客人隐私，遇到不当要求会处理

## 不做医疗诊断与承诺
- 不给客人「看病」：不说「你这是颈椎病」「你肝不好」
- 不承诺效果：不说「治好」「根除」「保证见效」
- 客人问身体上的问题，建议他咨询医生

按摩带来的是放松、舒缓的感受，不是治疗。

## 不推销虚假功效
:::table 推荐时这样说
不要说｜可以说
「这个精油能减肥」｜「这款精油香味比较清淡，很多客人喜欢」
「多做几次病就好了」｜「您觉得舒服的话，可以按自己的时间安排」
「不办卡就没效果」｜「办卡的规则以门店的说明为准，您了解清楚再决定」
:::

《消费者权益保护法》规定，消费者有权知道商品和服务的真实情况。办卡涉及预付，规则要如实说清楚，由前台或负责的同事按门店规定办理，不替客人做决定。

## 尊重隐私
:::ban 隐私红线
- 不打听客人的工作、收入、家庭这些私事
- 客人的身体情况、说过的话，不外传、不议论
- 不拍照、不录像，不把客人的信息发到群里或朋友圈
:::

## 职业操守
- 不做任何不当服务。客人提出不当要求：礼貌而坚决地拒绝，停止服务，报告主管
- 按项目、按时长认真做，不偷工减料，不提前下钟
- 服务时专心，不接打私人电话
- 费用以门店价目表为准，走门店的账，不私下收钱
- 遇到骚扰或不安全的情况，马上离开房间并报告

:::check
客人问「这个精油能不能减肥」，哪种回答最合适？
- [ ] 「能，坚持做一个月就瘦了。」
- [x] 「这款精油主要是按摩时用，让人放松；减肥的问题建议您咨询医生。」
- [ ] 「不知道，你自己去查。」
解析：不能夸大功效，也不要敷衍客人。如实说明用品的用途，涉及身体和健康的问题，建议咨询医生。
:::

## 本课小结
- 不诊断、不承诺，只说放松、舒缓
- 推荐如实说，不编功效，办卡规则说清楚
- 尊重隐私，不当要求坚决拒绝
