# 课时 key=revenue min=6：门店是怎么赚钱的
新同事问："我们一天来那么多客人，门店是不是很赚钱？"其实门店收进来的钱，要付房租、工资、水电、布草、食材……弄明白钱从哪来、往哪去，你就知道自己的每个动作为什么重要。

## 本课目标
- 学完能说出门店收入的几个主要来源
- 学完能用「客流、客单价、复购」解释营业额
- 学完明白会员储值为什么不等于门店赚的钱

## 钱从哪来
:::table 门店主要的收入来源
来源｜是什么
门票、浴资｜客人进店泡汤、洗浴的费用
按摩项目｜保健部、康美部技师做的项目，加钟也算
餐饮｜自助餐、点餐、饮品
客房｜客人过夜休息
娱乐与零售｜娱乐项目、洗浴用品等（以门店实际为准）
:::

具体价格，以门店价目表为准。

## 三个关键词
:::cards 三个关键词（点一下翻面）
客流｜来了多少位客人
客单价｜平均每位客人花多少
复购｜客人多久再来、一年来几次
:::

营业额大致就是：**客流 × 客单价**。复购决定了明天、下个月还有没有客流。

想把生意做好，就三条路：
- 让更多人来：口碑好，回头客会带新客来
- 让来的客人体验更多：泡完想按摩、按完想吃饭，自然就会加项、加钟
- 让客人愿意再来：服务好、记得他

「体验更多」靠的是服务好、介绍清楚，不是硬推。

## 储值卡里的钱，不是门店赚的
会员充值的钱，是客人**提前放在门店的**。客人每消费一次，才变成门店的营业收入。没花掉的余额，门店还欠着客人一份服务。

所以储值一定要管好：每一笔充值、消费都要记清楚，余额要准，客人问起来随时能查。

:::warn 钱不只是收进来
门店还要付房租、工资、水电燃气、布草洗涤、耗材、食材、设备维修……收入减去这些成本，剩下的才是利润。
:::

:::check
营业额大致等于什么？
- [x] 客流 × 客单价
- [ ] 储值余额 × 会员人数
- [ ] 员工人数 × 工作时长
解析：来了多少客人，乘以平均每位花多少，大致就是营业额。复购决定以后的客流。
:::

## 本课小结
- 收入来自门票浴资、按摩项目、餐饮、客房、娱乐与零售
- 营业额约等于客流 × 客单价，复购决定以后的客流
- 储值是客人预存的钱，消费了才是营业收入

# 课时 key=metrics min=6：员工能影响的几个指标
月底开会，店长说："这个月加钟的少了，客诉多了，布草也丢了不少。"这几样听起来是数字，其实每一样都和我们每天的服务有关。

## 本课目标
- 学完能说出员工能影响的四个指标
- 学完明白每个指标为什么重要、自己能做什么
- 学完知道哪些做法不能为了指标去做

## 四个指标
:::table 四个指标，你能做什么
指标｜为什么重要｜你能做什么
满意度｜满意的客人才会再来、才会带朋友来｜三米微笑、记住偏好、主动一步
加钟与复购｜说明客人觉得值、愿意多待、愿意再来｜手法用心、介绍清楚，客人想加才加
客诉｜一条客诉背后，可能还有很多没说出口的不满｜早发现、早处理，按四步法，及时上报
损耗｜布草、物料、食材的浪费和丢失，都是门店的成本｜按需取用、及时回收，损坏丢失如实上报
:::

## 加钟和复购：靠体验，不靠推
加钟，是客人自己觉得舒服、还想再按一会儿。复购，是客人觉得值，愿意再来。

:::tip 怎么做
- 服务开始前，问清客人的需求和力度
- 快结束时，自然地问一句：「时间快到了，您看还要不要再加一点？」
- 客人说不用，就不再提
- 介绍项目时把内容、时长说清楚，价格以门店价目表为准
:::

## 客诉：越早越小
客人皱眉、语气变了，就是信号。当场多问一句、早一点处理，就不会变成正式的客诉。处理不了的按四步法上报，由前台记「客诉」备注，主管在客诉台账里跟进。

:::ban 不能为了指标这样做
- 硬推、反复推，客人拒绝了还纠缠
- 没说清价格就给客人加项、加钟
- 瞒着客诉不报
- 布草丢了、坏了不说
:::

:::check
按摩快结束时，下面哪种做法最合适？
- [ ] 不问客人，直接多按一个钟
- [x] 自然地问一句还要不要加一点，客人说不用就不再提
- [ ] 一直劝客人加钟，直到他同意
解析：加钟要客人自己愿意、价格说清楚。不问就加、反复劝，都会变成客诉。
:::

## 本课小结
- 满意度、加钟与复购、客诉、损耗，每个人都能影响
- 加钟和复购靠体验和说清楚，不靠硬推
- 不为指标硬推、不瞒客诉、不藏损耗

# 课时 key=prepaid min=7：会员储值与预付卡的合规常识
一位客人在前台犹豫要不要充值，旁边的员工催："今天不充，以后就没这个价了，赶紧的！"可今天并没有要截止的活动。这一句话，就可能让门店违反《消费者权益保护法》。

## 本课目标
- 学完知道两部相关法规讲了哪些一般原则
- 学完能做到如实告知、明码标价、不强迫消费
- 学完知道退卡、余额的问题交给谁处理

## 两部法规，几条原则
**《消费者权益保护法》**保护客人的几项权利，也给经营者定了规矩：
- 知情权：客人有权知道商品和服务的真实情况
- 自主选择权：买不买、买哪个，客人自己决定
- 公平交易权：价格公道、计量准确
- 经营者要明码标价，不能作虚假的或者让人误解的宣传
- 用预收款的方式提供服务，要按约定提供；没按约定提供的，客人可以要求履行约定，或者退回预付款

**《单用途商业预付卡管理办法（试行）》**管的是只能在本企业（或同一品牌）里用的预付卡。它要求发卡的企业把卡的使用范围、余额怎么查、怎么挂失、怎么退卡等规则跟客人讲清楚，并提供余额查询。

## 门店的做法
:::steps 办储值时的四要
如实告知｜充值前把规则说清楚：能用在哪些项目、有没有赠送、退卡怎么办，都以门店规定为准
明码标价｜价目表公示，按价目表收费，不私下另定价
余额可查｜每一笔充值、消费系统里都有记录，客人问余额，前台在系统里查给客人看
自愿消费｜充不充、充多少，客人自己决定
:::

:::ban 不能说的话、不能做的事
- 「今天不充，以后就没这个价了。」（没有这回事的时候）
- 夸大赠送，隐瞒限制条件
- 客人不想充，还反复纠缠
- 把客人的余额、消费记录告诉别人（同行的朋友问也不说）
:::

## 退卡、退余额：交给前台和主管
客人要退卡、退余额，或者对余额有疑问：
- 不自己答应怎么退、退多少
- 告诉客人「我请前台（或主管）来给您办」
- 具体怎么退，以门店规定和当地法规为准

:::scenario 客人问充值的事
你是浴区的服务员。一位客人问你：「充值划算吗？充了以后不想用了能退吗？」你怎么回答？
- [ ] 「划算！充了肯定不亏，想退也能退，您放心充。」｜你不清楚退卡规则，就替门店许诺，等于误导客人，以后容易起纠纷。
- [x] 「有什么活动、退卡怎么办，前台会给您讲清楚。我带您过去问问？」｜如实、不夸大、不替门店许诺，把客人交给清楚规则的前台。
- [ ] 「这个不归我管。」｜推诿，客人体验很差。你可以帮客人找到对的人。
:::

:::check
客人问"我卡里还有多少钱"，下面哪个做法对？
- [x] 请前台在系统里查给客人看
- [ ] 凭印象说个大概
- [ ] 让同行的朋友帮他查
解析：余额要准、要能查，由前台在系统里查。凭印象说容易说错，余额也不能让别人代查。
:::

## 本课小结
- 消费者有知情权、自主选择权、公平交易权；要明码标价，不虚假宣传
- 办储值：如实告知、明码标价、余额可查、自愿消费
- 退卡、退余额交给前台和主管，以门店规定和当地法规为准

# 课时 key=cost min=6：成本与损耗意识
下班时，更衣室有几个淋浴头还在哗哗流水，休息区没人却亮着所有的灯，几条新浴巾被拿去擦了地。每一样看起来都是小事，一个月加起来就不少了。

## 本课目标
- 学完能说出门店主要的几类成本
- 学完能在自己的岗位上做到节约
- 学完明白哪些地方「不能省」

## 门店的几类成本
:::cards 几类成本（点一下看怎么省）
水｜淋浴不长流，龙头关紧，漏水马上报修
电｜人走灯关，没人的区域按门店规定调节照明和空调
燃气和热能｜热水、池温按工程部的设定，不自己调高
布草｜按需发放，不当抹布用，及时回收，损坏丢失如实上报
耗材｜洗浴用品、一次性用品按需摆放补充，不一次堆太多
食材｜先进先出，按量备料，减少报废
设备｜按规程使用，小毛病早报修，别拖成大修
:::

## 人人都能省
:::steps 下班前三查
查水｜淋浴、水龙头有没有关好，有没有漏水
查电｜没人的区域，灯和设备按门店规定关好
查物｜布草收回、物料归位，损坏的登记上报
:::

## 不能省的地方
:::ban 这些不能省
- 消毒：毛巾、杯具、拖鞋一客一换一消毒，不能为了省消毒液少做
- 换水和检测：池水按规定换水、消毒、检测
- 通风：排风设备该开就开
- 安全：防滑垫、提示牌、急救用品不能少
:::

**省钱要省在浪费上，不能省在卫生和安全上。**

:::check
下面哪个是正确的节约做法？
- [ ] 毛巾少消毒几次，省消毒液
- [x] 没人的区域按门店规定关灯，淋浴用完关紧龙头
- [ ] 自己把热水池温度调低，省燃气
解析：省在浪费上：关灯、关水、布草不乱用。消毒不能省；池温由工程部按设定管，自己不调。
:::

## 本课小结
- 水、电、燃气、布草、耗材、食材、设备，都是成本
- 下班前查水、查电、查物，损耗如实上报
- 省在浪费上，不省在卫生和安全上
