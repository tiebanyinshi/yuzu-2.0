## 1. 两类异常

- **未交回**：客人结了账、没把手牌还回来。前台「锁牌 / 解锁」里选「未交回」登记，系统记下**最后一位结账用这张牌的客人**（那次来访）。
- **挂失**：客人在店里把手牌弄丢了。照旧在手牌账单里「手牌丢失 · 换牌」（锁原牌、收赔偿、换新牌），原牌自动进挂失清单，记下这位客人；在「锁牌 / 解锁」里也能对结过账的牌登记挂失。
- 只锁定（损坏、柜锁故障）的照旧，不分类。

两类都要这张牌**有人结账用过**（`TAG_NEVER_USED`）、**现在没人在用**（`TAG_IN_USE`，在店的请先换牌）。

## 2. 清单

前台工具栏「异常手牌」（带锁定张数），打开是一张清单：挂失、未交回在前（同类按登记时间从早到晚，越早越该追），后面是手动锁定、维修中、暂停使用。每行有牌号、男宾 / 女宾、类别、当时的客人（会员名或称呼、来访单号、结账时间）、原因、谁几点登记的。

- ↑↓ 选一行、回车 = **找回**（解锁，值班经理、店总、店主）；也可以点行尾的按钮。找回后类别和客人一起清掉，牌能再发；审计里记 `recovered`。
- 「登记未交回 / 挂失」打开锁牌对话框，默认选「未交回」。
- 维修中、暂停使用的在「手牌管理」里改，清单里只列出来。

接口：`GET /api/frontdesk/tag-exceptions`（前台可看）；登记照旧 `POST /api/frontdesk/tags/:id/lock`，多一个可选的 `kind`（`lost` / `unreturned`）；换牌 `POST /api/frontdesk/visits/:id/swap` 多一个 `lost`（收了丢牌赔偿的也算挂失）。

## 3. 交班提醒

交班表「确认交班」上方：还有挂失、未交回的手牌时提示几张、哪几张（谁的），交班时交接给下一班。只提醒、不拦交班。

## 4. 数据库

迁移 `740`（`740_tag_exceptions_v8221.sql`）：`hand_tags.lock_kind`（`lost` / `unreturned`，只能在锁定时有）、`hand_tags.lock_visit_id`（哪一次来访，外键带索引）。以前锁的牌都算手动锁，不回填。回滚 `docs/rollback/740_tag_exceptions_v8221.down.sql`。

## 5. 没做的

- 未交回的不自动向客人收费（客人已经走了），要不要追偿由前台和店长线下处理。
- 结账时不逐张问「手牌交回了没有」：没交回的少，靠收牌时发现再登记。
