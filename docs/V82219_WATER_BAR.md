## 2. 规则

### 2.1 首杯免费

- 算哪些：挂到手牌上的明细（点单页、桌台挂牌、餐厅入口以外的入口都算），出品口是**水吧**的饮品；
- 按什么分：价目表的小分类（菜品的「分组」）；没有分组的按「水吧」一组；
- 一位客人 = 一次来访（一张手牌）；同一小分类已经有一行没作废的首杯赠，就照价；首杯那一行作废了，下一杯算首杯；
- 一行点了两杯以上：只折一杯（这一行实收 = 原价 − 单价）；
- 记法：照 8.2.8 的自动折扣（单项打折表，档 `auto`、规则 `first_cup`），结账时一起记「单项折扣」；与 8.2.8 的自动折扣一样不能手动撤下或改（要改就作废那一行，下一杯算首杯）；
- 后台「餐饮规则」→「水吧首杯免费」：首杯免费（默认）/ 都照价。

### 2.2 赠标签

- 账单（收银台）：折到 0 或首杯赠的那一行标红色「赠」，下面一行写原价、规则、实收；
- 结账单、出品单（打印）：那一行印「【赠】品名」（折到 0）或「【折】品名」（部分折），下一行「原价 x · 实收 y」。

### 2.3 取餐叫号

- 发号：一单（一次下单）里有水吧饮品就发一个号，门店、营业日从 1 起（显示 A001）；没有水吧饮品的单不发；
- 进度看这一单的出品单：待做 / 制作中 = 制作中；有已出餐的（没有还在做的）= 请取餐；都上了 = 已取；全退了 = 已退；
- 叫号屏（餐饮「取餐叫号」，有出品或点单权限的能看）：今天制作中、请取餐的号，几秒刷新一次；
- 客人进度页 `/q/<编号>`：编号是随机的（小票二维码里），不用登录，只给这一单的号、饮品与状态、前面还有几单在做。

## 3. 数据与锁

迁移 `610`：

- `pickup_tickets`：取餐号（出品单号唯一、来访、营业日、号、随机编号唯一；同一店同一营业日号唯一）；只追加。

加锁顺序：发号在挂账（`postChargesTx`）的同一个事务里、建完出品单以后：先取「这家店这一营业日取餐号」的咨询锁，再取最大号 + 1。
首杯免费在挂账的同一个事务里、写完明细以后：来访已锁，按这次来访已有的首杯赠核对。

## 4. 没做的 / 要店主定的

- App、短信、公众号推送：要另接短信账号与公众号模板消息，这一版用扫码看进度代替（8.2.19-4）；
- 首杯按「一次来访」算，不按自然日；第二天续住的客人同一张牌不再送（8.2.19-1）；
- 桌台（餐包）点的水吧饮品挂到手牌上的也送首杯；没挂手牌的桌台单不送（8.2.19-2）。
