# 汤崎学堂 · 员工培训体系（店主 2026-11-27）

店主 2026-11-27 发来 8 张截图（希尔顿欢朋的员工学习小程序），原话：「这里面 8 张图，是我们觉得目前在员工培训这一块，做的比较好的体系，我们不知道该怎么给你提示词去描述，请你自己量化和考究这里面的专业化方向，与目前开源的一些 AI 教育项目进行融合，搭建我们自己的员工培训体系。然后，请你针对我们的应知应会，还有水疗行业的通识课，自己设计一些课件出来。工作量比较大，你自己多分几个 PR 去完成，最后都审核完后，一起合并成一个 PR，用一个新版号去合并 main。」

这一份是设计稿：第 1–3 节是对截图的拆解与开源项目的调研，第 4–9 节是「汤崎学堂」怎么做，第 10 节是分批与 PR，第 11 节是开发时定的默认做法（`PENDING_DECISIONS.md` XT01 起，待店主确认）。8.1.36 的「员工培训」（`docs/TRAINING.md`，文件夹 + 看过记录）原样保留，成为学堂里的「知识库」一栏；它第二期（指派、必读）、第三期（题库、考试、证书）由这一份接着做。

从这些数看得出几条设计取向：

- **学分按完成给、不按时长给**：48 分钟拿了 140 学分，大部分来自「完成一项给 1 分」，时长单独成一个榜。
- **路线是「岗位 × 阶段 × 任务」三层**：地图对应岗位或计划，阶段 2–4 个任务，任务是「先学后考」。
- **文化先行**：每张地图第一站都是品牌文化，首页有品牌横幅。
- **知识库与课程分开**：知识共享中心是按部门堆的资料（234 份），学习地图是排好顺序的课。
- **游戏化做得足**：IP 形象贯穿、等级有江湖味的称号、跨店榜单、完成即时反馈。
- **可以更好的地方**：视频 37 分钟太长（微课一般 5–10 分钟）；只看完成不看记没记住；测验题目固定；没有在岗实操的考核记录。

| ⑥ 系统操作培训 | 西软小课堂                            | 软件操作微课                                        | 「柚子系统小课堂」：WCP、收银台的操作课                                                           |
| ⑦ 品牌文化     | 欢朋之道、KEY TO HAMPTONALITY         | 文化落地                                            | 「汤崎之道」放在新员工地图第一站                                                                  |

课件本身照两套教学设计方法写：

- **ADDIE**（分析—设计—开发—实施—评估）：每门课先写清对谁、学完能做什么，再写内容、再出题，最后看评分与考试数据回头改。
- **加涅九段教学**：一节课按「引起注意（情景）→ 告知目标 → 唤起旧知 → 呈现内容 → 学习指导 → 练习 → 反馈 → 评估 → 保持与迁移」排；学堂的课件模板（第 6 节）对应成「情景导入 → 本课目标 → 正文与要点卡 → 课中小测 → 本课小结 → 课后测验 → 每日一练」。
- **布鲁姆分类**：题目分三档难度（1 记住、2 理解、3 应用 / 判断情景），每课的题三档都有。
- **微课**：一个课时 3–8 分钟，一个课时只讲一件事。

## 4. 学堂的结构

```
学习地图（按岗位 / 计划，蜿蜒路线）
 └─ 阶段 = 课程（一门课，例：「泡汤健康与安全禁忌」）
     └─ 课时（学习任务）：图文互动课件 / 文件（视频、PDF，引用员工培训的文件）/ 测验 / 实操签核
         └─ 题库：每题挂一个知识点，供测验、每日一练、掌握度用
```

- **课程分类**（知识中心的几栏）：汤崎之道（文化）、应知应会、行业通识、岗位技能、系统小课堂、安全、管理。课程可挂一个部门（进那个部门的知识中心），不挂就是全员通用。
- **必修与选修**：由「指派」决定——一条指派 = 一张地图或一门课 + 对象（全员 / 部门 / 岗位 / 个人）+ 必修或推荐 + 几天内完成。员工命中的所有指派合起来就是「我的必修」。新员工入职、调岗以后自动按规则带上，不用一个个派。截止日 = 指派生效日与入职日中较晚的那天 + 天数。
- **课时完成方式**：图文课件读到最后（课中小测答过）、文件看过（视频、PDF 打开过）、测验及格、实操由带教签「通过」。一门课的上架课时都完成，这门课就完成；一张地图的课都完成，发证书。
- **知识库**：员工培训的文件夹（培训资料 + 各部门）放在学堂首页「知识库」一栏，地址仍是 `/oa/training`。

## 5. 评估、激励与 AI

- **测验**：每次从这门课的题库按掌握度抽（默认 5 题、80 分及格，可在课时上改），题目与答案当场存一份快照，之后改题不影响已交的卷。可以重考，学分只在第一次及格时给。
- **每日一练**：每天 10 题——先出到期该复习的，再补新题（每天最多 5 道新题，来自我已开始学的课）；客观题自动判对错，问答卡（应知应会的「问—答」）看完答案自己评「忘了 / 模糊 / 记得 / 很熟」。答完当天的题得 1 学分，记连续天数。
- **掌握度**：测验与每日一练的每次作答都更新那个知识点的掌握概率（BKT）；≥ 0.95 算「已掌握」，< 0.6 算「薄弱」。
- **实操签核**：实操课时列出检查项（例：前台接待六步），带教（有「带教签核」权限的同部门员工，或学堂管理员）在岗看完逐项打勾、签「通过 / 再练」，签核记录只追加。
- **学分**：图文 / 文件课时 1 分、测验及格 2 分、实操通过 3 分、每日一练 1 分 / 天、完成一张地图 5 分（课时上可改）。学分流水只追加，同一件事只给一次。
- **时长**：页面在前台、打开着课时才计，每分钟报一次，服务端按两次上报的间隔封顶（不会比真实时间多）。
- **等级**（汤主题，待确认 XT05）：LV1 初试水温（0）→ LV2 温汤渐暖（60）→ LV3 汤中好手（150）→ LV4 独当一面（300）→ LV5 汤崎匠人（500）→ LV6 一代宗师（800）。
- **榜单**：学分榜、时长榜，本月 / 累计，全公司 / 本店；显示姓名、门店、部门。
- **证书**：完成地图自动发，编号 `XT-年月-序号`；安全类地图带有效期（默认 12 个月），到期要重新学。
- **AI 出题**：管理员在课时上点「AI 出题」，按这节课的正文出 5 道题，进题库是「草稿」，审过改过才启用；只发课件正文，不发员工、会员的任何数据。
- **问柚子**：课程页里问问题，柚子只按这门课的课件回答、注明出自哪个课时；课件里没有的说「课件里没讲到，请问主管」；每人每天最多 30 次（待确认 XT10）。

## 6. 课件格式（学堂课件文本）

课件用一种扩展的 Markdown 写，内置课件包与后台编辑共用一份解析（`src/shared/academy-markup.ts`），页面上渲染成卡片。管理员不用懂代码：后台编辑框旁边就是手机预览。

```text
正文：空行分段，**加粗**，「- 」列表，「1. 」有序列表，「## 」小标题，「> 」引用。

:::tip 要点标题        要点卡（绿）
:::warn 注意标题       注意卡（橙）
:::ban 禁忌标题        禁忌卡（红）
:::steps 步骤标题      每行「步骤名｜说明」
:::cards 记忆卡标题    每行「正面｜背面」（点一下翻面）
:::table 表格标题      首行表头，「｜」分列
:::scenario 情景标题   先写情景，再写「- [x] 选项｜点了以后的反馈」，[x] 是最好的做法
:::check               课中小测：题干，「- [x] 对的」「- [ ] 错的」，「解析：…」
:::question single skill=知识点 level=1   题库题：single 单选 / multi 多选 / judge 判断 / recall 问答卡
:::                    每块以单独一行「:::」结束
```

一门课一个文件，头部写课程信息，然后按课时分段：

```text
---
code: spa-103
title: 泡汤健康与安全禁忌
category: industry
minutes: 30
summary: 一句话说明
---
# 课时：标题 {min=6}
……
# 测验：课后测验 {count=5 pass=80}
# 实操：标题
- 检查项
# 题库
:::question …
```

课时模板（加涅九段）：情景导入（一个真实场景）→ 本课目标（学完能做到的 2–3 件事）→ 正文（每段配要点 / 注意 / 禁忌卡）→ 课中小测（1–2 道）→ 本课小结（3 条以内）。

## 7. 算法

### 7.1 掌握度（BKT）

每个知识点四个参数：初始掌握 P(L0)=0.3、学会 P(T)=0.15、猜对 P(G)=0.2（判断题 0.4、问答卡 0.05）、失误 P(S)=0.1。答对：P(L|对) = P(L)(1−S) / (P(L)(1−S) + (1−P(L))G)；答错：P(L|错) = P(L)S / (P(L)S + (1−P(L))(1−G))；然后 P(L) ← P(L|观察) + (1 − P(L|观察))·T。

### 7.2 每日一练（FSRS）

照 FSRS 公开的公式与默认参数（w0–w16：0.40255, 1.18385, 3.173, 15.69105, 7.1949, 0.5345, 1.4604, 0.0046, 1.54575, 0.1192, 1.01925, 1.9395, 0.11, 0.29605, 2.2698, 0.2315, 2.9898），评分 1 忘了 / 2 模糊 / 3 记得 / 4 很熟（客观题：答错 1、答对 3）：

- 可提取概率 R(t,S) = (1 + F·t/S)^C，F = 19/81，C = −0.5；目标保持率 0.9 时下次间隔 = S 天（最少 1 天、最多 180 天）。
- 第一次：S0 = w[G−1]，D0 = w4 − e^(w5·(G−1)) + 1（限在 1–10）。
- 难度：D′ = D − w6·(G−3)·(10−D)/9，再向 D0(4) 回归：D″ = w7·D0(4) + (1−w7)·D′（限在 1–10）。
- 记得（G≥2）：S′ = S·(1 + e^w8·(11−D)·S^(−w9)·(e^(w10·(1−R)) − 1)·h·b)，h = w15（G=2）否则 1，b = w16（G=4）否则 1。
- 忘了（G=1）：S′ = min(S, w11·D^(−w12)·((S+1)^w13 − 1)·e^(w14·(1−R)))。

## 10. 分批与 PR

店主要求多个 PR 分开做、都审完再合成一个 PR 用新版本号合进 main。做法：集成分支 `claude/peaceful-mendel-jardzy` 开一个合进 main 的 PR（就是最后那一个），下面几个子 PR 都合进这个集成分支，各自过 CI 与审查：

| 子 PR       | 范围                                                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| A 后端核心  | 迁移 600：课程、课时、地图、指派、进度、学分、榜单、等级；课件文本解析；员工端与管理端接口；集成测试                     |
| B 测评      | 迁移 601：题库、测验、每日一练（FSRS）、掌握度（BKT）、实操签核、证书                                                    |
| C 界面      | 员工端学堂（首页、地图、课程、课件播放、测验、每日一练、我的、榜单）、带教签核、管理端六个页签；三台目标设备             |
| D 课件与 AI | 内置课件包（汤崎之道、应知应会、水疗行业通识、系统小课堂、带教）与导入；迁移 602：AI 出题、问柚子；题库 Excel / CSV 导入 |

全部合进集成分支后，在集成分支上改版本号（main 那时的版本号最后一位加一）、写交接说明，CI 与审查都没有问题再合进 main。
