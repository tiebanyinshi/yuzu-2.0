# 8.1.41 自定义轮班周期与成本卡

范围见 `docs/V8138.md` 第 1 节：《门店系统需求梳理与优化方案》的「自定义轮班」「成本卡」两条。

轮班周期见 [`docs/V8141_ROTA.md`](V8141_ROTA.md)。

## 1. 逐条对照

| 需求                         | 系统里已有的                                                                                                                       | 这一版                                                      | 怎么不把原来的弄复杂                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------- |
| 自定义轮班（中医 10 天一转） | 技师排班表：按天排班或排休、复制上一周                                                                                             | 「轮班周期」生成到现有排班表（V8141_ROTA）                  | 只是生成排班的一种方式，生成后照旧逐天改     |
| 成本卡与采购打通             | 库存「用料与扣料」里每道菜的配方（物料、用量、损耗）就是成本卡；物料成本是采购到货的移动加权平均；出品自动扣料；成本报表有理论毛利 | 菜品管理里直接看到成本与毛利、哪些菜还没配成本卡（第 2 节） | 不另建一套成本卡，不另存菜品成本：只读、现算 |

## 2. 菜品管理里看成本卡（`GET /api/dining/dishes/costs`）

- 菜品表每道菜价格下面一行小字：
  - 配了成本卡：「成本 ¥1.50 · 毛利 70%」。毛利 =（售价 − 一份成本）÷ 售价，售价按默认规格；亏本的标红。
  - 时价、称重的菜：只写一份成本，不算毛利（售价是点的时候填的）。
  - 成本卡里有物料还没有成本（没进过货、也没填参考价）：「成本卡有物料还没成本」。
  - 没配成本卡：「没有成本卡」，有「查看库存」权限的点一下到「库存 → 用料与扣料」去配。
  - 套餐不写（按里面的菜扣料）。
- 筛选多一个勾「只看没有成本卡的（N）」，方便一道一道补。
- 一份成本与成本报表、配方列表同一个算法：各样用料（含损耗，按物料小数位向上取整）× 物料现在的平均成本；没进过货的按参考价起算。采购到货改了平均成本，这里下一次打开就跟着变，**「采购物料同步为菜品成本」就是这一条**。
- 权限：看得到菜品的都能看「有没有成本卡」；金额只给有「看成本」（`inventory.cost`）的人，与库存成本页一样。只读，不记审计。
