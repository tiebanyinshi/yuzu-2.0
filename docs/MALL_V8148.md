# 8.1.48 · 采购商城：逛电商的感觉、商品图、排到采购第一项

> 店主 2026-11-26：「采购商城我们想要的感觉是淘宝商城那样的，或者说得物，真的有那种逛高级电商的感觉，透明质感 UI，好的商品图。然后采购商城是目前进采购的第一项。顺便 UI 你可以学习一下一些好的 skill……直接去模仿现成的 UI 库。」

商城的功能（比价、清单、提交即生成采购需求单、自主申请、需求池、后台）照 8.1.32 / V1.1 不变（[`MALL_V8132.md`](MALL_V8132.md)），这一版改三件事。

## 1. 排到采购第一项

ERP 侧栏「供应链」一组里，「采购商城」排第一（原来在库存、采购、采购需求单之后）：`@shared/erp` 的 `ERP_NAV_GROUPS`。地址、权限不变。

## 2. 商品图（迁移 `490`）

- 每样物料最多 6 张商品图，第 1 张是封面。表 `material_images (material_id, sort_no, image_id)`；图片本身照旧存在 `erp_images`（按内容去重、只追加，上传前在浏览器里压成 JPEG，最长边 1600 像素、单张不超过 1 MB）。
- 在「采购商城 → 物料主档 → 维护」里传、删、设为封面，「保存商品图」整组写（`PUT /api/erp/shop/materials/:id/images`，`{ imageIds, expectedImageIds }`）：要「物料档案」权限；带页面看到的那一组，别人先改过的拒绝 `IMAGES_CHANGED`，原样重提结果一样；记审计 `material_images`。
- 看图 `GET /api/erp/shop/images/:id`：进得了商城的都能看（部门申购也能——需求单图片的数据隔离不放行别人传的图，商品图是公开给全店挑的）；只给挂在物料上的图，别的图片按编号取不到。
- 目录（`/catalog`）、比价（`/offers`）、物料主档列表都带 `imageIds`。

## 3. 版面（逛电商的感觉）

照 shadcn / frontend-design 那一路的做法：不引新的组件库，用现有的 Tailwind 与全店的颜色变量（深色模式照样跟着走），玻璃质感用半透明底 + `backdrop-blur`。

- **首屏**：深色渐变底（柚子黄与湖蓝两团柔光），大标题「挑好东西，比好价格。」，在架几样、几家供应商；搜索框与门店是玻璃质感的胶囊。
- **分类**：一条玻璃质感的横向分类，往下翻时贴在上面。
- **商品卡**：正方形大图（悬停轻微放大）、左上角「N 家比价」、右上角「包邮」玻璃角标；名字两行、规格一行；价格 ¥ 小一号、数字大；最快几天到。宽屏 4–5 列、手机 2 列。
- **没有商品图时**：按分类给一块柔和的渐变底、物料名字与包裹图标（同一类颜色一样），不留空白格子。
- **商品页**：左边大图与缩略图、右边名字、规格、可采购最低含税价，「横向比价、选供应商」「看各家报价」；下面是各家报价卡。
- **比价页、清单**：物料信息头与清单每一行带封面图。
- **页签**：一条玻璃质感的胶囊；逛的时候右下角浮着「采购清单 N」（提醒在页面上方，不挡它）。

## 4. 测试

- `tests/shop.test.ts`「商品图」：整组换、原样重提、别人先改过拒绝、目录 / 比价 / 主档都带、部门申购能看、没挂在物料上的图取不到、没登录 401、换顺序、重复拒绝、清空后取不到。
- `e2e/shop.spec.ts`：物料主档传一张图、保存 → 商城卡片与商品页的图换上；`e2e/erp-ia.spec.ts`、`tests/erp-ia.test.ts`：供应链一组采购商城排第一。

## 5. 没做的 / 待定

- 商品图只能一张张传（主档里），没有批量导入；以后供应商门户可以让供应商自己传，待店主定。
- 商品图没有裁切工具：建议传正方形、白底或干净背景的图，卡片按正方形铺满。
