# 系统门户页（店主 2026-11-24）

> 店主《系统门户页改造需求说明》：新增统一门户页作为打开网页后的第一个界面，分四大板块（柚子、ERP、办公、管理后台）；
> 侧栏底部的换店、环境标识、版本号与头像，连同通知铃铛，移到门户页顶部右侧；ERP、办公的入口从柚子侧栏拿出来，归入门户页。
> 纯入口层改造：四个板块里面的功能、菜单、业务逻辑不改；登录认证与权限模型不改；不改主题色；没有迁移。
> 规则 PT1–PT6 见 `PENDING_DECISIONS.md`「系统门户页」。
>
> **店主 2026-11-24 起四个板块改叫 CRM、ERP、WCP、Design**，原来管理后台的分区拆进各板块，见 [`BOARDS.md`](BOARDS.md)（下表是改名以前的写法，以 BOARDS.md 为准）。同一天起**门户就是首页 `/`**（`/portal` 跳过来），CRM 在 `/crm`（BOARDS.md 第 8 节）。

## 1. 门户页（`/portal`，`src/client/features/portal/PortalPage.tsx`）

- **顶栏**：左 Logo、「柚子 yuzu」与门店名称；右依次是通知铃铛（未读角标，点开是通知面板）、环境标识、换店（能进多家店时）、版本号（窄屏排在环境标识下面，常显）、头像（个人信息、本机终端、网络与同步、外观、修改密码、退出登录）。
- **欢迎语**：门店名称、「早上好 / 下午好……，姓名」、岗位与职责。
- **四张板块卡片**：图标 + 板块名 + 一句说明，圆角卡片，悬停上浮、描边。宽屏一行四张，窄屏两列两行。

| 板块     | 进到哪里                                                           | 谁能进（按现有权限）                 | 卡片配色                     |
| -------- | ------------------------------------------------------------------ | ------------------------------------ | ---------------------------- |
| 柚子     | 门店主导航第一个能用的页面（会员工作台优先；只有对客导览的进导览） | 门店主导航里有页面（后台不算）       | 墨绿（侧栏的 `rail`）        |
| ERP      | `/erp`                                                             | 能进 ERP（有能用的模块，或能改设置） | ERP 顶栏的深蓝（`rail-erp`） |
| 办公     | `/oa`                                                              | 人人都有                             | 浅底 + 湖蓝点缀              |
| 管理后台 | `/admin`                                                           | 有任一后台入口权限                   | 中性灰绿                     |

- 进不去的板块照样显示，置灰、写「没有这个板块的权限」，点了不跳（不白屏）。点餐平板账号不经过门户，直接进点餐页。

## 2. 路由

- 登录以后先到 `/portal`：从登录页登录、打开网页（首页 `/`）登录的都是；会话过期、点了某一页的链接被送回登录页的，登录后回到原来那一页。
- 各板块之间切换不用重新登录（同一个会话）。门店首页 `/` 照旧按岗位落到会员工作台、ERP、餐饮……（门户页「柚子」卡片与「返回门户」以外的旧入口都不变）。
- 浏览器用例：登录以后从门户页回到首页继续（`e2e/portal.ts` 的 `passPortal`），原来的落点不变；门户页本身在 `e2e/portal.spec.ts`。

## 3. 侧栏与「返回门户」（第二批）

- 柚子侧栏最下面原来的换店、实例标识、版本号、头像，以及「收起导航」旁边的通知铃铛都去掉（在门户页顶栏）；头像菜单里的「进入 ERP」「办公」去掉（门户页有板块卡片）。
- 侧栏最下面换成「返回门户」（`PortalBackRail`）：图标 +「门户」，下面只写版本号（店主 2026-11-24 定，PT5；环境标识与 SHA 常显在门户页顶栏），悬停看完整标识与 SHA。
- ERP、管理后台的顶栏各加一个「门户」按钮（`PortalBackButton`）；原来的「返回门店」「返回前台」照旧。
- 修改密码、退出登录、外观、网络与同步、本机终端都在门户页的头像菜单里：在柚子里要用时先点「返回门户」。

## 4. 分批

1. 门户页与路由改造（这一批）：门户页、登录后的落点、铃铛的通知面板、换店与头像菜单可以放在顶栏。
2. 侧栏清理与三项迁移：柚子侧栏去掉底部的换店、环境标识、版本号、头像与通知铃铛（已在门户页顶栏），头像菜单里的「进入 ERP」「办公」去掉；侧栏与 ERP、后台顶栏加「返回门户」。
