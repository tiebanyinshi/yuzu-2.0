# 8.2.14 前台改良：按人数发牌、结账记录搜索、POS 参考号查重

需求来源：店主 2026-11-27 发来的「收银员工作台」设计 demo：「如果有一些目前系统还没有的改良点，请学习优化」。键位在 8.2.12，界面在 8.2.13。

## 1. 按人数发牌

接待发牌对话框上面多一行「按人数发牌」：填男几位、女几位（全角数字也认），回车或点「按推荐区分牌」：

- 按 8.2.13 的区域状态推荐顺序（空闲 > 正常 > 繁忙，同一档在店占比低、停得久的先）逐区分空牌，区里按牌号顺序，一个区不够接着下一个区；
- 已经填了牌号的行（刷卡、手输、会员本人那一行）留着，只补齐不够的、去掉多出来的空行；
- 分好以后每一行照旧能改、能刷卡换；确认发牌照旧（这个数字框里的回车只分牌，不发牌）；
- 加入已在店客人的同行组时不显示（那是一位一位加）。

## 2. 结账记录搜索

结账记录上面多一个搜索框：牌号（部分、全角也认）、单号后几位、金额（「499」「499.00」）、经办人、桌号；↑↓ 选、回车打开那一单。

## 3. POS 参考号查重

银行卡收款的备注框改叫「POS 参考号（选填，填了能查重）」：

- 填了要是 4–20 位字母或数字（敲成中文、带空格的拦下，写明原因）；
- 今天（营业日）没反结账的单里，银行卡用过同一个参考号的，这一笔下面提醒「今天已有 n 笔用过……请核对是不是同一笔刷了两次」——只提醒、不拦（同一张卡分两次刷，参考号也不一样；真重复了由收银核对）。

## 4. 撤销发牌的时间

店主定的自己能撤销的时间是 15 分钟（后台「前台规则」默认就是 15）；页面上几处没取到规则时的兜底原来写的是 10，改成跟默认一致。

## 5. 没做的 / 要店主定的

demo 里还有几项要店主先定，这一版没做：

- 前台的退款、反结账、超时取消改成「提交审批、店长批了才生效」（现在是值班经理当场授权）；
- 交班「盲点」（先点钞再看应有现金）；
- 未收回手牌、挂失手牌清单；
- 储值卡支付输密码；
- 发牌台验团购券、绑到某张手牌（现在是结账时验券）。

店主 2026-11-27 已定：1 保持现状、2 不做、3 做（8.2.21，见 `V82221_TAG_EXCEPTIONS.md`）、4 不设密码、5 结账时才验。
