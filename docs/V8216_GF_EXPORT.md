# 8.2.16 · 业财法与审批中心导出；微信特批登记时必传 OK 截图

《汤崎 ERP｜业财法审批与 WCP 模块 需求变更文档 v0.1》第 6 批（核对见 `docs/V8212_APPROVALS_PURCHASING.md` A3、A4）。按文档建议 WB6、WB7（`docs/PENDING_DECISIONS.md`）。没有数据库迁移。

## 1. 导出（A3）

| 入口                         | 谁能导                                             | 内容                                                                                                                                                                                                               |
| ---------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| WCP「业财法审批 → 全部」顶上 | 看全部事项的：店主（配置业财法角色）、内控、董事长 | 按发起日期段：编号、类型、事项、经营主体、费用承担部门、金额、发起人、发起时间、状态、逾期、当前等谁、审批记录（每轮每级谁、什么时候、同意 / 退回 / 驳回 / 自动跳过、意见）、关联的微信特批编号；一次最多 2,000 项 |
| ERP「审批中心」顶上          | 店主（维护审批规则）                               | 按提交日期段：单号、类型、金额、部门、提交人、提交时间、状态、走到第几级 / 共几级、审批记录（谁、代谁、同意 / 退回、时间、意见）、结束时间；一次最多 5,000 张                                                      |

- 接口 `GET /api/gf/export.xlsx`、`GET /api/approvals/export.xlsx`，参数 `from`、`to`（必填），另可按类型 `docType`、状态 `status` 筛。
- 超过上限拒绝（`EXPORT_TOO_LARGE`，请缩小范围），不悄悄截掉；导出写操作日志（`audit_logs`，`action = export`，带筛选条件与条数）。
- WCP 办公审批、ERP 费用与备用金原来就有导出，不动。

## 2. 微信特批：登记时必传 OK 截图（A4，WB6）

- 「登记微信特批」要同时上传微信里的 OK 截图（PNG / JPG / WEBP，5 MB 以内，按文件头核对类型），存在特批的文件里（`gf_files`，`ok_screenshot`）。不传、类型不对的拒绝。
- 补登（1 个工作日内）只要需求说明；8.2.16 以前登记、当时没有截图的，补登时照旧要一起上传 OK 截图。
- 提醒文字改成「请在 … 前上传需求说明补登」。

## 3. 截图复用提示（WB7：只提示、不拦）

同一张截图（内容摘要一样）用在了别的特批上：照样登记，登记后提示「这张 OK 截图也用在了别的特批上」，特批列表上两边都标出对方的编号，交审核的人判断是不是同一次确认。只能认出完全相同的文件，裁剪、重新截图的认不出。

## 4. 测试

`tests/govflow-export.test.ts`：必传截图、类型核对、补登只要需求说明、截图复用两边标出；两个导出的权限、日期段、写日志。`tests/govflow-p01.test.ts`、`tests/govflow-p05.test.ts` 按登记要截图更新。

## 5. Codex 审查修正

业财法事项导出按状态筛时，原来先取日期段里的前 4,001 项再筛，范围里事项多就总是报「超过上限」。改为按编号分批（每批 500 项）读、算出状态先筛再计数：筛下来不超过 2,000 项的照样导出，超过的照旧拒绝（`EXPORT_TOO_LARGE`）。`tests/govflow-export.test.ts` 加了 2,100 项已撤回事项下按状态导出的用例。
