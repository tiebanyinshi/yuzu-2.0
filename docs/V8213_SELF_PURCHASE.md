# 8.2.13 · 采购：无供应商自购

《汤崎 ERP｜采购模块 需求补充文档（单号搜索 / 排序 / 无供应商自购）v0.1》第 3 部分。8.2.12 做了单号直达与排序（`docs/V8212_APPROVALS_PURCHASING.md`），这一版是第 3 批。
待确认项按文档建议（`docs/PENDING_DECISIONS.md` PS-A、PS5–PS8）。数据库迁移 `700`，回滚 `docs/rollback/700_self_purchase.down.sql`。

## 1. 核对时（C5、C6）

采购单、收货单、发票、付款都要求供应商；急采、直接收货也要供应商。零采备用金、业财法零星采购没有供应商，但不连采购单，走不了「采购单 → 收货 → 报销」。没有供应商时只能临时建一个供应商，档案里混进「楼下五金店」「某平台某店」这类一次性的。

## 2. 做法（PS-A）

- 采购单加「采购方式」：**供应商采购**（原来的做法，默认）/ **自购**。自购不选供应商，**不造虚拟供应商**。
- 自购要填：自购原因（无供应商可供 / 应急 / 零星采购 / 其他，选「其他」要写说明）、购买渠道或商家名称、经办人、付款方式（员工垫付后报销 / 备用金 / 对公转账 / 其他）、购买日期（选填），**至少一张发票或收据照片**（最多 9 张）。
- 数据库约束：供应商采购必须有供应商、自购必须没有（`purchase_orders_method_supplier`）；自购必须有原因、渠道、经办人、付款方式（`purchase_orders_self_info`）。票据照片在 `purchase_order_self_receipts`。
- 列表、单号直达、流程进度、审批中心、采购台账、需求单进度里，供应商一栏写「自购 · 渠道」。

## 3. 审批

- 自购提交**一律要审批**，不走「未超过免确认门槛，提交即确认」，也不能「同时以负责人身份确认」；**提交人不能审**自己的自购单。
- 默认一级负责人；**超过 ¥2,000 加一级店主复核**（PS5）。店主在「审批中心 → 审批规则」给采购单配了规则的，按规则走。
- 偏差：PS5 写「后台可改」，这一版金额是常量 `SELF_REVIEW_CENTS`（`src/shared/purchasing.ts`）；阈值统一做成后台可改放在第 5 批（审批流程配置与阈值）。

## 4. 收货与付款

- 收货单挂自购的采购单时不选供应商：收货页供应商下拉选「自购（不选供应商）」，采购单下拉只列自购的单。选了供应商再挂自购单的，拒绝。
- 结算按**现付**：不进应付、不进三单匹配的供应商付款，出现在「采购单转报销」的候选里，在报销里报（员工垫付）或用备用金。
- 只有收据的入账照报销「收据」的口径（PS7，文档写需财务确认）。

## 5. 不能做的

自购单没有供应商，所以：不能挂采购合同（`SELF_NO_CONTRACT`）、不能从询价单转、不能补单（`SELF_NOT_ALLOWED`）、不能发到供应商门户（`SELF_NO_SUPPLIER_LINK`）。

## 6. 修改（PS8）

草稿、退回时可以改采购方式与自购信息；改成供应商采购要选供应商，改成自购要填自购信息。

## 7. 测试

`tests/self-purchase.test.ts`：必填校验、自购不能带供应商、数据库约束；¥900 自购等负责人审批（提交人审不了）、列表与单号直达的「自购 · 渠道」、收货不选供应商、转报销候选；超过 ¥2,000 加店主；供应商采购照旧。

## 8. Codex 审查修正

1. 迁移 `700_self_purchase.sql`：新列不带行内约束，CHECK 与外键（`self_handler_id` → `staff`）、`purchase_orders_method_supplier`、`purchase_orders_self_info`、放宽后的 `inv_docs_check` 都先 `NOT VALID` 再 `VALIDATE`，含义不变。
2. 改版已确认的自购单：改版前的版本快照里留下自购信息（原因、说明、渠道、经办人、付款方式、购买日期、票据照片编号），换掉票据后照样能查回旧凭证。
3. 操作编号摘要：供应商采购、没带自购信息的新建请求不把 `purchaseMethod`、`self` 两个默认值算进摘要，与升级前一样；升级前提交、结果没确认的原样重提照旧认（`poRequestHash`）。
4. 收货选采购单：采购单列表加 `method`（`supplier` / `self`）在服务端筛，收货页按选的「自购（不选供应商）」或供应商传；不再在取回的前 300 张里筛，自购的单不会被挤掉。
5. 草稿在同一次请求里换采购方式并提交：重读改后的采购单再提交，自购照旧走负责人审批（店主勾了「直接确认」也不直接确认），改成供应商采购的照旧核询价门槛与供应商准入。

`tests/self-purchase.test.ts` 加了对应的用例。
