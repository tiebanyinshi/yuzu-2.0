# 8.2.22 前台快捷键：全部操作键盘完成

需求来源：店主 2026-11-27 发来的「收银员工作台」设计 demo（`cashier-workstation-demo.zip`）：「新 UI 的清晰感，以及可把前台所有操作通过快捷键解决，让前台能够快速发卡收银」；与现系统冲突的地方选汤泉业务更合理的一方。
这一版做键位层；界面清晰感在 8.2.23，demo 里现系统没有的改良（按人数发牌、POS 交易号核对、订单查询搜索等）在 8.2.24。

## 1. 键位总表

| 在哪           | 键                | 做什么                                                                                       |
| -------------- | ----------------- | -------------------------------------------------------------------------------------------- |
| 哪里都能用     | ⌥1–⌥9（Win：Alt） | 跳到左边导航的第几个入口（顺序就是侧边栏的顺序）                                             |
|                | ⌥0                | 全部功能：输入名字筛选，↑↓ 选、回车打开                                                      |
|                | ⌥N                | 系统通知                                                                                     |
| 发卡台、收银台 | F1–F10            | 原来的固定键表不变（8.2.1：F1 充卡、F2 发牌、F4 加项目、F9 买单、F10 打单……），「?」看一览   |
|                | ↓ / ↑             | 进到账单明细（第一行 / 最后一行）                                                            |
| 账单明细       | ↑↓                | 在明细之间移动                                                                               |
|                | Del / ⌫           | 作废这一项（餐饮是退菜，照原来的规矩：超时、不是自己登记的要店主）                           |
|                | /                 | 给这一项打折                                                                                 |
| 买单对话框     | ⌥1–⌥9             | 加第几种收款方式（按钮上写着），金额默认还差的部分，光标落到这一笔的金额                     |

| 任何输入框     | 全角              | 输入法开着时敲的「８２０１」「Ａ０２３」「１２８．５」按半角认（牌号、金额、芯片号、读卡器） |

对话框里的 F 键：对话框自己的按钮写了哪个 F 键，按它就点那个按钮；没写的照旧提示「先关掉现在的对话框」。

## 2. 现金找零核对（demo 里有、现系统没有）

现金那一笔填了「客人实给」，找零超过 ¥500，或者实给超过应收的两倍：按「确认结清」（F9）先提示「要找零 ¥…，请核对客人实给」，再按一次才结清。多半是把实给敲错了一位。

## 3. 与 demo 不一样的地方（选了汤泉业务更合理的一方）

- **F 键固定，不随快捷栏重排**：demo 改快捷栏后 F 键跟着挪，前台练熟的手感会乱；沿用 8.2.1 店主定的固定表；
- **数字键留给金额**：demo 收款时方向键选方式、数字是金额；我们的收款是一行一行的组合收款，用 ⌥数字加方式，数字照样输金额；
- **保留系统的保护**：结果待确认（断网重提不重复收）、未开班不能收款、权限与当场授权、押金与锁牌外出——demo 没有，照旧；
- **不抢焦点**：demo 每次刷新都把光标拉回命令框，和弹窗打架；我们只在需要的时候（加收款方式后）把光标放到金额；
- **读卡器**：沿用系统的键盘式读卡器识别（50 毫秒、至少 4 位），不改成 demo 的 80 毫秒 3 位，只加全角。
