# 8.2.27 前台界面：区域状态、最近发牌、应收大字

需求来源：店主 2026-11-27 发来的「收银员工作台」设计 demo（「新 UI 的清晰感」）。键位在 8.2.27，现系统没有的改良在 8.2.27。

## 1. 发卡台：没选手牌时右边一栏

原来是一句「选一张手牌看客人卡」的空白提示，改成：

- **区域状态**：男宾、女宾各区（牌号的字母：A 区、B 区；没有字母的是普通柜）一张卡片：
  - 状态：**空闲**（最近 15 分钟没往这里发过）、**正常**、**繁忙**（最近 15 分钟发了 3 张以上）、**已满**（没有能发的空牌）；
  - 在店占比条、在店几张 / 一共几张、空牌几张；
  - 每个分区推荐一个区（金边、「推荐往这里发」）：空闲 > 正常 > 繁忙，同一档先挑在店占比低的，再挑上一次发牌早的；
  - 点卡片：手牌板筛到这个区。VIP 柜不参与（按客人指定发）。
- **最近发牌**：最近发出去的 8 张（牌号、客人、几点、哪个区），还在自己能撤销的时间里的标「可撤 n 分」，点一下打开客人卡；
- 最下面一行常用键位。

原来的「连续 10 张发到同一区才提示换区」（8.2.3）照旧，这里是常驻的一眼可见。

## 2. 收银台：此刻应收用大字

账单底部原来大字是「本牌未结（已挂明细）」，含门票的应收是下面一行小字。收银最要紧的是此刻要收多少：

- 在店、有门票的：**此刻应收（含门票）**用 36 号大字（绿色），下面一行是「已挂明细 ¥… · 门票 ¥…」；
- 发卡台、已结账的照旧。

## 3. 快捷键的顺序

⌥1–⌥9 按侧边栏展开时从上到下的顺序（按业务域分组排），「全部功能」里每个入口旁边写着它的 ⌥ 键。

## 4. 与 demo 不一样的地方

- 配色用系统原来的色标（浅色、深色模式都有），不照 demo 的深底金色；
- demo 的发牌台是左右两栏常驻；我们的发卡台左边是整个手牌板（找牌、看在店），所以区域状态放在没选手牌时的右栏，选了手牌就是客人卡。
