# 四个板块：CRM、ERP、WCP、Design（店主 2026-11-24）

店主 2026-11-24：门户页的四个板块改名——「柚子」改叫 **CRM**，**ERP** 不变，「办公」改叫 **WCP**，「管理后台」改叫 **Design**；把现在跟品牌与设计有关的模块都搬进 Design，并做成**素材库**：字体、图片、视频都存在素材库里，可以一键切换。

店主同天定（问答）：

1. **原来管理后台里的分区拆进各板块**，后台不再单独作为一个板块存在（地址 `/admin/…` 不变，书签、用例照旧能用）。
2. **搬进 Design 的**：UI 工作台、电子菜单的版面与字体、对客导览、官网。
3. **一键切换 = 按用途设「当前使用」的素材**：素材库按字体、图片、视频分类存多份；每个用途（例如平板菜单的英文品牌字体）选一份「当前使用」，点一下全系统换掉，旧的留着随时切回。

门户页、侧栏、返回门户的做法照旧（[`PORTAL.md`](PORTAL.md)）。

## 2. 原来后台的分区拆到哪

分区的地址、权限、页面内容都不变，只是**归到某一个板块**：在哪个板块的设置里出现、进去以后侧栏只列这个板块的分区、顶上写这个板块的名字、「返回」回到这个板块。

| 板块   | 分组             | 分区                                                                         |
| ------ | ---------------- | ---------------------------------------------------------------------------- |
| CRM    | 概览             | CRM 设置首页（原后台首页）、数据看板                                         |
| CRM    | 规则中心         | 规则总表、门店基本规则、数据字典与字段                                       |
| CRM    | 会员与营销       | 会员体系、券、签赠                                                           |
| CRM    | 营业项目         | 价目与套餐、手牌与前台、技师、餐饮、电子菜单、客房、预约                     |
| CRM    | 场地、设备与线上 | 空间台账、设备、微信小程序                                                   |
| ERP    | 主体、接口与审计 | 门店与主体、对外接口、期初与旧账、操作审计                                   |
| WCP    | 人员与行政       | 员工账号、岗位权限、组织架构、考勤设置、办公审批、工资条、员工食堂、安保巡场 |
| Design | 品牌与设计       | Design 首页、素材库（第二批）、UI 工作台、对客导览、官网（第三批）           |

怎么分的（默认做法，BD2 待确认）：管客人、管前台营业、管价目与会员的在 CRM；管钱的主体、对外的支付与开票接口、旧账与审计在 ERP（ERP 本来就管财务与审计，`/erp/audit` 是账目自检，`操作审计` 放在旁边）；管人的在 WCP；对客的视觉在 Design。规则总表照旧列全部规则（含库存、ERP、人员的），每一行「去哪里改」照旧跳到对应的页面。

**入口**：

- **CRM**：门店主导航原来的「后台」改叫「CRM 设置」，进 CRM 设置首页；只有看板权限的岗位进来直接到数据看板（原来的规则不变）。
- **ERP**：ERP 侧栏「设置」一组在「ERP 设置」下面加上 ERP 板块的几个分区（有权限的才显示）。
- **WCP**：办公首页加一块「WCP 设置」（有人员与行政任一分区权限的才显示），进去是第一个能进的分区；部门负责人、人力行政部照旧只看得到自己那几项。
- **Design**：门户页的 Design 卡片，进 Design 首页；有 UI 工作台、对客导览、电子菜单任一权限的进得去，没有的置灰（PT3）。设计师账号（只有工作台权限）点 Design 进 Design 首页，看得到工作台。

进不去任何 CRM 设置分区的人，CRM 侧栏不显示「CRM 设置」；其余板块同理。直接打开某个分区的地址照旧按分区自己的权限放行。

## 3. Design 首页

Design 首页列这个板块的分区卡片，每张写这个分区管什么、最近一次改动（有的）。第一批是：UI 工作台、对客导览，加上从电子菜单里拿出来的**品牌字体**状态（现在的「品牌英文字体生效了没有」）。第二批加素材库，第三批加官网。

电子菜单拆成两半：**内容**（设置、分类、菜品图文、价格）留在 CRM 的「电子菜单」；**样子**（版面在 UI 工作台里本来就有；品牌字体第二批改成从素材库选）在 Design。

## 4. 素材库与一键切换（第二批）

- **素材**：字体（WOFF2 / TTF / OTF，≤ 8 MB）、图片（PNG / JPEG / WebP / SVG，≤ 10 MB）、视频（MP4 / WebM，≤ 80 MB）。每一份有名字、分类、上传人、上传时间、大小、宽高或时长、备注（例如字体的授权说明）。按文件头认格式（不看扩展名）、SHA-256 去重；SVG 有脚本、事件属性、外部链接的不收；送出去带禁止脚本的 CSP。与 UI 工作台的素材（`studio_assets`）同一个存法，工作台里插图片也能从素材库选。
- **用途**：系统里登记好的「这个位置用哪份素材」，每个用途限定素材的种类。第一批用途：

  | 用途                     | 种类        | 用在哪                                         | 没设时                                             |
  | ------------------------ | ----------- | ---------------------------------------------- | -------------------------------------------------- |
  | 平板菜单 · 英文品牌字体  | 字体        | 电子菜单的英文标题（现在的 ABC Arizona Flare） | 照旧读服务器 `brand-fonts/` 目录，再没有用顶替字体 |
  | 登录页 · 插图            | 图片        | 登录页左侧                                     | 现在的样子                                         |
  | 门户页 · 顶部横幅        | 图片        | 门户页欢迎语后面                               | 不显示                                             |
  | 门店大屏 · 待机视频      | 视频        | 对客导览大屏没有轮播时                         | 现在的样子                                         |
  | 官网 · 首屏视频 / 分享图 | 视频 / 图片 | 官网（第三批）                                 | 官网自带的                                         |

- **一键切换**：每个用途一行，右边是当前用的那份；点「换」从素材库里选（只列种类对得上的），确认后立即生效（各终端下次取设置时换上，平板在客人没在点菜时换）。每次切换记一条（谁、什么时候、从哪份换到哪份），可以一键「切回上一份」。被某个用途用着的素材不能删，要先换掉。
- **权限**：新权限「素材库 · 管理」（上传、改名、删、切换），默认店主、店总、设计师；能进 Design 的都能看。切换、上传、删除记审计。
- **授权字体**：授权的商业字体放进素材库以后存在数据库里（不进 Git、不进镜像，AGENTS.md 环境隔离），只发给登录的终端与平板；上传时要求填授权说明。试用版字体（字体名里写着 Trial / Unlicensed）照旧拒收。

迁移号 `265`–`269` 留给这件事（ROADMAP 第 7 节登记；`260`–`264` 是手牌管理预留的，`262` 已用于改名）。
