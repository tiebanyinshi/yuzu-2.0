店主 2026-11-24：门户页的四个板块改名——「柚子」改叫 **CRM**，**ERP** 不变，「办公」改叫 **WCP**，「管理后台」改叫 **Design**；把现在跟品牌与设计有关的模块都搬进 Design，并做成**素材库**：字体、图片、视频都存在素材库里，可以一键切换。

## 4. 素材库与一键切换（第二批）

- **素材**：字体（WOFF2 / TTF / OTF，≤ 8 MB）、图片（PNG / JPEG / WebP / SVG，≤ 10 MB）、视频（MP4 / WebM，≤ 80 MB）。每一份有名字、分类、上传人、上传时间、大小、宽高或时长、备注（例如字体的授权说明）。按文件头认格式（不看扩展名）、SHA-256 去重；SVG 有脚本、事件属性、外部链接的不收；送出去带禁止脚本的 CSP。与 UI 工作台的素材（`studio_assets`）同一个存法，工作台里插图片也能从素材库选。
- **用途**：系统里登记好的「这个位置用哪份素材」，每个用途限定素材的种类。第一批用途：

  | 用途                     | 种类        | 用在哪                                         | 没设时                                             |
  | ------------------------ | ----------- | ---------------------------------------------- | -------------------------------------------------- |
  | 平板菜单 · 英文品牌字体  | 字体        | 电子菜单的英文标题（现在的 ABC Arizona Flare） | 照旧读服务器 `brand-fonts/` 目录，再没有用顶替字体 |
  | 登录页 · 插图            | 图片        | 登录页左侧                                     | 现在的样子                                         |
  | 门户页 · 顶部横幅        | 图片        | 门户页欢迎语后面                               | 不显示                                             |
  | 门店大屏 · 待机视频      | 视频        | 对客导览大屏没有轮播时                         | 现在的样子                                         |
  | 官网 · 首屏视频 / 分享图 | 视频 / 图片 | 官网（第三批）                                 | 官网自带的                                         |

- **一键切换**：每个用途一行，右边是当前用的那份；点「换」从素材库里选（只列种类对得上的），确认后立即生效（各终端下次取设置时换上，平板在客人没在点菜时换）。每次切换记一条（谁、什么时候、从哪份换到哪份），可以一键「切回上一份」。被某个用途用着的素材不能删，要先换掉。
- **权限**：新权限「素材库 · 管理」（上传、改名、删、切换），默认店主、店总、设计师；能进 Design 的都能看。切换、上传、删除记审计。
- **授权字体**：授权的商业字体放进素材库以后存在数据库里（不进 Git、不进镜像，AGENTS.md 环境隔离），只发给登录的终端与平板；上传时要求填授权说明。试用版字体（字体名里写着 Trial / Unlicensed）照旧拒收。

**8.1.33 实际做的（与上面的规划不同处以这里为准）**：

- 用途按门店分开设（迁移 `266`，Codex 安全审查）：每家门店各自选「现在用哪一版」，只挂在分店的设计师改不了总店的；素材与版本全公司一份，哪家店用着的素材都不能归档。
- 第一批用途做了三个：平板菜单 · 英文品牌字体、门户页 · 顶部横幅、门店大屏 · 待机视频（`@shared/design` 的 `DESIGN_SLOTS`）。登录页插图没接（登录页在登录前打开，素材文件要登录才能取）；官网两个用途随第三批。
- 上限：字体 ≤ 8 MB、图片 ≤ 5 MB、视频 ≤ 30 MB（文件存在数据库里，视频再大拖慢备份与恢复）。SVG 照工作台素材的规矩查。素材库一共 ≤ 2 GB（所有版本、归档的也算；超了拒绝 `DESIGN_QUOTA`，Codex 安全审查）。上传在读正文之前先核对登录、权限、种类与声明的大小，全店同时最多 2 个、同一个人同时 1 个（`DESIGN_UPLOAD_BUSY`）。还没有永久删除旧版本、腾出空间的办法（素材只追加），待店主定。
- 权限：没有另建新权限，用现成的「UI 工作台 · 编辑」（设计师）与「设置管理」（店主、店总）；登录了就能读「现在用的」与文件（门户横幅、大屏、平板都要）。
- 素材不删，只「归档」：被某个用途用着的不能归档，要先换掉；归档的不能再设。素材加新版时用途不会自己跟着换，用途卡片上提示「有新版本」，点一下换。
- 切换带操作编号与「页面看到的现在用的」：结果不确定时原样重提，同一个编号只换一次；别人先换过的拒绝（`SLOT_CHANGED`）。本机先记下再发，写后读回核对，记不下不发。
- 读的地方：平板菜单英文字体（`/api/emenu/fonts/brand-en` 先看用途，没设再读 `brand-fonts/`）、门户页横幅、对客导览大屏没有在用底图时循环播放待机视频（静音）。

迁移号 `265`–`269` 留给这件事（ROADMAP 第 7 节登记；`260`–`264` 是手牌管理预留的，`262` 已用于改名）。

**据此调整第二批（素材库）的做法**（替代第 4 节里相应的写法）：

1. **素材与版本分开、只追加**：素材（名字、种类、标签、授权说明）一行，每次上传文件追加一个版本（摘要、格式、大小、宽高或时长、上传人）。「替换文件」是加一个新版本，编号不变、旧版本还在（不学 Strapi 原地覆盖）。
2. **用途绑定到某个版本**：素材出了新版本，用途不跟着悄悄变；用途卡片上提示「有新版本」，点了才换（学 Penpot 的「更新」）。
3. **切换只追加**：每次切换追加一行（用途、版本、经办人、原因、时间），当前用的是最新一行；「切回上一份」也是追加一行。带操作编号、行锁，接进「结果待确认」。
4. **在哪里用**：用途的分配就是反查表；用着的素材只能归档、不能删，删之前列出用在哪。
5. **字体**：服务端读出字族、字重、斜体（opentype.js，MIT）按字族归组；授权说明必填，试用版拒收；预览写店名、菜名、价格。
6. **图片**：按命名的几档尺寸出 WebP（sharp，Apache-2.0）加一张模糊占位；格式按文件头认；SVG 照工作台的规矩清洗。
7. **视频**：取一帧做封面；只收浏览器能直接播的 MP4（H.264 / AAC）和 WebM，不在服务器上转码（门店服务器不装 ffmpeg，转码交给设计师上传前做；以后要再说）。
8. **界面**：左边按种类与标签筛，网格 / 列表两种看法（记在本机），拖进来批量上传；右边抽屉看版本、用在哪、「设为某个用途」。另有「用途墙」：每个用途一张卡，写当前用的、谁什么时候换的、「切回」。
9. **权限**：看、上传与改信息、切换用途分开；切换会改线上，单独授权、记审计。
10. **编辑器接素材库**：工作台、导览只记素材编号或用途代码，不记地址。
