# 采购商城并进柚子（8.1.32）

店主 2026-11-24：「采购商城其实是我们直接把他的这个模块接进来了，后续由我们开发……把这个采购商城完善到上线程度。」
8.1.31 先把外部商城接进来（`docs/MALL_V8131.md`，`/api/erp/mall/*`）；这一版把商城的页面做进柚子的 ERP：**ERP → 供应链 → 采购商城**（`/erp/shop`）。
提交生成的还是同一种采购需求单（XQ，来源「商城」），后面的主管确认、核库、采购审核、下单、收货都照原来的流程走；外部商城的接口照旧可用，两边的单在一张表里。

## 1. 页面

| 页签         | 谁看得到                                                                          | 做什么                                                                                                                                                                                                                                                      |
| ------------ | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 商品目录     | 能提需求的（`request.create`）、采购、库管                                        | 选门店（只列可用的）→ 按分类、关键字找物料 → 进比价页看各家供应商的报价：未税价、税率、含税价、起订量、交期、运费、有效期、适用门店；不能采购的写原因（改价审核中、待上架、已停用、供应商未准入、价格已过期、这家门店不适用）。最低的可采购含税价标在卡片上 |
| 采购清单     | 同上                                                                              | 本机按账号存（localStorage）；按供应商分组、改数量（不能低于起订量）、看合计；去结算填预算项目、期望到货、收货地点、主体、拟定支付方式、紧急程度（三档）、备注后提交                                                                                        |
| 自主申请     | 同上                                                                              | 商城里没有的东西：名称、预期分类、数量与单位、规格、品牌型号、参考链接（可不填）、图片（可不传）、采购理由                                                                                                                                                  |
| 我的采购需求 | 同上                                                                              | 自己提的、本部门的、自己当主管的（审核、核库的人在这里也只看这些）；详情有进度步骤与退回原因，「按原单再提」把选品放回清单，自主申请的带回表单                                                                                                              |
| 需求池       | 采购（`request.review`）、库管（`request.stock`）                                 | 全部来源是商城的需求单，按进度时刻排；点进去到 ERP 的需求单页处理                                                                                                                                                                                           |
| SKU 维护     | 采购（`purchase.manage`）看、建、改；审核要「采购规则」（`purchase.rules`）或店主 | 见第 2 节                                                                                                                                                                                                                                                   |

提交断网、超时：本机先存原编号与原请求，再发；结果不确定时页面顶上常显「上一次提交结果待确认」，可以查结果、原样重提、确认作废（`AGENTS.md` 开发约定，与其他 ERP 单据一样，按 `purchase_request` 类型）。

## 2. SKU 与审核（迁移 271）

`mall_skus`：一条 SKU = 一个物料 × 一家供应商 × 一个价：SKU 编码（唯一）、未税单价（分）、税率（基点）、起订量（千分之一）、交期（天）、每行运费（分）、有效期至、适用门店（空 = 全部）、价格版本（整数，每次核心改动通过加 1）。

- 状态：草稿 → 待审核 → 已上架；已上架可停用、停用可重新上架；SKU 不能删（守卫触发器）。
- 草稿随便改；**提交以后改核心信息**（价格、税率、起订量、运费、有效期、适用门店）要提一张「改动」（`mall_sku_changes`，记改前改后与原因），审核通过才生效、价格版本加 1；审核期间这条 SKU 不能采购（改价审核中）。同一条 SKU 同时只能有一张待审的改动（唯一索引）。
- 审核（上架、退回、改动通过或驳回）：要「采购规则」权限或店主；**提交人不能审核自己的**（店主除外）。改动可以由提的人撤回。
- 只有准入通过（`admission = approved`）、在用的供应商的 SKU 能采购；物料要在用、受管。
- 每次写都记审计（`mall_sku`）。

## 3. 提交时的核对

选品提交在建单的同一个事务里，按 SKU 编号升序 `FOR SHARE` 锁住再核对，任何一项不对整单拒绝、清单不清空：

| 错误码                   | 情况                                                               |
| ------------------------ | ------------------------------------------------------------------ |
| `PRICE_CHANGED`（409）   | 加清单时看到的价格版本与现在的不一样（期间改过价）：回清单确认新价 |
| `SKU_UNAVAILABLE`（422） | 现在不能采购（原因同比价页）                                       |
| `BELOW_MOQ`（422）       | 低于起订量                                                         |
| `DUPLICATE_SKU`（422）   | 同一个 SKU 在清单里两行                                            |

需求单行写 SKU 编码、价格版本、意向供应商、参考单价（含税）、税率、运费；商城单号是 `YZ-<操作编号>`。之后的流程、可见范围、进度与外部商城一样（`docs/MALL_V8131.md`）。

## 4. 与 ERP 的需求单页

- 商城来的单在 ERP 的需求单页能看、能审、能核库、能下单，**不能在 ERP 的填单页改**（`MALL_EDIT_IN_SHOP`）：那里没有 SKU 与价格版本，改了会丢。退回的撤回以后在「我的采购需求」按原单再提。
- 模块开关：「采购商城」依赖「采购需求单」，关了需求单（或库存）商城也关。
